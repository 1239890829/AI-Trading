# 战法实证核验（五道检验 + 边界声明）

**问题**：民间战法几乎都"听起来有道理"。凭逻辑点评 = 说废话；只看单次回测的绝对收益 = 被市场 beta 骗。
核验的价值在于**证明它不成立**（省下开发成本），或**证明它成立且稳定**（值得接入）。

## 铁律

1. **先把规则转成可计算谓词**，再谈验证。含糊的"主力吸筹""悄悄搞事情"无法验证——必须落到
   `量比 = 当日量 / 前 N 日均量(不含当日)` 这种程度。**原文没给阈值的地方要显式声明取的是什么默认值。**
2. **主指标一律用「市场中性超额」= 个股收益 − 同一交易日全市场均值**，不要用"信号收益 −
   全样本均值"。后者在**条件本身含大盘/强势日成分**时（如"大盘涨才出手"）会把**市场 beta
   整个算成 alpha**（实测：某组合混合池超额 +1.46%，市场中性后只剩 +0.43%）。
   **判 alpha 还是 beta 的判据：叠加大盘前提后，是否仍跑赢同日全市场。**
3. **结论必须带口径边界**（数据源、复权、费用、可成交性、样本区间），并声明**这不是终审**。
4. **事后发现的规则一律标「样本外待验」**，不得写成"已验证"。

## 五道检验（缺一不可）

| # | 检验 | 回答什么问题 | 做法 |
|---|---|---|---|
| ① | **累计漏斗** | 每多筛一步，是变好还是变差？ | 逐层 `AND`，输出 通过前 k 步 的样本量与 T+N 收益 |
| ② | **单条件独立** | **哪一步真的携带信息**？ | 每次只用一条条件分组 |
| ③ | **参数敏感性** | 原文阈值是不是拍脑袋？ | 把该参数分档（如涨幅 <0/0-2/2-3/3-5/5-7/>7），其余步固定 |
| ④ | **环境分层** | 是市场级效应还是选股 alpha？ | 按大盘（全市场中位涨幅/指数）分档；**关键判据：叠加大盘前提后，是否仍跑赢同日全市场** |
| ⑤ | **分年度稳定性** | 稳定效应还是某几年特例？ | 逐年输出，统计"年度为正的年数"（如 2/11 vs 11/11） |

补充两道常被漏掉的：

- **可成交性**：涨停收盘买不进、次日一字板卖不出。**纸面最好的档往往恰好在涨停附近**——"最优参数"可能是幻觉。
  至少要检查：最赚的那一档是否可执行。
- **成本**：往返成本按 0.2~0.35% 估（佣金双边 + 印花税 0.05% 卖出 + 滑点）。T+5 超额 <0.3% 的结论基本无意义。

## 实现骨架（duckdb，避免把千万行拉进内存）

```python
# 1) 特征一次性物化成临时表（窗口函数），后续所有聚合都打在这张表上
CREATE TEMP TABLE sig AS
WITH feat AS (
  SELECT thscode, date_ms, close_price, volume,
    lag(close_price) OVER w AS prev_close,
    avg(volume) OVER (PARTITION BY thscode ORDER BY date_ms
                      ROWS BETWEEN 5 PRECEDING AND 1 PRECEDING) AS vol_ma5_prev,  -- 不含当日！
    avg(close_price) OVER (... ROWS BETWEEN 4 PRECEDING AND CURRENT ROW) AS ma5,
    lead(close_price, 5) OVER w AS c5,            -- 前瞻收益
    row_number() OVER (PARTITION BY thscode ORDER BY date_ms) AS rn
  FROM daily_k WHERE close_price > 0 AND volume > 0
  WINDOW w AS (PARTITION BY thscode ORDER BY date_ms)
)
SELECT ..., (close_price/prev_close-1)*100 AS chg, volume/vol_ma5_prev AS vr,
       (c5/close_price-1)*100 AS fwd5
FROM feat WHERE rn > 20;    -- 均线预热

# 2) 大盘代理（等权宽度口径，非指数）：每日全市场个股涨幅中位数
CREATE TEMP TABLE mkt AS SELECT date_ms, quantile_cont((close_price/prev_close-1)*100, 0.5) AS mchg ...

# 3) 每个检验 = 一条 GROUP BY 查询；显著性用 t = Δ / sqrt(s1²/n1 + s2²/n2)
```

**踩过的坑**：`", ".join(...)` 拼聚合片段时用空格 join → `AS s1 count(fwd3)` 语法错误（报错位置误导）。

## 读结果的五条经验

1. **"越筛越差"很常见**——民间战法的后置条件常把好样本筛掉。单条件检验通常会发现
   **一半以上的步骤零信息量或负贡献**（实测：某战法五步里只有 1 步微弱为正，1 步明确为负）。
2. **方向对但阈值反了**比"完全无效"更常见。例：原文"别偏离均线"，数据却显示**跌破均线才有效**；
   原文"剔除缩量"，数据却显示**缩量组更好**。此时不是否定该方法，而是**保留方向、重定阈值**。
3. **市场级 vs 选股级必须分开说**。"顺势而为/顺大盘做"通常是**真的**（大盘大涨日全市场普涨），
   但如果叠加该前提后组合仍跑不赢同日全市场 ⇒ **它只是在分享 beta，没有 alpha**。
   这是最容易被自己骗过去的一步。
4. **均值必须配中位与「跑赢比例」**一起看。实测某规则样本外中性超额均值 **+1.33%**，但
   **中位 −0.08%、跑赢比例 49.3%** ⇒ 收益全靠少数极端样本（**右偏**）。这种分布对资金曲线
   极不友好且对样本期极敏感；**只报均值 = 只报一半**。（"跑赢比例"指跑赢基准的比例，
   与"绝对收益为正的比例"是两回事，别混。）
5. **网格选取：t 值 ≠ 效应量**。按 t 值最高选规则，会挑到「样本量巨大、效应极小」的组
   （实测 n=35 万、t=+11.8，超额仅 +0.12%，扣成本即负）。必须**并列**「max t」与
   「max 效应量（设样本量下限）」两种准则，只看一种必然偏。

同时注意**统计实现的静默陷阱**：SQL `GROUP BY` 不返回空分组 ⇒ 漏斗/单条件这类
"标签集合已知"的检验要 LEFT JOIN 补齐、显式输出 `n=0`（否则读者会以为那一档不存在）。
写单测时，合成数据**必须让市场因子逐日波动**，否则连"市场均值 join 错位一天"都测不出来
（实测踩过：第一版数据太规则，变异逃逸）。

## 输出模板

```
一、规则化（原文 → 可计算谓词，标注默认取值）
二、口径声明（数据/复权/费用/可成交性/样本区间/估算字段）
三、主结论（对照全市场：n / T+N 均值 / 超额 / 胜率 / 年度为正数）
四、五道检验逐节结果
五、逐项裁决：哪几条站得住（方向对）/ 哪几条方向反了 / 哪几条零信息量
六、处置：不接入 / 待样本外复验 / 接入（附复验方案）
```

## 判定线（建议）

| 结论 | 条件 |
|---|---|
| **不接入** | 市场中性超额 ≤ 0，或扣成本后 ≤ 0，或年度为正 < 一半，或叠加环境后跑不赢同日全市场 |
| **观察项（不建议接入）** | 均值正但**中位 ≈ 0 或跑赢比例 < 50%**（右偏，靠少数极端样本） |
| **待样本外复验** | 事后发现、跨年度一致为正、但未做时间切分盲测 |
| **可接入** | 样本外复验通过 + 扣成本仍正 + **中位/跑赢比例不透支** + 与既有信号不重复计分 + 可成交 |

## ⚠️ 反之：**否决类规则**（风控过滤器）的验收口径是反的

上面整张判定线针对的是**选股/进攻类规则**（"它能不能选出涨的"）。若被核验的对象是
**一票否决 / 硬排除 / 风控闸门**（如停牌核查红线、退市风险、异常波动），
**不要套上面的判定线**——那会把正确的规则删掉：

1. **均值不是它的目标函数。** 实测（2026-09-11 停牌红线）：红线组前瞻超额
   **−0.080%（t=−0.20，不显著）**、全池等权剔除红线仅 **+0.0016pp/日（t=+0.475）**、
   最强 5 只代理剔除后累计收益还变好但**最大回撤 −21.6%→−28.6% 恶化**。
   只看均值 ⇒ 结论是"删掉它"。**但尾险在均值与 t 值里看不见。**
2. **判据换成「收益结构不对称性 + 不可交易性」**：上行有顶（涨停）、下行无底
   （连续跌停且无法止损）、极端情形下**连申报撤单都做不到**（停牌）⇒ 期望结构为负，
   属于**制度约束**而非统计效应，应按制度排除，**不要求统计显著**。
3. **因此：若规则命中后仍可能被选中，就不能降级为"扣分"** —— 要么硬排除，要么不动。
4. **仍要做实证**，但用途变了：不是"决定删不删"，而是
   ①确认规则**不稀有**（触发频率别是 0.01%，否则调不调无所谓）；
   ②找出**真正稳健的部分**（该例：`dev10∈[50,80)` 分年度 10/11 年，是全表最稳信号）；
   ③确认**哪一部分方向站不住**（该例：连板扣分在长样本 0~2/10 年 ⇒ 其数值只能算"经验刻度"，
   不代表已找到最优值）。**结论写法要区分"已核实该不该排"与"未证明最优刻度"。**
5. **必须双口径**（对进攻类同样重要）：**当日收盘封板的票买不到** ⇒ 除
   `T 日收盘 → T+h 收盘`（不可成交，对涨停组**系统性高估**）外，必须并列
   `T+1 开盘 → T+h 收盘`（可成交）。**该例中这一条直接翻转了连板组结论**：
   收盘口径 boards 1→≥6 超额单调递增（t 最高 +19.9）看似"连板该加分"，
   换成 T+1 开盘口径 boards 1~5 **全部转负** ⇒ 连板溢价是「收盘价幻觉」。
   ⚠️ 复权折算：只有复权收盘时，复权 T+1 开盘 = `open × (close_adj / close)`（同日折算）。

## 核验之后：准入—监控—退役（别停在"测过了"）

核验器只回答"这条规则在这段样本上成不成立"。**测完还要挂进生命周期**，否则结论会停在文档里：

| 环节 | 动作 | 本项目承载 |
|---|---|---|
| **准入** | 三级态：候选假设（不得带权重/进推送/入代码）→ 观察项（可展示不可自动执行）→ 战术（过上面判定线） | `kb/04-decisions.md` **KB-DEC-019** |
| **登记** | 记 定义 / 所需数据 / 验证状态 / **样本环境** / 失效判据 / 处置 | 策略级登记册（待建，总账 P1-37） |
| **监控** | 滚动胜率跌破历史分位 或 收益 CUSUM 下漂 → 标记「待评估」 | `picks/signal_health.py`（现有，组合级；按策略键聚合待泛化） |
| **退役** | 连续失效达阈值 → **清除 / 归档 / 改造**，留证据链；**否决必须标样本边界**以便翻案 | 处置台账（待建，P1-39） |

**反固化（KB-DEC-019，与核验直接相关）**：入体系必须写成**可跨题材复现的谓词**
（`量比 = 当日量 / 前 N 日均量(不含当日)`），**不得写成"XX 题材会涨"**；
具体题材/个股名只能出现在**映射索引**（供检索）与**示例库**（标 `📎`），
且其中的排序/强度/"更优"**不得固化**（判据：「词→类目」是索引可枚举，「类目→标的强弱」是结论须验证）。

## 样本外盲测协议（模板）

`scripts/verify_candidate_b_oos.py` 可直接照搬：
① 训练段按参数网格选规则（并列 max-t 与 max-效应量两种准则）；
② **冻结**后测试段只看一次；③ 主指标 = 同日市场中性超额；④ 扣 25/35bps 往返成本；
⑤ 可成交性（疑似涨停比例）；⑥ 结构（流通市值分档、次新、**同市值段中性化** —— 排除
"只是小市值 beta"）；⑦ 分年度；⑧ 方向一致性（网格里训练为正的组，测试段还有多少为正）
—— 这一条比单点成绩更能说明"方向是否稳健"。

# 报告交付完整性核验（判据要能变红，且不许自己造缺口）

## 0. 何时用 / 核心风险

适用：交付的产物是**派生关系**（`源 → 渲染`、`旧 → 新`、`文档声称 → 代码实际`）。

**核心风险不是"没检查"，而是"检查本身在骗你"。** 一次性比对脚本是**为这一次结论专门写的**，
写它的人和下结论的人是同一个 ⇒ **天然缺少他者复核**。它一旦失真，会**主动诱发对正确代码的错误修正**
（实例：曾据失真脚本判定「渲染器把裸 `<` 当标签吞字、丢失 2 处」，**已准备去"修"一个本来正确的渲染器**）。

> **自造判据 = 自造的假阴性。** 与「shell grep 静默返空」（KB-ENG-04）同族，但更隐蔽一层。

## 1. 三条判据（本项目已固化为工具，不要再手写脚本）

```bash
python3 scripts/reports/md-report-html.py  <in.md> [out.html]   # 渲染（md → 单文件 HTML）
python3 scripts/reports/md-html-parity.py  <in.md> [out.html]   # 核验（exit 1 = 有差异）
```

| # | 判据 | 内容 | 为什么不能省 |
|---|---|---|---|
| ① | **逐条目文本命中** | md 的每个**正文行 / 表格单元格**归一化后，须在 html 可见文本中**完整**找到 | 只数结构测不到**单元格内部**的内容 |
| ② | **结构计数相等** | `<table>` = md 对齐行数 · `<li>` = md 列表项数 · `<h1..h4>` = md 同级别标题数 | 整块被吞时①会给出一串未命中，②给出一眼可读的差值 |
| ③ | **时间戳新鲜** | `.md` 的 mtime **不晚于** `.html` | 防「md 改了没重渲染」⇒ HTML 静默停在旧版 |

失败时工具会打印**第一个断裂点**（保留前缀 / 断裂片段 / md 原文），据此定位比看总条数快得多。

## 2. 判据必须能变红（否则等于没写）

**新写/改动任何核验工具，必须做注入自证**——删掉一处真实内容，看它是否**精确**报出那一处。

本项目已验的三组（可复现）：

| 注入 | 预期 | 实测 |
|---|---|---|
| A 删掉 HTML 中某半句（含 `&lt;` 转义片段） | ①精确报 1 处、断裂点吻合 | 精确报该行，断裂点一致 ✅ |
| B 破坏 `<table>` 计数（删块 + 删 1 个开标签） | ②计数不等 | `table 37=35` 判红 ✅ |
| C `touch` 使 md 新于 html | ③判红 | ❌ ✅ |

> 顺手产出的一条硬证据：注入脚本里写 `assert "均 &lt; 24h …" in html` **通过**
> ⇒ 直接证明渲染器**确实做了转义**，比读代码更硬。

## 3. ⚠️ 误报撤回纪律：三种「判据失真」形态

| 形态 | 机制 | 实例 |
|---|---|---|
| **跨格式误用解析器** | 在 **md 侧**做 HTML 去标签 `strip('<[^>]*>')`——**md 是纯文本，`<` 是内容**，一次 strip 吃到下一个 `>` 的大段正文 ⇒ **md 侧凭空变短** ⇒ 反被读成「html 缺失」 | 「丢失 2 处」的来源 |
| **归一化顺手多删** | 把**字面量**当标记删掉：`*`（`NEXT_PUBLIC_*` / `tests/*.py` / `12 * 3600` / `is_*`）、`\|`（`grep "\|"`）、`\`（`"\|err\|"`） | 修正版仍报 **16 处**假缺口 |
| **不能变红** | 判据恒真（覆盖面错 / 断言写宽），注入后仍全绿 | 见 KB-ENG-65 / 72 |

**硬纪律**：
1. **被比对象是什么格式，就用该格式的解析器**——md 侧**不得**去 HTML 标签；html 侧须**先 `unescape` 再比**。
2. **归一化只去真正的标记**（成对 `**`、反引号、行首列表/标题/引用标记、链接语法），**字面量一律原样保留**。宁可多留噪声，不可多删内容。
3. **「某处丢失/不存在」的结论，在据此动手改之前必须换一种独立手段复核一次**。方向读反时，**变短的往往是自己造的那一侧**。
4. 结论反转时，**如实撤回并记录根因**（含入 KB），不要静默改口——否则下一个人会再踩一次。

## 4. 收尾顺序（单向派生）

1. **先改完 md 的全部内容**（报告正文、小节、数字回填）；
2. **最后一步才渲染** `md → html`（本项目已有「md 晚于 html ⇒ HTML 停在旧版」的实际案例）；
3. 跑 `md-html-parity.py`，三项全过才算交付；
4. 若核验工具本身被改过，**重跑第 2 节的三组注入**。

# 执行交接与审核

先读 AGENTS.md 与 docs/collaboration-workflow.md。网页ChatGPT统筹计划和逐轮审核；Codex是执行侧，不自批、不自行降低验收。任务状态只在总账索引的阶段条目。

1. Codex只回填实际执行状态、证据、阻塞和变更建议；任务增删重排/重大方案/验收变更由网页ChatGPT裁决。完成实现但尚未审核/CI时保持待交付，不写最终完成。
2. 生成脱敏审核包：任务/切片、方案哈希、repo/base/head、文件差异、实际命令结果/环境、风险与偏差、未验项、恢复及证据哈希；不传密钥/私人数据或模型内部推理。
3. 更新 handoff 当前现场，保留前任/接手者、日期、来源任务、继承HEAD与各自贡献。证据持久化到原项目忽略的 artifacts，不能只存临时worktree；原会话不可伪造改写。
4. Codex提交审核包后停止，请网页ChatGPT实际读diff/消费者/证据。工具不可用时由用户发送审核短模板；不能把文件写成或PR创建视为审核已启动。
5. 审核侧输出明确APPROVED/CHANGES_REQUESTED/BLOCKED，绑定任务/计划/base/head/证据并给允许动作。回执放候选HEAD之外，阶段只存索引；Codex不得代写批准或接受无来源的“通过”。
6. 网页通过也不替代完整CI；发布按 AGENTS §6.5 和 release_check.py 准确SHA/base/latest attempt 全部必需job。新提交、计划变化或过期使旧放行失效。下一轮另须明确派工。
7. 编号不复用，退出/合并须网页裁定、处置依据与有效去向；完成只留必要证据，旧号迁移表保持固定来源。不恢复多表同步或复制全部状态。
8. 文档修改同样运行 doc-health 与相关回归；新增路径准确暂存，干净检出复验。审核检查器未实现/无独立来源时保留人工确认，不能声称平台已强制。

预算、登录、工具确认与权限阻塞如实报告。当前Codex额度不足不试发模型请求；不要用Stop hook或等待循环重复花额度。自动化仅搬运与验证，不自行决定下一轮、不绕用户控制。

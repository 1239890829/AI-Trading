# 美股财报只读核验

本流程适配Jakeschincariol/trader-skill的完整trader-analyst工作流；[来源和取舍](references/adoption.md)。现有行情来源缺口不能由SEC财报补成实时价格。当前项目没有准入SEC自动抓取器，不运行上游broker或写trader配置。

1. **锁定对象与知识截止**：从正式ticker/CIK/股类消歧，绑定财年、币种、报告期、filed时点与修订。只有明确获准的已有文件或读取工具才能继续；不要向SEC发送虚构User-Agent联系人。
2. **读取原报事实**：先companyfacts/submissions对应10-Q/10-K，再读当次业绩8-K的EX-99.1和必要原文页。没有XBRL最新期时明确滞后，不能用旧期代新期。
3. **按同口径比较**：收入、经营/净利润、稀释EPS及适用利润率逐季与上年同季比，TTM按覆盖完整四季计算；银行/保险不适用毛利率时留空，不填0。单位、会计口径和一次性项目保留。
4. **明确推导和冲突**：年报减前三季得到Q4须标推导，EPS差分不得冒充原报。修订值与当时版本并列；不同日期不可拼成虚假点时输入。
5. **读取解释再给短结论**：用财报/业绩新闻稿解释变化，逐项附原文件依据；不给无据形容词、估值买卖结论或预测胜率。
6. **保全与重读**：沿现有公司证据owner保存source/period/available_at/version/hash；只读结果不得进入A股选股或执行。没有适用抓取授权/联系人时保留明确未实施，不安装第二套SEC解析器。

完整输出是“本期变化、利润率、异常/推导/滞后、原文依据”；完整文件按需，不把13F迟报当当前仓位。非投资建议。

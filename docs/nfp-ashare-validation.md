# 非农意外差 → A 股指数适用性验证报告（2026-09-07）

> 背景：用户提供的美股非农三票策略（新增就业/时薪/失业率意外差投票，2022 年 12 次回测，
> +3.23% 但 t=1.03 不显著，作者结论为"适合做时间序列宏观因子/状态开关而非选股因子"）。
> 本报告在 A 股语境用 **10 年 × 116 期**样本检验其核心命题，决定是否接入本项目。
> 脚本：`/tmp/star-eval-20260907/nfp_ashare_test.py`（一次性验证，未入仓库）。

## 1. 方法

| 项 | 说明 |
|---|---|
| 事件源 | 金十数据（akshare `macro_usa_non_farm` + `macro_usa_unemployment_rate`），今值/预测值/前值三列齐 |
| 意外差 | 今值−预测值；**失业率取反**（低于预期=劳动市场意外强=正票），与美股策略"劳动市场强弱"语义对齐 |
| 标准化 | 意外差 ÷ 滚动 36 期 std（shift(1) 防未来函数），按符号投票（z>0→+1），score∈[-2,+2] |
| 反应窗口 | 非农周五盘后（北京 20:30/21:30）公布 → 反应日 = 发布日后第一个 A 股交易日（通常下周一） |
| 收益口径 | 跳空 = 反应日开盘/发布日收盘−1；日内 = 收/开−1；全日 = 收/昨收−1；振幅 = (高−低)/昨收 |
| 指数 | 上证指数 sh000001、深证A指 sz399107（新浪日K，2015-12~2026-09） |
| 样本 | 2016-01 ~ 2025-08 共 116 期（score 分布：0×63、±2×32、±1×21），配对 228 行 |
| 统计 | 手工 Welch t（无 scipy），|t|≥2 视为显著 |

**已知局限（如实声明）**：
1. **两票版**——akshare/金十封装无"平均时薪"指标（attr_id 1~99 试探无命中），第三票缺失。
   就业+失业率是同一次发布的核心维度，命题检验不受根本影响，但与原策略非严格复现。
2. 金十数据存在初值/修正重复行，已按发布日去重保留首行。
3. 预测值是发布前市场一致预期（金十口径），与作者原回测的预期源可能不同。

## 2. 结果

### H1 方向性：不成立（无稳定 alpha）

| 分组 | 上证（n=114） | 深证A指（n=114） |
|---|---|---|
| score>0（意外强） | −0.03%，胜率 54%，t=−0.10 | −0.28%，胜率 54%，t=−0.66 |
| score<0（意外弱） | +0.33%，胜率 72%，t=+1.43 | +0.63%，胜率 78%，t=+1.78 |
| score=0 | −0.09%，胜率 62%，t=−0.41 | −0.02%，胜率 61%，t=−0.08 |

- 最好的组合（深A score<0，t=1.78，n=18）仍不达显著。
- **方向与美股原策略相反**：A 股上"劳动市场意外弱"次日反而偏强——传导链是「弱数据→宽松预期→风险偏好回升」，而非「经济好→买」。这印证了原策略作者"方向取决于宏观环境"的判断：该信号无条件使用不可行。

### H2 波动率开关：弱证据，方向正确但不显著

| 指标（\|score\|=2 n=32 vs 其余 n=82，绝对值均值） | 上证 | 深证A指 |
|---|---|---|
| 跳空 | 0.81% vs 0.40%（t=+1.25） | 1.01% vs 0.46%（t=+1.35） |
| 全日 | 1.26% vs 0.99%（t=+1.07） | 1.72% vs 1.37%（t=+0.88） |
| 振幅 | 1.67% vs 1.27%（t=+1.35） | 2.14% vs 1.60%（t=+1.49） |

- 三项全部方向一致（意外大→波动大），振幅差 +24~33%，但 Welch t 均在 0.9~1.5，不达 2。
- **结论：可作参考信号，不足以支撑硬性仓位规则**（regime/gate 硬接入为时过早）。

### H3 跳空-日内路径：与美股发现不同

- 跳空与日内反向比例仅 40~42%（<50%），且两者均值都 ≈0。
- **A 股对非农不存在美股那种"开盘跳空+日内修复"路径**——非农公布在 A 股收盘后隔一个周末，
  反应日开盘时信息已被周末对冲/消化，A 股整体对非农钝化。

## 3. 落地决策

| 用法 | 决策 | 依据 |
|---|---|---|
| 方向信号（多/空） | ✗ 不接入 | t≤1.78 不显著，且方向与美股相反 |
| 硬性仓位规则（regime/gate 维度） | ✗ 暂不接入 | 波动差 t~1.3-1.5 不显著；等时薪三票完整版+更长样本再议 |
| 日历提醒类标注 | ✓ 可做（P2 级） | 零风险：盘前简报/预警在非农日标注"明晨非农，周一波动或放大"，符合显式标注纪律 |
| 选股因子 | ✗（与原作者结论一致） | 事件级因子不适用截面 |

**一句话结论**：原策略在 A 股的唯一残余价值是"事件波动提示"，连波动率开关的硬规则都证据不足；
不接入方向信号。时薪数据若后续找到可靠源（金十网页端人工确认 attr_id 或其他源），可补三票复验一次。

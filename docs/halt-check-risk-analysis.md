# 停牌核查 / 异动风险：对短线情绪的传导与选股条件设计

> 日期：2026-09-02（收盘后）　数据：本机 8000 实例实时 API + 日 K 实测
> 性质：规则化研究与系统改造方案，不构成投资建议

---

## 0. 结论先行

**应该加入选股条件，但不能做成"有异动就排除"的一刀切。**

正确形态是**三档：红线硬排除 / 黄线降权 / 仓位约束**。理由是这类风险的收益结构严重不对称——
向上最多一个涨停（+10%），向下是连续跌停叠加**停牌期间无法申报、无法撤单**（止损纪律在停牌期
完全失效），期望值为负，且本系统当前对该维度**零覆盖**（第 3 节有今天的实证）。

用户原表述需要修正一处关键口径：**"可能被停牌核查"在监管上是两个层级**——普通异常波动只发公告
不停牌，严重异常波动才强制停牌核查。今天触发普通异动的票有几十只，全规避就没得做了；真正要
规避的是**逼近严重异常波动阈值**的那一小撮（今天全市场大约个位数到十几只）。

## 1. 监管规则基线（2026 年现行，可核验阈值）

### 1.1 普通异常波动 —— 触发必发公告，**不停牌**

| 板块 | 连续 3 个交易日收盘价涨跌幅偏离值累计 | 备注 |
|---|---|---|
| 沪深主板 | **±20%** | ST / *ST 为 **±12%** |
| 创业板 / 科创板 | **±30%** | |
| 北交所 | ±40% | |

量能型（需同时满足）：连续 3 日日均换手率 ÷ 前 5 日均值 **≥30 倍**，且 3 日累计换手率 **≥20%**。

### 1.2 严重异常波动 —— **强制停牌核查**（满足任一）

| 情形 | 主板 | 创业板 / 科创板 |
|---|---|---|
| 10 日内同向普通异动次数 | 4 次 | 3 次 |
| 10 日累计偏离值 | **≥ +100%**（或 ≤ −50%） | ≥ +100%（或 ≤ −50%） |
| 30 日累计偏离值 | ≥ +200%（或 ≤ −70%） | ≥ +200%（或 ≤ −70%） |

- **偏离值 = 个股区间涨跌幅 − 对应基准指数区间涨跌幅**
  （沪市→上证指数/上证A指；深主板→深证A指；创业板→创业板综指；科创板→上证科创板 50）
- **停牌核查时长**：首次 1–5 个交易日，二次及以上 5–10 个交易日
- **停牌期间全天不可申报、不可撤单**（连续停牌），复牌时对已接受申报集合竞价撮合
- 异常波动指标自交易所公布的**次一交易日或复牌之日起重新计算**

> 来源：上海证券交易所交易规则（2026 年修订）第 6.10 / 6.11 条（官方文本）；深交所规则同源。
> 今日实例印证：深中华A 9/2 晚公告"连续 10 个交易日收盘价格涨幅偏离值累计达 100%"，
> 并提示"如进一步异常上涨，公司可能申请停牌核查"。

## 2. 传导机制：从一只票被关，到全市场降温

### L1 个股层 —— 风险不可控（最致命的一环）
停牌核查 = **资金锁死**。1–5 个交易日内不能卖、不能撤单，所有止损纪律失效；复牌后把
停牌期间积累的抛压一次性释放，通常是连续跌停。这意味着：**你为这只票设的止损位，在它最需要
的时候不起作用**。这不只是选股问题，是风控漏洞（见第 6 节补丁建议）。

### L2 题材层 —— 龙头缺位，两种分化
龙头被关后题材失去"带头大哥"，结果是二选一：

- **卡位成功**：次龙头接棒，资金换手接力，题材续命甚至更集中；
- **卡位失败**：无票接力，跟风股集体补跌，题材直接结束。

决定因素是**题材所处阶段**：发酵/启动期卡位概率高；高潮期与退潮期卡位几乎必败。
→ 所以"同板块龙头被关"这个信号，**必须和题材阶段一起看才有判断价值**。

### L3 连板梯队层 —— 天花板效应
最高板被关，等于市场当日的**空间高度预期被打断**。资金不敢接力中高位板（怕自己也进小黑屋），
被迫高低切换涌向低位首板。结果：连板高度压缩，3 板以上存活率骤降。
今日数据就是活样本：最高板由昨日 **7 板** 断到 **4 板**，高位存活率（≥3 板）仅 **2/9 = 22%**。

### L4 整体情绪层 —— 赚钱效应崩塌
连板高度压缩 → 打板收益率下降 → 封板率下降、炸板率上升 → 亏钱效应扩散 → 情绪由高潮切退潮。
今日：涨停 49 家、炸板率 23.4%、1 进 2 晋级率 11.3%、昨涨停今日中位 −2.6%、跌停 10 家，
系统判定**退潮，温度 35.7，置信度高**——与上述传导链完全吻合。

### ⚠️ 两条反向效应（不可作为主策略依据，但要知道）
1. **锁住抛压**：龙头被关期间没有龙头砸盘，跟风股有时反而多走一两天；
2. **"监管认证"**：个别票被特停后被市场解读为"官方认证真龙"，复牌一字。

两者都是少数情形。**在退潮期，反向效应的胜率显著低于正向传导。**

### 3.1 连板高度：两个口径差 1 板的原因（不是 bug）

实测发现新赛股份按日 K 是 **5 连板**，但系统情绪模块报"最高 4 板"、选股把它判成
"非涨停"。拉原始数据核对后定位：

```
东财 push2ex 炸板池 20260902：600540 新赛股份
  zbc=6（当日炸板 6 次）  zttj={days:5, ct:4}（5 天 4 板）
  p=6730  ztp=6730（收盘价确实等于涨停价）  hs=37.5%（换手率）
```

**根因**：东财涨停池按"封板质量"收录，盘中反复炸板的票会被剔出涨停池、不计 lbc；
而交易所算偏离值**只看收盘价的涨跌幅**——新赛收盘 6.73 恰好等于涨停价，照常计入。

所以这不是口径不统一，而是**两个口径服务两个目的**：

| 口径 | 定义 | 适用 |
|---|---|---|
| 收盘涨停连续天数 | 只看收盘涨幅 ≥ 涨限（容差 0.6pct 应对四舍五入） | **停牌/异动风险**（监管口径） |
| 涨停池 lbc | 封板质量加权，炸板多的不计 | 梯队地位 / 情绪强度 |

**结论：不需要统一，但必须各归各用。** `app/picks/halt_risk.py` 一律用前者，
梯队与情绪模块继续用 lbc。混用会让 5 连板的新赛在风控维度"消失"。

## 4. 逻辑补全：你遗漏的风险因素

你提到了**停牌核查**与**股价异动**，以下是同一风险谱系里被遗漏、且实际杀伤力往往更大的部分：

| # | 遗漏因素 | 为什么比异动更硬 |
|---|---|---|
| 1 | **证监会立案调查** | 今日新赛股份、捷荣技术均在此列。坐实可能直接触发退市风险警示，不是回调级别风险 |
| 2 | **问询函 / 关注函** | 交易所直接质疑题材真实性，未回复期间题材逻辑悬空 |
| 3 | **澄清 / 风险提示公告** | 公司自己否认题材关联 = 题材逻辑当场证伪。今日深中华A 澄清"无 AI 业务"、恒宝股份澄清"数字人民币收入占比不足 5%" |
| 4 | **限售解禁 / 大股东减持** | 连板高位遇上减持，与异动叠加时是"双杀" |
| 5 | **业绩预告变脸 / 商誉减值** | 纯题材炒作票常见"炒作—业绩打脸"路径 |
| 6 | **ST / 退市风险警示** | 涨跌停变 5%，异动阈值降到 ±12%，被关概率更高 |
| 7 | **游资席位被盯** | 知名席位上榜后交易所重点监控其账户 → 该席位后续不敢接力 → **这只票的接力资金直接断档**（这是"资金接力意愿"最隐蔽的杀手） |
| 8 | **监管周期（择时因子）** | 证监会 2026 年系统工作会议强调"严肃查处过度炒作"，高压期特停频率系统性上升；重要会议、长假前更严 |
| 9 | **一字板零换手** | 无换手的连板筹码断层，复牌补跌更狠（注意：官方计算偏离值时剔除一字零换手交易日） |
| 10 | **板块联动** | 同板块已有一只被关，**其余跟风票风险不降反升**——资金集中涌向剩余标的，反而更容易触发阈值 |
| 11 | **标的类型不适用** | 可转债、ETF 不适用上述异动/停牌规则，别把规则套错对象 |

### 对你表述的三处修正

1. **"停牌核查"要拆成两层**（普通异动 vs 严重异常波动），否则会过度规避——今天触发普通异动
   的有 20+ 家，全排除等于放弃整个连板战场。
2. **"涨幅"要换成"偏离值"**：必须减去基准指数。指数大涨时，个股涨 30% 也可能不触发异动。
3. **"成交量异常"应改为"换手率异常"**：官方量能指标是换手率（30 倍 + 20%），不是成交量绝对值，
   且需要流通股本数据——这一点直接决定了规则能否落地（见第 6 节）。

## 5. 规则设计（三档，可直接编码）

### 🔴 红线：硬排除（veto）

| 编号 | 条件 | 理由 |
|---|---|---|
| R1 | 10 日累计偏离值 **≥ +80%** | 距 100% 红线仅剩约 2 个板，留缓冲 |
| R2 | 已触发严重异常波动：10 日偏离 ≥100% / 30 日 ≥200% / 10 日内同向异动次数 ≥ 阈值−1 | 直接进停牌区 |
| R3 | 当前停牌，或公司已公告"可能申请停牌核查" | 明确信号 |
| R4 | 处于证监会立案调查期 | 非回调级风险 |
| R5 | ST / *ST / 退市风险警示 | 阈值更低、风险更高 |

### 🟡 黄线：降权（不排除，扣分并标注）

| 编号 | 条件 | 扣分（建议初值，待回测校准） |
|---|---|---|
| Y1 | 3 日累计偏离值 ≥ +20%（已触发普通异动） | −6，标注「已触发异动公告」 |
| Y2 | 连板高度 ≥ 4 板 | 4 板 −5 / 5 板 −10 / 6 板及以上 −15 |
| Y3 | 10 日累计偏离值 50%~80% | −8 |
| Y4 | 近 5 日出现风险提示 / 澄清 / 异常波动公告 | −6 |
| Y5 | 近 20 日有解禁或减持公告 | −4 |

### 💰 仓位约束（不扣分，直接限仓）

| 编号 | 规则 |
|---|---|
| P1 | 连板 ≥ 3 板 → 单票仓位上限减半 |
| P2 | 命中 Y1 或 Y3 → 单票仓位上限 1/3 |
| P3 | 组合内 ≥3 板的票合计不超过 2 只（避免整组被一锅端） |

### 风控补丁（独立于选股，必须做）

**持仓股触发停牌 → 复牌首日无条件减仓 / 清仓（纪律预置）**。理由是停牌期间止损纪律失效，
唯一能做的是把"复牌即处置"写进纪律，而不是等复牌后临场判断。

**实现期踩到并修掉的三个坑**（都会造成**静默失效**——不报错、但规则等于没上）：

1. **`change_pct` 字段不可依赖**：腾讯源当日 bar 的 `change_pct` 为 None，且熔断切源后
   时有时无。只认该字段 → 连板数恒为 0、全市场"零风险"。改为缺失时用收盘价序列自算。
2. **沪市指数代码要带 `sh` 前缀**：`000001` 在行情源里是平安银行（收盘 11.91）。
   用它当基准，沪市标的偏离值全错且看不出来。
3. **指数日 K 必须预取复用**：24 只候选各拉一次指数 = 请求量翻 5 倍，实测触发腾讯
   熔断（502「熔断冷却中 19s」）。改为流水线开头一次取完，按板块分派。

## 1. 布局 v3（工作台详情区，对标终端范式）

```text
┌─ 紧凑行情条（已有）──────────────────────────────────────────┐
├──────────────────────────────────────┬──────────────────────┤
│ 图表区页签: K线 | 分时 | 资金图        │ 右列页签: 盘口 ↔ 逐笔 │
│ · K线: MA/MACD/KDJ 副图可选            │ · 五档盘口（默认）     │
│ · 图上标记: 🏷龙虎榜日 ▲B持仓买 ▼S持仓卖 │ · 逐笔成交            │
│   （技术信号改名，不再冒充 BS）          │                      │
├──────────────────────────────────────┴──────────────────────┤
│ 底部资讯 tabs: 新闻 | 公告 | 财务 | 资金明细 | 龙虎榜明细 | 研报  │
│ （每个 tab 内容独立滚动，表格只滚表格）                          │
└─────────────────────────────────────────────────────────────┘
```

- 上部页签只留**图表类**（K线/分时/资金图）；财务、龙虎榜、新闻、公告全部下沉底部资讯 tabs。
- 盘口与逐笔在右列做 tab 切换，盘口为默认（同花顺范式）。
- 底部固定资金明细条**撤销**，其表格并入底部"资金明细"tab；资金页签只留柱状图。
- 消灭双重滚动条原则不变：容器 overflow-hidden，内容自滚。

## 3. 持仓与自选（两个不同概念，模型分立）

- **自选 = 观察列表**：SQLite `watchlist` 增加 `group_name` 字段；左栏顶部分组标签条（默认组/自建组），支持增删改组；分组数据同 pin 到工作台。
- **持仓 = 模拟账户头寸**：Phase 6 模拟交易成交后自动生成 `positions`（代码/成本/数量/可用(T+1)/盈亏）；左栏增加"持仓"组（只读映射），点击持仓股右栏直接显示成本线与浮动盈亏。**Phase 6 前不造假数据**。
- 左栏结构：`[全部|分组1|分组2|…|持仓]` 标签行 + 列表。

# W07 模块与产品去重

> 定位：最终融合方案的阶段任务文档；由 [总账 §6.0](../retro-and-gaps.md#60-阶段索引) 唯一索引。任务状态只在本页更新。
> 当前为DESIGN_ONLY：本轮只复核和完善理论/计划/文档。下面的实施步骤不是新派工；规划交付、用户确认与代码实施/发布分别授权。

- **阶段目标**：让全产品及大小动作有明确用途、信息层次和上下游；仅做有用户/维护收益的聚合、后移与退出。
- **依赖边界**：按实际消费者判断输入/接口/发布条件，不要求关联阶段整体清零，也不把猎场新接口作为全站所有小功能的前置。
- **排期**：产品主路径P1；额外拆分/聚合P2且有证据才实施；按风险、输入可用性和跨模块收益选切片，不机械顺序开发。

## IMP-050

**猎场及全站用户视图与后台职责分离**

- **状态**：待条件
- **优先级**：P1
- **依赖**：无
- **方案依据**：用户对全模块、小功能、后台业务/前台结果、原UI风格与规划范围的累计要求；product-closure-design、hunting-decision-design、feature-closure-audit及U40。
- **范围**：工作台/搜索/自选、盘面/市场、猎场/个股详情、通知、模拟/手工记账、助手、复盘与公共交互；包括原hunting/page、agent/page、PickCard、nav-bar、ReviewTab和相关API消费，不仅猎场。保留现有主题/字号/组件体系。
- **验收**：每个已识别动作能说明用途、输入/对象、消费者、成功/空/错误/取消反馈与恢复；主屏能回答为何/等什么/何时失效。配置/进化/调试告警后移，必要风险结果保留；直接URL/API鉴权不因隐藏菜单减弱。亮暗/小屏/键盘、真实Canvas、旧深链与源时间分别验证，不靠打开页面产生核心业务计算。
- **证据**：26a0c44/9d439c5所读猎场有生成组合、简报和手动单拍，agent有内部标签。对应设计与细功能来源表已归三专题；后续复盘回调隔离反例记录见下。上述均为历史证据，本次未改UI或运行组件。
- **产品确认边界**：总流程与信息架构供用户确认；当前无实施派工。用户另行要求实施后，网页按真实需求、输入、证据和风险指定切片，Codex不据旧下一步或一句“审核完了”自行启动。
- **下一步**：满足条件为用户明确进入实施，并取得该切片的范围/对象/验收/恢复依据。新猎场界面先用明确夹具验证，再接IMP-049合格契约；其余功能不必等猎场整体完成，但同样不得无派工实施。
- **实施步骤**：①核原用户路径、每个动作及接口副作用；②分业务读写与用户/运营权限；③在原组件内实现确认的信息层次；④先让受控后台承接管理操作，再退出普通前台入口；⑤按小动作和相邻消费者验证正常/失败/取消/恢复；⑥实源与用户反馈验证简化收益。一个切片只改变一个主要行为链。
- **恢复**：旧深链保留准确对象的兼容落点，切换前后不抹历史/用户数据；呈现可回退，但不能重新开放已封堵的代码执行/自动晋级权限。后端契约变化须版本对照，不把旧批准套到新代码。
- **条件化依赖**：取消原依赖栏对IMP-049的全任务锁定。只有消费新机会结构的猎场卡片/详情才以IMP-049相应接口为前置；搜索/日期/错误反馈等依据其自己的对象和API；运营迁出依据已有后台承接及鉴权。每片先列真实输入条件，不能将“无整体依赖”解释成没有安全或发布前置。
- **细粒度范围**：feature-closure-audit逐项保存来源及已读/未验边界，product-closure-design §5/§5.1定义小动作目标契约。新增入口/按钮/筛选/计数/提示/后台动作不得被父模块完成覆盖；不为每个按钮新增平行任务编号。
- **历史复盘回调证据**：源9d439c5、review-tab.tsx blob 65b4777dd8d1eb7bd4854f06abfcdeb282708f70。此前在独立Node容器对原toggle只去一处TS注解并注入Promise/setter：控制组单次A成功一致；先A后B且B先成功，迟到A成功会显示B标题/A正文，迟到A失败会清掉B正文。是同一请求身份缺陷的两种反例，不是生产事故或真实React验收。
- **历史反例的未来验证**：在获准实施片用真实组件覆盖初始化、focusDate、toggle、reloadAfterDispose、关闭/卸载/重开；成功和失败都绑定当前对象/代次，显式区分加载/有效空/缺失/错误与陈旧缓存。公共useResource只保护其返回快照，回调自设状态仍须逐消费者检查。
- **非猎场补充契约**：复盘采纳率不作效果指标，“已实施/确认/回退”管理动作迁后台并留证；六位数字先核实体再链接证券。助手本地历史缓存不等于后台任务事实，不能借后台化无授权上传私人聊天。搜索失败、云图自选同步、空池日期、资金历史切换、记账时区和前端费率均按原任务验收。
- **本次变更边界**：只校正任务范围/依赖与历史说明，状态仍待条件；不追加模型/组件/交易试验，不把旧3851/151结果写成本轮新测。

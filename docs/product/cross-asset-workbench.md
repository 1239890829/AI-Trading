# 统一资产工作台

## 1. 授权、入口与职责

2026-10-30用户批准前轮Decisions、金融Skills、国内QDII/联接优先及美股只读方案，并明确工作台合一。本合同取代前轮“基金另设业务入口”的导航建议；`/workbench`仍是唯一工作台，按`asset=cn_equity|fund|us_equity`切换对象能力。原无asset链接仍读A股。`mode=watch|positions`保留原自选/持有语义；基金链接携来源完整份额代码，不猜市场后缀。

合一的是导航与组件外壳。基金净值/披露、A股行情、美股只读feed分别拥有事实、时钟、缓存和权限；基金手工份额/成本不进入paper/real A股账户。美股与基金不进入A股选股、预警轮询、模拟撮合或券商。旧研究、旧选择和历史来源不迁写。

## 2. 数据身份与时点

- 基金身份为`fund:{market}:{source_symbol_without_suffix}:{currency}`；目录返回的source_symbol、asset_type、ticker、exchange、currency必须一致。根对象仅本轮获准场外`.OF`份额；联接穿透可读取其披露指向的场内目标基金。
- 美股只读身份为`us_equity:US:{source_symbol}:USD`，保留来源确认的OQ/N/AM及类股，如`BRK.B.N`；GP/GP-ETF明确区分stock/etf。搜索候选仅有来源代码/名称，点选后由报价确认身份和USD，不凭名称构造记录或市场后缀。美股记录只供自选，不录份额/成本或接任何交易账户。
- 货币须来源明确，不从名称/后缀猜人民币。A/C和币种独立；同号A股仍由原股票接口处理，不合并存储或订阅。
- 官方NAV的nav_date、发布日期、持仓报告期/披露日/修改日、接收时刻独立。接口data.timestamp可能只是响应组装钟，不升级为NAV发布时间或市场报价钟。
- 基金核心读取沿原THS通道，公开产品说明、重仓参考及美股价格各标独立来源；相同事实不跨源改身份或借用钟。普通用户页面不携Key。代码许可不授予第三方数据再分发、公开展示或永久留存权；本机受控读者与未来公共部署许可分开，部署继续搁置。

## 3. 基金研究与持有记录

完整流程为身份→正式材料/净值/披露→费用/规则→穿透/重合→同类比较→有依据的建议/失效条件→保存版本与后续核验。具体助手工作流归`skills/qdii-fund-research/SKILL.md`，不是第二份任务账本。

基金增加同花顺原`meiguo`栏目候选，候选、自选与持有用紧凑视角选择复用同一左区。原子类切换只过滤已读源名单，原顺序去重、下拉递增显示，不当官方涨幅榜或推荐榜；点击单只才核完整身份并读详情。全名按完整代码引用独立额度名单，保留目录原名与各自证据，不覆盖旧记录。`classify`是份额提示，不能生成不存在的代码。

读取界面在同一右区切换净值、披露、费用、研究核对；使用原左右宽度和移动切换，不新增常驻占图顶栏或多滚动owner。净值曲线是已公布NAV而非交易价格；游标按估值日读数，范围切换不触发模型。原文和回执按需查看。

手工记录以instrument_id为键，份额/同币种总成本同时填写或同时清空，保存明确`manual_not_broker_verified`。首次expected_version=0、后续须当前版本；冲突409保留输入，不能盲覆盖。收益只使用同份额/币种的有效单位净值并标净值日，缺NAV不拿成本当现价。不同币种不相加。

联接穿透仅乘可得同报告期权重，保留路径和未知残余。一层可读范围不冒充全基金全集；部分披露的重合是下界，不把已知部分放大到100%。没有本人记录不编造组合仓位。

研究候选不等于已推荐。必须核正式投资范围、跟踪基准、美股/科技敞口、份额/费用、申赎与额度，再作透明同类对照；纳指100不等于纯科技，也不等于纳斯达克综合指数。QDII目录的`all`与`source_buyable`读者分别保留查询、接收钟和哈希，后者仅表示该次源方可购筛选返回，不能以未出现或额度0断言停售。明确null按文档解释源称无限额，缺字段仍未知；quota单位未给出、year是上游近一年原字符串，不猜元/百分比/年化或据此自排收益榜。源数据时点未知。`meiguo`实含全球、新兴市场、富时100产品，栏目及名称不证明纯美国/科技敞口。

已补公开F10的投资目标/范围/策略/基准，来源为华安基金时再读其官网的明确币种和申赎状态；管理人非空字段优先，空字段不覆盖已有事实，冲突保留。每字段带source/source_url，资料源钟未知则保留null。研究核对随实际字段更新，不再固定全项“缺失”；公开产品说明仍不等于监管文件、完整当前持仓或渠道资格已核，不能自动荐基或给不明总分。

当日估算不是官方净值。当前持仓、同口径境外行情、基准和估值汇率未满足时不提供整只基金的当日涨幅。新浪当前可读的上一季度前十大重仓参考独立显示源警告、源日/钟和两个原曲线口径，不选择其中一条冒充基金真值；缺点、陈旧或空集保持真实状态，整基金估算值仍为空。`fundgz`等失败候选不静默换成目标ETF价格。未来若引入基准代理或部分持仓贡献，须保留输入版本/源钟/覆盖，不虚构置信区间；实际NAV公布后对不可变估算核误差。人民币目标ETF价格不能代NAV或重复叠加汇率。

## 4. 美股只读的条件

共用工作台、搜索/自选和图表基础组件，不能把A股六位代码校验、手数、亿元、涨跌停、北京日历和前复权名称直接套到美股。按能力分别开放，不因尚缺全时段来源而拒绝已核标准报价和日K；也不因一个标准报价成功就宣称盘前、盘后、夜盘和分钟全通。

| 能力 | 当前合同 | 真实限制 |
|---|---|---|
| 搜索与自选 | 腾讯原候选；点选报价确认完整canonical、USD与stock/etf后保存 | source-only搜索不构造完整资产；旧记录不回写改名；不保存美股交易仓位 |
| 标准报价 | 腾讯原报价、昨常规收盘及原涨跌字段；量以股、额以美元保留 | `feed_delay_seconds=null`、`realtime_verified=false`；不称全市场实时。16:04:51等已核窗外报价为`session_unverified`，不叫盘后 |
| 120根日K | 同一canonical的原始`day`，`price_basis=none` | 不借A股前复权、分钟或假曲线；日K局部失败不抹去有效报价 |
| 分钟、盘前与盘后 | 分别返回不可用原因 | 本次分钟源没有有效源日/完整序列；不能把收盘哨点绘成分时 |
| 夜盘指示报价 | 可选Alpaca固定数据域读者，离线合同与一次真实账号读取已验 | 用户已确认保存Key，15:28 AAPL独立夜盘指示报价成功；不外推全标的/整日覆盖 |

源钟按`America/New_York`及该源日期的夏令时解释，接收钟独立；`clock_phase`只是纽约时钟窗口，节假日、半日市及实际开市状态未核，不能据本机时钟宣布已开市。已核常规收盘事实可带原日显示，不能当当前夜盘。

Alpaca[个人免费夜盘合同](https://docs.alpaca.markets/us/docs/245-trading-for-trading-api)允许`feed=overnight`实时指示性报价，成交延迟15分钟；本实现只取bid/ask，绝不生成last/mid或当可成交价。Basic 200请求/分钟是速率限制，未见累计用尽型次数上限；免费IEX不等全市场覆盖。Paper Only可用邮箱申请，不需要实盘券商开户；应用只允许`data.alpaca.markets`只读GET，不接账户、资产名单或订单。旧Paper页与新夜盘页的权限范围有差异，本轮Key后的AAPL最小实测已通过，其他标的/时段仍按本次响应核对。401/403停止该owner后续取源，不换feed探权限；缺Key、过窗、旧钟和授权未验各有独立状态。60秒是本地新鲜判据，不是供应商时延保证。

源的个人本机用途与公开再分发许可分开：Alpaca[条款](https://files.alpaca.markets/disclosures/library/TermsAndConditions.pdf)要求向他人提供用户应用前提前书面通知；Tiger现行协议限制未授权第三方工具取用及再发布，不接其公开页面抓取。新浪App有正式夜盘产品，但本轮没有取得不同的可用公开夜盘feed；旧hq403不重试。Finnhub未核得免费夜盘合同，报价文档不能替代覆盖证明。既有THS未证明覆盖美股/纳指100正式基准。取源与失败记录归[能力对比§23](../data/data-source-comparison.md#23-2026-10-30-基金同源读取与美股条件)。

## 5. Decisions与外部方法

Decisions只在已保存公司/事件证据上提供手动、固定选项的未验证关系研究；正式合同归[语义蓝图](../ai/semantic-decisions.md#2026-10-30-decisions具名研究与统一工作台)。不替代完整TradingAgents，不改变评分/通知/执行资格。行情刷新和切换不调用模型；失败保留原解释、真实错误和已知用量。

完整独立工作流分别由基金尽调、论点/催化剂跟踪、SEC财报核验Skill承接，许可与固定来源随目录。后两项是助手研究流程，未部署应用自动跟踪器或第二个SEC解析器；SEC自动读取尚缺真实联系人及源准入，不声称已经启用。其余七仓不机械安装，具体筛选结果按本批源评估和`continuous-evolution`原owner追溯。

## 6. 验收与恢复

工程覆盖身份/币种碰撞、NaN/未知、源日期/修订、跨期拒合、穿透不归一、同key单飞/缓存副本、并发有界、取消排空、设备鉴权/默认拒绝、CAS保存、旧A股链接/搜索和资产切换乱序。公开资料错码/币种冲突、来源警告、双曲线缺点、分钟缺失、US错venue/ETF/旧钟、Alpaca无Key不外发/鉴权终态/不重定向与不泄漏Key分别验。离线adapter测试不证明实际账号权限。新表迁移必须在目标连接重复升级而不修改旧账户数据。

真实运行另验普通配对页面的搜索直达、来源净值/披露读取、图表游标/口径、保存/重读边界和窄屏。没有真实本人份额时不往生产录测试持仓；写读闭环用隔离夹具证明，并分别声明。模型访问、完整本地门、准确HEAD发布、主目录加载和效果逐层留证。

恢复只需停用新手动研究/资产读取开关和回到A股视图；新表与证据保留，不回滚删除本人记录。没有新的后台采集器、模型调度、真实交易、收费数据或外部通知。状态仍归原stage，后续源/效果缺口不能被工程绿色代替。

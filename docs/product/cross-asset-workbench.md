# 统一资产工作台

## 1. 授权、入口与职责

2026-10-30用户批准前轮Decisions、金融Skills、国内QDII/联接优先及美股只读方案，并明确工作台合一。本合同取代前轮“基金另设业务入口”的导航建议；`/workbench`仍是唯一工作台，按`asset=cn_equity|fund|us_equity`切换对象能力。原无asset链接仍读A股。`mode=watch|positions`保留原自选/持有语义；基金链接携来源完整份额代码，不猜市场后缀。

合一的是导航与组件外壳。基金净值/披露、A股行情、未来美股feed分别拥有事实、时钟、缓存和权限；基金手工份额/成本不进入paper/real A股账户。美股与基金不进入A股选股、预警轮询、模拟撮合或券商。旧研究、旧选择和历史来源不迁写。

## 2. 数据身份与时点

- 基金身份为`fund:{market}:{source_symbol_without_suffix}:{currency}`；目录返回的source_symbol、asset_type、ticker、exchange、currency必须一致。根对象仅本轮获准场外`.OF`份额；联接穿透可读取其披露指向的场内目标基金。
- 货币须来源明确，不从名称/后缀猜人民币。A/C和币种独立；同号A股仍由原股票接口处理，不合并存储或订阅。
- 官方NAV的nav_date、发布日期、持仓报告期/披露日/修改日、接收时刻独立。接口data.timestamp可能只是响应组装钟，不升级为NAV发布时间或市场报价钟。
- 读取来源为原THS金融数据通道，按正式API合同和实抓核验。它不是新独立行情源；普通用户页面不携Key。代码许可不授予第三方数据再分发、公开展示或永久留存权；本机受控读者与未来公共部署许可分开，部署继续搁置。

## 3. 基金研究与持有记录

完整流程为身份→正式材料/净值/披露→费用/规则→穿透/重合→同类比较→有依据的建议/失效条件→保存版本与后续核验。具体助手工作流归`skills/qdii-fund-research/SKILL.md`，不是第二份任务账本。

读取界面在同一右区切换净值、披露、费用、研究核对；使用原左右宽度和移动切换，不新增常驻占图顶栏或多滚动owner。净值曲线是已公布NAV而非交易价格；游标按估值日读数，范围切换不触发模型。原文和回执按需查看。

手工记录以instrument_id为键，份额/同币种总成本同时填写或同时清空，保存明确`manual_not_broker_verified`。首次expected_version=0、后续须当前版本；冲突409保留输入，不能盲覆盖。收益只使用同份额/币种的有效单位净值并标净值日，缺NAV不拿成本当现价。不同币种不相加。

联接穿透仅乘可得同报告期权重，保留路径和未知残余。一层可读范围不冒充全基金全集；部分披露的重合是下界，不把已知部分放大到100%。没有本人记录不编造组合仓位。

研究候选不等于已推荐。必须核正式投资范围、跟踪基准、美股/科技敞口、份额/费用、申赎与额度，再作透明同类对照；纳指100不等于纯科技，也不等于纳斯达克综合指数。当前原接口尚未提供可核的完整投资范围/基准/即时申购状态；字段缺失时明确待补，不能凭名字造推荐或给不明总分。

当日估算不是官方净值。当前持仓、同口径境外行情、基准和估值汇率未满足时不提供整只基金的当日涨幅。未来若引入基准代理或部分持仓贡献，须保留输入版本/源钟/覆盖，不虚构置信区间；实际NAV公布后对不可变估算核误差。人民币目标ETF价格不能代NAV或重复叠加汇率。

本轮核实的Alpaca个人免费计划仅IEX实时；IEX覆盖08:00–17:00 ET，不能代表完整04:00–20:00盘前盘后。免费overnight为实时指示性报价、15分钟延迟成交，不能冒充全市场实时成交。该候选需要新Key且未满足用户完整免费来源要求，因此未申请、未实接，页面如实显示来源待核，不发A股行情请求或绘制假曲线。既有THS通道未证明覆盖美股/纳指100正式基准。

## 5. Decisions与外部方法

Decisions只在已保存公司/事件证据上提供手动、固定选项的未验证关系研究；正式合同归[语义蓝图](../ai/semantic-decisions.md#2026-10-30-decisions具名研究与统一工作台)。不替代完整TradingAgents，不改变评分/通知/执行资格。行情刷新和切换不调用模型；失败保留原解释、真实错误和已知用量。

完整独立工作流分别由基金尽调、论点/催化剂跟踪、SEC财报核验Skill承接，许可与固定来源随目录。后两项是助手研究流程，未部署应用自动跟踪器或第二个SEC解析器；SEC自动读取尚缺真实联系人及源准入，不声称已经启用。其余七仓不机械安装，具体筛选结果按本批源评估和`continuous-evolution`原owner追溯。

## 6. 验收与恢复

工程覆盖身份/币种碰撞、NaN/未知、源日期/修订、跨期拒合、穿透不归一、同key单飞/缓存副本、并发有界、取消排空、设备鉴权/默认拒绝、CAS保存、旧A股链接/搜索和资产切换乱序。新表迁移必须在目标连接重复升级而不修改旧账户数据。

真实运行另验普通配对页面的搜索直达、来源净值/披露读取、图表游标/口径、保存/重读边界和窄屏。没有真实本人份额时不往生产录测试持仓；写读闭环用隔离夹具证明，并分别声明。模型访问、完整本地门、准确HEAD发布、主目录加载和效果逐层留证。

恢复只需停用新手动研究/资产读取开关和回到A股视图；新表与证据保留，不回滚删除本人记录。没有新的后台采集器、模型调度、真实交易、收费数据或外部通知。状态仍归原stage，后续源/效果缺口不能被工程绿色代替。

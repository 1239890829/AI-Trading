## 4. 重建方向：任务布局与材质系统一起设计

**Design Read：这是为中文A股研究者重做的实时操作型工作台；深色、顶部导航、数据清晰，液态材质承担层级和来源连续性。** 展示型页面才使用Taste主技能的dials；工作台不继承旧融合版4/5/8，也不照搬Taste默认8/6/4。

原版context已执行；未给target的自动发现未识别到嵌套web实现，不据此称项目没有UI。源码与41入口是现状证据。原版要求的工具上下文放在忽略批次中的隔离适配目录，事实指回产品文档，不建立新的产品账本。concept-seed已实跑，key 88adca6b、assigned index 3；这是候选分配，不是用户批准。

七个方向覆盖至少三种来源：研究图书馆目录、瑞士科学出版、深海测绘图册、建筑材料色样、夜间展览导视、航空旅行凭证、植物固定尺度比较。均只能影响字体/配色/密度/标志性交互，不能改变顶部导航及金融控件语义。仪表盘、科幻驾驶舱和报纸拼贴不进入候选。

建议主案为第三个：**深海图册中的蓝银研究面**。这是待确认提案，不能声称已完成原版选案、效果图批准、方向契约或finish review。原版交互选案及必要效果图将在方案确认后的方向阶段完成，先看到组合再实施。

### 4.2 暂拟视觉规则，确认后由实屏决定

画布用墨蓝黑，任务底面为低饱和深青，数据阅读面为中性石墨，主文字为铂银；蓝色只承担操作选中与证据关联，涨跌红绿、风险/降级状态另有语义。不是全页一块灰加一个发光按钮：头部、分析主区和浮层有可区分的色域与明度，数据底面保持稳定。

可见控件候选尺寸：桌面次级操作28–32px、主操作32–36px、关闭图标面24–28px；手机可见面保持紧凑，命中区至少44px。命中区必须真正位于所属容器内，不能靠伪元素伸出遮住邻项。手机搜索独立整行，320px宽度按安全边距计算，不挤进通知按钮旁。

中文使用现有本地/系统无衬线栈；数字tabular-nums，正文和金融读数不做扰动、故障或分字符翻转。字号、行高、字重而非巨大标题建立层级。图标统一现有Hugeicons家族与线重，禁止一个模块一个图标风格。

圆角按职责：输入与小控件较紧，阅读面较缓，导航/浮层体现液态边缘；不能随意混用。层级固定为内容、固定工具、下落选择器、抽屉/模态、提示；每层均有焦点、关闭和滚动所有者。正文不套玻璃卡片；卡片只用于有独立对象/动作/层级的内容。

### 4.3 标志性交互与液态材质

标志性交互是**从证券/事件触发点展开可追溯证据阅读面**：来源锚点可见，展开保留同对象、日期与返回位置，关闭沿原入口收回。只用一个主交互语言贯穿搜索、机会、消息和研究；不是各页拼一套动画。

液态材质集中在导航、搜索展开层、轻选择器及抽屉外沿。比较React Bits GlassSurface的SVG位移、ThreeUI材质和原生CSS基线；字层与折射层分离。必须用真实背景移动证明像素位移；局部WebGL内部纹理折射不等于底层DOM折射。无法支持的浏览器回落到高对比实体底和边缘层次，并说明缺失效果。Safari/Chromium/Firefox分别截图及交互，不能只用CSS.supports下结论。

正文、K线、分时和关键风险不随材质扭曲。高频报价即时更新；数值滚动仅在不误读精确值的低频摘要使用。共享元素/Flip用于真实重排，列表不每次轮询都重新入场。3D微倾只用于非密集对象封面，鼠标和触摸边界分开，避免抢手机滚动。抽屉关闭判断位移或速度、结束吸附；减少动态时直接到终态。

### 4.4 原版挑战方向的比较

seed的六个挑战均按“用户辨识、产品清晰度”评估，以下为文字层诊断，尚未完成原版QUALITY BAR图板和效果图选案：车站翻牌保留状态列稳定的要求，金融数值逐字翻转会误读；单色产品营销保留主张紧邻证据的纪律，但不足以区分实时操作区域；定向越野图保留状态与底层事实分离，地图化控件会增加学习成本；动物园导览保留区域主次与连续形变，彩色团块会挤占图表；航空票夹保留取消/无效状态可追溯，不使用盖章和撕票替代交易动作；植物图册保留同尺度/同窗口比较，不用连续变形伪造两段行情之间的事实。当前均不自动晋升主案，正式选择时仍按原版展示和裁定。

## 5. 先修真实问题，再完成整套表现

### 5.1 提醒行为

源码证据表明AI失败当前直接生成“未做噪音过滤”的llm_fallback通知。既有去重按rule_id和symbol，任何近期判读可能抑制后续，缺股票事件共享占位码；上下文统计跨股票；浮泡轮询没有展示修订身份。必须先区分事件、规则判定、提醒意图和展示状态，复用现有事实与去重链，不另造平行通知系统。

新方案：确定性候选筛选→新变化/关联/风险检查→形成提醒意图→可用时AI解释，否则标“规则提醒，AI不可用”→按修订投递/展示。重复轮询、重连、刷新不反复弹同一意图；新的规则穿越、风险升级、实质新事件可以重新提醒。不能靠全局静音、延长统一冷却或只在浏览器记一个布尔值解决。unknown/source stale必须与有效信号区分；ignore不能永久封死后续升级；不同股票和无股票题材不能互相去重。

管理面复用同一事实，明确已筛选/未筛选、AI/规则、事件时间/判读时间、待处理/已确认与失败。今日数按北京日和明确分母统计，不使用最近30条冒充全天。筛掉无效行后需有界补足查询，避免前部候选耗尽而饿死后部有效通知。

### 5.2 布局、滚动和控件

滚动从应用壳→工作区→列表/证据/表格→弹层逐层登记唯一owner。Grid/Flex可收缩项有min-width:0、min-height:0；表格有内容最小宽度和独立横向viewport；不能用全局overflow:hidden掩盖越界。横条只在内容超宽时出现。系统自动隐藏滚动条的平台须用可见滚动控件和边界提示补足，验证实际可拖动、可键盘、可触摸，不承诺CSS强迫所有系统显示原生横条。

提醒等宽内容弹层桌面按内容使用宽规格，手机占可用宽；正文长行可换，数据列按语义固定/横滚。窄窗与短屏不压扁Canvas，要在主要图表与次级说明之间分配滚动。图表本体、坐标、工具、来源和展开依据分别测量，不用整个外框高度替代绘图区高度。

按共享控件消费者扫描所有关闭、删除、通知、提交、选择、tabs和工具按钮。取消局部CSS覆盖堆叠，不能只修改被点名的按钮。核对视角使用真正Tabs；市场范围/排序用值选择器；MA5/MA10为语义button＋aria-pressed，明确按钮边界和选中状态。自选管理下落层避让正文与容器边界，删除列含完整触点。

历史回放只退出用户要求取消的回放入口、状态和唯一显示消费者。先核动态引用，再清理孤立组件；历史K线、共享行情API、研究/回测和模拟请求幂等的replayed字段保留。

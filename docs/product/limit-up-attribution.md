# 涨停归因与事件深度解读

> 用途：连接原始消息、事件版本、个股关联和市场响应，服务现有资讯、市场、选股、消息与复盘。任务状态只在 [W00/IMP-092](../stages/w00-foundation.md#imp-092)，模型准入仍归 [语义判断](../ai/semantic-decisions.md)。用户2026-10-12批准方案实施；不恢复Jev、Decisions或KEV。

## 1. 目标与基线

目标是及时解释苗头、首板、续强和趋势中的机会：发生什么、为什么是这只、持续看什么、何时失效。功能工程与未来赢家识别效果分别验收。普通股票称“驱动线索”，对应日涨停池内股票才称“涨停归因”；源端未收录不证明从未触板。

基线已有源端涨停标签、7x24快讯、有限个股新闻、观察/解释版本、选股引用、首次加入事实和通知去重。复用这些owner，不另建事件库或全市场推送。最新解释不能替代首次入选的冻结依据。

本轮先纠正持久契约5=官方与选股反向加权、缺阶段默认done、摘要关键条件遗漏和业务否认误判。市场响应confirmed保留兼容字段但明确只代表观察到呼应，不证明新闻真实性或涨停因果。存量记录及原归档不重写。

## 2. 多维解释与依据

至少覆盖公司事件、政策/时事、行业供需、海外产业、价格传导、气候/突发事件、公开舆情和市场结构。维度可扩展，允许多个解释、竞争解释与未知原因；关键词只用于组织材料，不构成独立证据。

| 判断 | 输入 | 限制 |
|---|---|---|
| 消息证据 | 原始标题/摘要/链接、发布者/采集者、版本 | 已收录不等于属实；自述/预期保留归属 |
| 个股关系 | 明确对象、source_symbol、方向/人工复核、题材成员 | 直接关联/源关联/题材线索/模型假设分别标注，不自动受益 |
| 市场呼应 | 同时点行情、涨停池、板块响应及来源 | 不是因果证明；当前读层未取行情时标未评估 |
| 后续条件 | 拟议/审批/否认、关键限制、下一节点 | 收购拟议不写完成，涨价同时检查收入和采购成本 |

公司、产品、客户、子公司和股权关系绑定有效时段与出处。海外财年不当自然年，区域灾害不自动扩为全国减产。人物发言保存主体、原话、时间与条件。源不足时保留未知；模型置信度不当上涨概率。

## 3. 原观察、版本和时钟

复用EventObservation/EventInterpretation，区分发布、收到、系统可用、解释生效与读取钟。源缺时间不以当前钟补填；日期精度不编分钟。修订追加版本，保留旧解释及原决定。多家同源转载不增加独立佐证，原发布者未知只显示采集者。

展示实际保存的标题/摘要、原文链接和材料范围；摘要不冒充全文，材料未提及不证明公司没有业务。读层按证券、有界数量和同一读取钟批量查询，未来观察、待复核和撤回状态不能贡献已生效方向。GET不写事件、补目录、调用模型或发消息。

## 4. 连续采集、覆盖与性能

| 时段/来源 | 工作 | 验收 |
|---|---|---|
| 盘前 | 隔夜消息、公告、未结束事件、海外信息 | 实际可见钟、关键条件、今日观察 |
| 盘中 | 原快讯循环、个股采集、新进展和澄清 | 到达延迟、遗漏、去重、反证传播 |
| 盘后 | 原涨停范围/个股采集与复盘 | 失败、无响应、漏选、次日条件 |
| 夜间/休市 | 原盘外循环；按接口条件补原始资料 | 页面关闭后持续性、合法空集与缺口 |
| 海外/政策/气候 | 原机构网页、RSS/公开接口先验收 | 字段、原钟、许可、失败，不保证免费全量SLA |
| 社交舆情 | 可访问公开渠道/特定账号/用户公开链接 | 原文、传播钟、公司关系、澄清 |

现有快讯代码连续竞价15秒、盘外60秒，配置不是实际时效保证。FlashWatermark继续拥有覆盖前沿和缺口，不新开重复调度器。补抓晚到不能倒填早盘证据。

同输入/协议版本只分析一次；有界并发、退避、共享缓存。归因先保存材料再异步分析，不阻塞行情/图表/通知。前端按需读取，换对象隔离旧回包，刷新保留已有内容。当前解释接口不额外采集或取全文。

## 5. 选股、组件和通知

独立公司事件、首板/接力、强趋势、情绪叙事和封板参考用各自条件。完整梯队不是独立走强的必要条件，起爆前预测不是门禁，封板不等于能成交。缺新闻的技术候选沿原策略保留，标明缺事件证据，不补造利好。

卡片回答为何关注、为何关联、新变化、持续条件、失效条件和首次加入时间价。related_event_refs冻结事实与当前解释分开；来源权重修正作用于新的原调用，不改原组合/晨报/历史机会。存量原标题/摘要中的明确业务否认，在当前选股与晨报计算中保守降为零贡献；保留原阶段、方向、解释引用与历史评分，不重写记录，也不把未知阶段升级。

市场源端标签与深度解释分层；股票、事件、资讯、选股和消息旁览复用当前页读组件，不增一级导航。默认显示事件标题、状态和关联类型；点击一条仅展示该条完整依据，返回恢复原条目焦点。关闭复开回到列表，换股清除旧选择；刷新失败保留旧内容，所选条目消失回到列表。深层原文、条件和时钟按需展开，保持手机可达和原风格。来源收录不等于事实正确，规则方向标明待核线索；个股入口不拿首个题材方向当该股方向。

通知由原selection/buy_point/持仓风险/用户提醒owner决定。正式入选、实质变化和正式反证才评估更新；原消息身份/去重保持。当前归因GET不承担评分、采样、通知或晋级。

## 6. 验证、效果与恢复

工程验证来源顺序、缺阶段、否认、摘要限制、错股、弱关联、模型假设、晚到/未来、修订/撤回、GET无写和窄屏。公开真实摘录与构造夹具分别报告。

RSH-030继续拥有同输入基线、模型/提示版本、关键条件、调用/失败/耗时和独立人工gold。先近期，再2024/2025代表窗，含失败/无响应/旧闻/澄清/相反影响。历史不冒充前向；引用命中不证明推理正确。已复现的纯内存反例“粮食涨价推升公司原料成本，毛利率下降”仍可能被旧关键词规则记为正向；当前展示纠偏不等于修复该语义规则，也不承诺准确率。该反例归原RSH-030评价，不能靠改标签宣布模型/规则效果已通过。context-v2未证明稳定增量，展示上线不晋级模型。

效果验误关联、遗漏、发现时点和解释质量。入选后D1/D3/D5、MFE/MAE、可执行性分别评价，不要求多年每分钟数据作为工程前置。长期观察不让确定性功能永远无法完成。

恢复只回退本次代码和读视图，不删原观察、重写首次加入、覆盖历史解释或恢复退役服务。新来源、模型、评分和通知消费仍需各自准入；问题回原owner，不凭涨跌自动调策略。

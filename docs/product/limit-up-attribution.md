# 涨停归因与事件深度解读

> 用途：连接原始消息、事件版本、个股关联和市场响应，服务现有资讯、市场、选股、消息与复盘。任务状态只在 [W00/IMP-092](../stages/w00-foundation.md#imp-092)，模型准入仍归 [语义判断](../ai/semantic-decisions.md)。用户2026-10-12批准方案实施；不恢复Jev、Decisions或KEV。

## 1. 目标与基线

目标是及时解释苗头、首板、续强和趋势中的机会：发生什么、为什么是这只、持续看什么、何时失效。功能工程与未来赢家识别效果分别验收。普通股票称“驱动线索”，对应日涨停池内股票才称“涨停归因”；源端未收录不证明从未触板。

基线已有源端涨停标签、7x24快讯、有限个股新闻、观察/解释版本、选股引用、首次加入事实和通知去重。复用这些owner，不另建事件库或全市场推送。最新解释不能替代首次入选的冻结依据。

本轮先纠正持久契约5=官方与选股反向加权、缺阶段默认done、摘要关键条件遗漏和业务否认误判。市场响应confirmed保留兼容字段但明确只代表观察到呼应，不证明新闻真实性或涨停因果。存量记录及原归档不重写。

## 2. 多维解释与依据

至少覆盖公司事件、政策/时事、行业供需、海外产业、价格传导、气候/突发事件、公开舆情和市场结构。维度可扩展，允许多个解释、竞争解释与未知原因；关键词只用于组织材料，不构成独立证据。

| 判断 | 输入 | 限制 |
|---|---|---|
| 消息证据 | 原始标题/摘要/链接、发布者/采集者、版本 | 已收录不等于属实；自述/预期保留归属 |
| 个股关系 | 明确对象、source_symbol、方向/人工复核、题材成员 | 直接关联/源关联/题材线索/模型假设分别标注，不自动受益 |
| 市场呼应 | 同时点行情、涨停池、板块响应及来源 | 不是因果证明；当前读层未取行情时标未评估 |
| 后续条件 | 拟议/审批/否认、关键限制、下一节点 | 收购拟议不写完成，涨价同时检查收入和采购成本 |

公司、产品、客户、子公司和股权关系绑定有效时段与出处。海外财年不当自然年，区域灾害不自动扩为全国减产。人物发言保存主体、原话、时间与条件。源不足时保留未知；模型置信度不当上涨概率。

## 3. 原观察、版本和时钟

复用EventObservation/EventInterpretation，区分发布、收到、系统可用、解释生效与读取钟。源缺时间不以当前钟补填；日期精度不编分钟。修订追加版本，保留旧解释及原决定。多家同源转载不增加独立佐证，原发布者未知只显示采集者。

展示实际保存的标题/摘要、原文链接和材料范围；摘要不冒充全文，材料未提及不证明公司没有业务。读层按证券、有界数量和同一读取钟批量查询，未来观察、待复核和撤回状态不能贡献已生效方向。GET不写事件、补目录、调用模型或发消息。

## 4. 连续采集、覆盖与性能

| 时段/来源 | 工作 | 验收 |
|---|---|---|
| 盘前 | 隔夜消息、公告、未结束事件、海外信息 | 实际可见钟、关键条件、今日观察 |
| 盘中 | 原快讯循环、个股采集、新进展和澄清 | 到达延迟、遗漏、去重、反证传播 |
| 盘后 | 原涨停范围/个股采集与复盘 | 失败、无响应、漏选、次日条件 |
| 夜间/休市 | 原盘外循环；按接口条件补原始资料 | 页面关闭后持续性、合法空集与缺口 |
| 海外/政策/气候 | 原机构网页、RSS/公开接口先验收 | 字段、原钟、许可、失败，不保证免费全量SLA |
| 社交舆情 | 可访问公开渠道/特定账号/用户公开链接 | 原文、传播钟、公司关系、澄清 |

现有快讯代码连续竞价15秒、盘外60秒，配置不是实际时效保证。FlashWatermark继续拥有覆盖前沿和缺口，不新开重复调度器。补抓晚到不能倒填早盘证据。

同输入/协议版本只分析一次；有界并发、退避、共享缓存。归因先保存材料再异步分析，不阻塞行情/图表/通知。前端按需读取，换对象隔离旧回包，刷新保留已有内容。当前解释接口不额外采集或取全文。

## 5. 选股、组件和通知

独立公司事件、首板/接力、强趋势、情绪叙事和封板参考用各自条件。完整梯队不是独立走强的必要条件，起爆前预测不是门禁，封板不等于能成交。缺新闻的技术候选沿原策略保留，标明缺事件证据，不补造利好。

卡片回答为何关注、为何关联、新变化、持续条件、失效条件和首次加入时间价。related_event_refs冻结事实与当前解释分开；来源权重修正作用于新的原调用，不改原组合/晨报/历史机会。存量原标题/摘要中的明确业务否认，在当前选股与晨报计算中保守降为零贡献；保留原阶段、方向、解释引用与历史评分，不重写记录，也不把未知阶段升级。

市场源端标签与深度解释分层；股票、事件、资讯、选股和消息旁览复用当前页读组件，不增一级导航。默认显示事件标题、状态和关联类型；点击一条仅展示该条完整依据，返回恢复原条目焦点。关闭复开回到列表，换股清除旧选择；刷新失败保留旧内容，所选条目消失回到列表。深层原文、条件和时钟按需展开，保持手机可达和原风格。来源收录不等于事实正确，规则方向标明待核线索；个股入口不拿首个题材方向当该股方向。

通知由原selection/buy_point/持仓风险/用户提醒owner决定。正式入选、实质变化和正式反证才评估更新；原消息身份/去重保持。当前归因GET不承担评分、采样、通知或晋级。

## 6. 验证、效果与恢复

工程验证来源顺序、缺阶段、否认、摘要限制、错股、弱关联、模型假设、晚到/未来、修订/撤回、GET无写和窄屏。公开真实摘录与构造夹具分别报告。

RSH-030继续拥有同输入基线、模型/提示版本、关键条件、调用/失败/耗时和独立人工gold。先近期，再2024/2025代表窗，含失败/无响应/旧闻/澄清/相反影响。历史不冒充前向；引用命中不证明推理正确。已复现的纯内存反例“粮食涨价推升公司原料成本，毛利率下降”仍可能被旧关键词规则记为正向；当前展示纠偏不等于修复该语义规则，也不承诺准确率。该反例归原RSH-030评价，不能靠改标签宣布模型/规则效果已通过。context-v2未证明稳定增量，展示上线不晋级模型。

效果验误关联、遗漏、发现时点和解释质量。入选后D1/D3/D5、MFE/MAE、可执行性分别评价，不要求多年每分钟数据作为工程前置。长期观察不让确定性功能永远无法完成。

恢复只回退本次代码和读视图，不删原观察、重写首次加入、覆盖历史解释或恢复退役服务。新来源、模型、评分和通知消费仍需各自准入；问题回原owner，不凭涨跌自动调策略。

### 2026-10-13 主线索与短阅读

### 2026-10-14 原因直接阅读与入口收拢

研究阅读范围同时覆盖最新合法归档中的已推荐股及通过参与硬门、但因低联动而未获推荐的题材参与股；后者仍不是推荐。它们与当日精选合并后有界去重，优先保留已有推荐顺序，不从候选审计的拒绝行、涨停参考或历史run补名单。最新合法空集或降级仍阻止旧名单复活；题材参与有股票不等于推荐名单非空。采集不调用页面接口，不扩大选股资格、共享预算或单批容量。

采集只用CNINFO公开身份与披露查询、官方PDF附件。证券代码和orgId精确匹配，原件再核证券与完整法定名（含“股份有限公司”“股份公司”）同页、URL/披露日/原始SHA/实收钟。经营资料主位优先选择本次有界查询中、as_of前最新可用的年报/半年报全文；没有这两类全文才选季度报告，不因季度披露较新就挤掉经营正文。仍只取一个报告及至多一份近期经营公告；分页、页数/文本/片段预算、缺类别和局部失败均保留，不能称全市场/全文/全部客户订单已覆盖。公开网页接口不是稳定性、自动化配额或再分发许可承诺；限频、缓存、单写者与失败退避限制本地负载，遇拒绝不换入口绕过。原始PDF不入公共仓库。pypdf进入正常固定依赖；子进程无服务凭据，限时、CPU/输出/页数约束，macOS采用采样RSS保护，明确不是OS安全沙箱；扫描件不做假OCR。

报告选择策略在资料缓存顶层单独标版本；策略变更重选资料，不冒充句子抽取算法改变。只改策略且原文档不变时复用原模型回执；实际文档或抽取版本改变则按原预算研究。缺经营完整句只说明本次正文未取得，不擅自归因扫描件或公司没有业务。

公司资料与事件解释分开保存。没有合格事件或模型失败时，仍能阅读本公司资料、取数时刻、缺项和失败状态；资料不构成受益、当前订单或收入证明。每次模型使用现有配置通道，只接收公共事件和有界公司片段，按原共享预算预留/开始/结算，不计未知为零，不自动重试。稳定输入摘要排除任务/刷新时刻；相同内容不重复花调用，开始后中断/未知不会自动重发。取消在有界步骤间协作检查，当前不可中断调用排空后才确认终态；发布前重核事件和公司资料版本，漂移不发布。稳定键绑定完整公司文档身份，与发布/读取的全文档核验一致；抽取方法、标题、披露及原件接收元数据改变不能借旧选择发布新版本。只排除当前检查/刷新时钟，不排除来源事实时钟；同版本同文档复用，未知调用仍不自动重发。

定期报告按实际独立财务章节标题截断经营摘录，保留标题前原句及原物理页码；目录、带页码目录行和正文提及不作为章节起点。财务附注可能含真实业务事实，本轮未纳入不代表不存在；未定位章节/页数截断明确覆盖不足，不承诺会计模板已全部过滤。独立经营公告沿原路径保留实际合同及否定证据。

片段类别只表示有界自动抽取的经营线索，不能把“以客户为中心”当具体客户、金融/担保/治理框架当营业订单、未使用募集资金当经营恶化。实际产品、客户、拟议/签约/定点/交付和否定反证继续保留原句。抽取版本更新复用已核哈希的原始PDF及原接收回执，不重下相同原件；新片段不回写旧作者对象。版本更新后的重新研究继续遵守未知调用不重发和实际输入幂等约束，覆盖仍非全文或全市场。

模型只能选择已有fact ID、逐字产品/原料短语、消息共同锚词、有限传导channel与缺项代码；代码复核本公司生产/采购角色、经营事件主体、盘面负例和引用后，编译带条件的解释。对明确本公司供货另用部件供货渠道，不强造需求增幅；对明确本公司资本开支/折旧/转固，核公司生产角色与财务事件主体后编译现金流/费用条件，不强求财务指标成为产品名的子串。无自由事实扩写、金额推演、客户实名或项目状态生成。客户制造不当本公司制造，客户采购不当本公司成本；产品否定保持局部范围，客户总名单不跨挂产品，纯龙虎榜/否认新增订单不补经营催化。共同产品词仅为经营交集，不证明历史地面终端与本次车载设备使用同一部件、规格或客户。词法守卫和引文命中仍不能证明语义正确；选择本身保留原答及拒绝原因，机械联合核对未通过不冒称消息没有公司主体。

自动结果严格标为`automated_evidence_bound_not_gold`，生成方法为`model_selection_and_deterministic_compilation`；旧`author_source_reviewed_not_gold`不变。后台采集后先检查当前有效作者回执，有则零新增模型并保留其指针/读者；自动发布在锁内再次检查，防止模型运行期间作者回执到达时被覆盖。过期或来源已修订的作者回执不阻止准确新版本的自动结果。两种结果都只供当前研究阅读，保留来源原句、报告期、披露/接收时刻、模型/调用身份、失效条件及缺项，不回填历史入选，不影响方向、排序、资格、通知或资金。新结果须同时满足公司资料摘要、准确symbol/event/version/observation、当前事件状态、引用和最多7日有效期；历史响应时点早于采集或发布时明确排除。文件hash是本地完整性，不是独立审核签名。

任务中心是原有维护入口，普通配对读者不需要维护授权。选股已有相关消息/AI区域统一显示未轮到、采集中、证据不足、来源/模型失败、预算阻断、取消/中断及已保存状态；GET只读，不启动任务或自动修文件。后台失联状态从AgentTask投影，不捏造仍在运行。停用调度、取消任务和保留旧基线是恢复路径，不删除用户数据或旧作者回执。

异步创建在等待前占用原同类型互斥，以固定任务ID幂等持久化queued，成功后才由原事件循环启动一次handler；持久化失败向调用方返回任务ID和明确unknown，调度器也记录失败，不当成正常互斥成功。生命周期状态与本管线的数据库单元在线程中真实收尾，等待不占ASGI事件循环。生命周期/异步checkpoint只对SQLite BUSY/LOCKED作最多4次数据库尝试，间隔0.1/0.25/0.5秒；每次仍受原驱动超时约束，handler、模型及预算事务不因此重放。终态计算后有界等待提交，后续审计失败不反写业务结果。全部尝试仍无法提交时只记`persistence=unknown`和预期终态，保留原持久行，按既有启动/操作者恢复；日志不能冒充持久终态。取消真实drain当前线程操作，回收句柄并消费后台异常，不能把数据库错误遗留的running当持续判读。

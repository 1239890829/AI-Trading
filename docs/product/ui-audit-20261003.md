## 1. 结论与系统定位

AShare 是 A 股行情、事件选股、持续观察、研究和模拟交易工作台。核心用户需要在多个对象、时间和证据之间连续核对，真实券商不在功能范围。适合它的视觉方向是“对象与证据驱动的投研工作区”：读数紧凑，解释可展开，变化清晰，动作有回执。创意集中在信息如何出现、如何联动、如何返回；装饰强度随场景降低。

本轮已形成 79 张有效现有界面截图、X01–X50 逐项图片映射、87 份非测试 TSX 源码结构索引和可操作 HTML 样本。87 = 76 份生产组件 + 11 份页面/布局；328 是 JSX 交互声明位置，不能当 328 个独立功能或已验证操作。50 项包含 WATCH 候选和无独立前台的后台能力，使用真实消费者上下文并明确缺口。没有为不存在的功能制作“现状截图”。

用户最新要求的完整功能、子功能、交互、效果和使用体验纳入下文。既有五任务导航、共享证券详情、状态标签、退出动效、焦点机制和减弱偏好已经存在；本次不把已有成果写成从零缺失。设计强度采用 variance=7 / motion=6 / density=7 作为探索目标，不作为实际性能或效果分数。

## 4. 使用流程与模块联动

主流程：市场变化 → 题材/事件 → 候选/线索 → 个股工作区 → 条件跟踪 → 同版提醒 → 独立账户结果 → 当时判断与复盘。独立公司事件和强趋势可以直接进入个股/线索核对，无需伪造同题材梯队。选中、收藏、持仓、研究候选和可执行账户必须有不同身份。

每次联动携带证券/事件 ID、交易日、源时间、决定版本、账户范围和返回位置。URL 负责可分享对象上下文，状态缓存负责可恢复阅读位置；金融事实与决定版本由后端拥有。跨日读取另标日期，不能用刷新替换固定旧版。参数、模型、策略晋级和任务取消保留原授权/幂等/终态，不因新界面多一个按钮而扩大权限。

| 任务 | 首屏重点 | 次层信息与交互 | 离开/失败路径 |
|---|---|---|---|
| 市场全景 | 环境/广度/变化和来源 | 题材、资金、热图、事件；对象点击联动 | 缺快照就地说明；保留日期与过滤 |
| 机会发现 | 形成路径、候选原因、缺口、等待/触发/失效 | 首见参考、同版依据、反例、跟踪 | 缺证不冒充无机会；失效立即显示 |
| 自选跟踪 | 大图表、当前证券、关键变化 | 指标/盘口/财报/事件/计划分组 | 换股弃置旧回包，关闭回原选中行 |
| 持仓与模拟 | 单账户结果、风险、成交与未成交 | 手工录入、模拟草稿、费用、回执 | 切 scope 不混本金；提交失败保留输入 |
| 复盘研究 | 当时判断与后续结果、完整分母 | 漏选/失败、方法、知识、反证与条件计划 | 未成熟不画胜率，建议不自动改评分 |
| 系统维护 | 真实后台健康与任务结果 | 运营、参数、实验、仓库、审计/恢复 | 长任务可继续/真实取消；不是关面板即取消 |

## 5. 五种核心创意交互与两种候选拓展

| 设计 | 触发与作用 | 反馈、关闭和边界 | 动效与替代 |
|---|---|---|---|
| 对象轨迹 | 点题材/个股/依据逐步核对，保留最近阅读链 | 每步有 ID/日期；可返回原过滤；历史阅读不冒充当前对象 | 少量边界强调；键盘按钮等价，不强制整页飞行 |
| 证据透镜 | 侧面板跟随选中对象；手动固定旧版 | 固定对象、范围、版本；新结果只提示，不覆盖阅读 | 侧面板180–220ms；手机底部阅读面板；减弱即显 |
| 变化镜片 | 有新版本点 count 才看字段变化 | 同一事件重复无效更新不累加；新旧来源独立，点完可回固定版 | count短提示220ms；文本立即改，不滚动关键价格 |
| 时间梳 | 点首见/收盘/当前查看快照 | 未来未采集禁用并说明；日期/源时点分开 | 激活短色转；可用下拉或按钮，不靠拖曳 |
| 对比托盘 | 明确加入最多三个不同对象，跨视图暂存 | 去重、上限、清空、选中对象显示；关闭回原按钮 | 下方180ms出现；不挡表单/焦点；手机上下排列 |
| 因果线索展开（候选） | 点“为何关联”逐段看事件→行业→公司暴露→当时响应 | 每段区分事实/推断/未核；缺段停止，不补虚构箭头 | 单段展开180ms；无依赖自动缩短；研究 owner 验证 |
| 观察卡叠层（候选） | 手动固定两版/两对象，露出可点边缘比较 | 最大两层，始终显示对象/版本；拖动可选，有按钮等价 | 局部FLIP候选；先比较CSS与原组件，不给实时排行重排 |

原型已覆盖前五种操作结构及层次效果开关；时间梳只演示选择标签，不切换实际行情数据。对比表是三个虚构路径的说明样本，另显示实际托盘选择，不伪装成实源个股比较。跨任务固定身份、对象去重、三对象上限、清空计数、隐藏托盘 inert、提示不拦截点击在本轮发现并修正。生产接入要换成原同版只读契约，不能直接把原型状态当业务实现。

## 6. 组件、视觉和效果系统

### 6.1 层级、布局、字体和间距

桌面保留原来的头部导航，不采用侧边主导航。品牌、五任务与系统维护在头部横排，桌面主导航64px；下方52px承载数据范围与工具。工作区使用全宽可伸缩图表和292–340px按需证据面板，容器 min-width:0；在1080px附近证据下移，手机自然纵向阅读。分区依据任务频率，不能固定每一页三个等宽卡。长文宽度约60–75中文/西文字符的可读量级，表格按字段必要性而非等列宽。

4/8px 节奏：4 图标内间距，8 关联控件，12 密集行内，16 面板边距，24 区段，32/40 主区段。生产必须用既有共享 token 迁移，不逐页随意硬编码。紧凑只减少 padding 和行高，关键控件与解释字体不无限缩小。手机点按区域目标44px，可视图标小而热区大；桌面控制至少32px为设计目标；目前原型全部触点尚未逐个符合44px。

文字层级：24–28任务标题、17–20对象标题、14–16数据与动作、12–13辅助标签、16长文。数字 tabular-nums；中文优先系统苹方/微软雅黑等稳定字体，避免为标题加载大字体网络包。格式里字号只是目标，必须真实页面核对换行、裁切和200%缩放。

### 6.2 颜色、边界、阴影和材料

原型深色 bg `#111417` / surface `#191d21` / raised `#23292f` / text `#edf2f7` / muted `#a5b0ba` / action `#80d8f7`；浅色 bg `#eef1f3` / surface `#ffffff` / text `#18232c` / muted `#52616c` / action `#075c7c`。红涨、绿跌只承担金融方向，unknown/零/未采集用中性，警示用琥珀+文字；操作成功不滥用金融绿。

常驻面板用1px边界和轻微表面差异；只有浮层、停靠比较托盘使用明显阴影。圆角按对象：控件6–8px、面板10–12px、抽屉12–16px，不把全部圆角做成相同胶囊。没有阴影的表格也要有选中/悬停/聚焦反馈。

| 效果 | 合适位置与具体用途 | 禁用/降级条件 |
|---|---|---|
| 毛玻璃 | 阅读抽屉的固定标题、命令面板背景，8px低强度；正文96%以上不透明 | 不支持backdrop-filter则实色；高频图表后方/低端机不模糊；需复核合成对比 |
| 渐变 | 变化条或研究概览的轻量方向底色，让新增材料有落点 | 不用于涨跌真假、正文文字或每张卡；关闭效果仍有文字状态 |
| 卡片叠层 | 固定证据面板后露出两层边缘，表达可比较的版本 | 多于两层、文本遮挡、手机窄栏取消；不要整屏倾斜3D |
| 阴影 | 只给暂态表面说明它在原页面之上 | 长列表不逐项大阴影；暗色避免黑影堆积、亮色避免灰雾 |
| 层次变化 | 就地展开小摘要，深读进入抽屉，跨对象再进完整工作区 | 同一操作不随机换Modal/Drawer；保留退出、焦点与来源 |
| 过渡/共享位置 | 关联条、抽屉进退、固定/跟随切换 | 快速反向、切对象、关层均可中断；风险与输入立即生效 |

原型提供“层次效果”开关，能实际比较局部渐变、证据叠层和抽屉标题模糊；这些是候选效果，不自动上生产。全页粒子、光标拖尾、持续发光、价格滚轮、实时列表弹性重排、背景循环视频、行情Canvas倾斜没有本系统收益证据，暂不采用。

### 6.3 每类控件的角色

| 控件 | 选择规则与搭配 | 状态/可访问性要求 |
|---|---|---|
| Tooltip | 简短口径、单位、快捷键；不能承载必须读的失败原因 | hover/focus/点按均有路径；可Esc关，不遮关键信息 |
| Popover/Hover Card | 简短事件/标的预览，有完整查看入口 | 固定读取对象；不hover自动取收费资料；手机显式点按 |
| Drawer/Sheet | 连续阅读依据、新闻、资金、通知 | 来源方向进出；顶层Esc；关闭停止相应读取并回焦；长文内部滚动 |
| Dialog/Alert Dialog | 聚焦对比、预览确认或危险动作 | 标题/描述明确；焦点圈定；底部按钮不挤；退出保草稿 |
| Tabs | 同任务同对象的互斥视图，标签不逐字断行 | 键盘、选中、面板语义一致；溢出可滚而不是缩至不可读 |
| Count/Badge | 数量明确其分母/新变化/未读语义 | 0/未知/99+分开；减少动态保留数值；只重要变化播报 |
| 表格/列表 | 同类对象比较优先行，展开才用卡片 | 固定表头不遮焦点；source/date/scope就地；列隐藏可恢复 |
| 表单 | 草稿→预检→授权/提交→真实回执 | label不靠placeholder；错误靠字段；失败保值；按权限禁用并说明 |
| Toast | 短暂浏览/偏好反馈；不代替订单、取消、风险终态 | 无动作提示不拦截指针；重要结果持久可查；计时可访问 |
| Skeleton/Progress | 首次读取/长后台任务分别用；保留旧内容 | 不虚构进度或ETA；超时给实因/重试；取消与drain分名 |
| 搜索/Command | 任务+对象+原文的明确导航 | IME、arrow、enter、Esc、空与失败；收费/写命令不隐藏于快捷键 |
| Resizable/Split | 图表与证据可调比例，可复位 | 最小宽、键盘等价、拖曳提示；不迫使手机横滑全页 |

## 7. 状态与动效规范

数据状态有八种，组件输入状态另有 default/hover/focus/pressed/loading/disabled/error/success/empty/skeleton；两套维度不能混成一枚“失败”标签。

| 数据状态 | 可读内容 | 后续动作 |
|---|---|---|
| ready | 正确源时间/范围的内容 | 看依据或对比 |
| loading | 局部骨架，已有内容不清空 | 允许换对象/退出；旧请求不覆盖 |
| valid_empty | 指定日期/源有效无记录 | 看口径/改日期；不说服务失败 |
| local_empty | 当前筛选没有结果 | 清筛选，保留原数据 |
| error | 受影响能力和具体恢复动作 | 重试只读查询或去维护；不造空池 |
| stale | 旧值、原时间、陈旧原因 | 保留可读但阻止不合格消费 |
| unknown | 未采集/缺字段/未核关联 | 明确缺什么；不显示0/确定评级 |
| disabled | 任务/能力未启用 | 可读历史及启动条件，不偷偷启动 |

动效叙事为“用户展开证据，系统只突出实际变化”。按钮/颜色120–160ms、Tab内容120–180ms、Drawer180–220ms、退出160ms、count220ms；生产仍沿既有token做可测调整。入场 ease-out，反向使用当前进度；不 `transition:all`，不scale从0，不每刷新重播。长文新段的叠层可以220–280ms，不能阻止立即点击或关闭。

行情和风险值即时更新，只有少量短色提示；风险弹出不等队列/动画。真实排序发生时优先固定阅读行+“有更新”按钮；只有用户主动重排小集合才比较FLIP。系统/手动减少动态同时覆盖CSS与JS，数据仍完整。关闭视觉层不是服务端取消；动画退出层须inert/aria-hidden，不保活后台计费和读取。

# 风险管理 — full.md §12 / §15.4

## 1. 风险拦截位置

```text
信号产生（评分/策略） → 风险引擎 → 模拟交易/提示
```

风险引擎（`backend/app/risk/`，Phase 5-6）在 Strategist 输出与订单撮合之间强制拦截，
任何 AI 或策略输出不得绕过。

## 2. 市场状态驱动的仓位参数

状态：震荡筑底 / 震荡上行 / 主升趋势 / 高位加速 / 高位分歧 / 下跌趋势 / 恐慌下跌 /
极端波动 / 题材轮动 / 权重主导 / 小盘主导 / 数据不足。

每个状态配置：单股最大仓位、组合总仓位、追涨/趋势/低吸/价值策略权重、止损幅度、
新增仓位限制、高位股限制、单一题材/行业暴露上限、最大回撤保护线。
状态由规则引擎判定并输出依据（同情绪阶段判定要求），`数据不足` 时收紧默认参数。

## 3. 硬性拦截规则（不可被覆盖）

- 第一阶段：禁止连接真实券商、禁止真实下单（系统层面不提供接口）。
- 触发 `禁止交易名单`（ST、退市整理、监管风险、流动性不足等）的标的不得进入候选与订单。
- 组合回撤超过保护线：只减不加，直至人工解锁。
- AI 结论必须带失效条件与有效期；过期信号自动失效并通知。
- Auditor 审计结果只写记忆与评估，**禁止自动修改核心交易规则**（需人工确认）。

## 4. 数据质量联动

`quality ∈ {low, stale, invalid}` 的数据：AI 分析默认禁用、回测禁用、
前端必须展示风险标识（QualityBadge）。评分系统对数据质量降级自动扣分并降低置信度。

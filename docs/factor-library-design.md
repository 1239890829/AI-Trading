# 因子库建设方案（Factor Library Design）

> 定位：把散落在 11+ 个模块里的「准因子」收拢为**唯一口径、评估准入、可验证**的因子库。
> 状态：**P0 评估闭环已实施（2026-09-07）**，P1/P2 待做（见 §6）。
> 数据事实全部为 2026-09-07 午后实测（marketdb 直查），非推演。

**全仓无「因子库」概念**（grep 验证：`alpha` 零命中；`factor` 命中全部是 `session_factory` / 系数参数 / 回测统计的 profit_factor）。但存在四类相关资产：

### 1.1 数据底座（已就绪）
marketdb DuckDB（`backend/data/marketdb/market.duckdb`，不入 git）：
- **1023.8 万行 / 5555 只 / 2016-09-05 → 2026-09-03**（10 年），最新截面 5549 只；

### 1.3 评估方法论基建（可复用）
- `picks/backtest.py`：**事件研究范式**（前瞻收益 fwd + 触发/未触发基线对比 + 样本 ≥120 日防过拟合 + 「报告给建议不自动回写」）；
- `market/walkforward.py`：walk-forward 多窗验证（anchored 切窗、防泄露、参数稳定性）；
- `docs/backtest-rules.md`：代码级防泄露禁令（时点数据、幸存者偏差、T+1 撮合、一字板禁成交）。

### 1.4 数据质量实测结论（评估边界）
- **幸存者偏差实锤**：最后交易日早于全库最新 90 天的股票 = **0 只** → dump 是「当前在市股票的全历史」，2016~2026 期间退市股完全不在库。影响：全期回测的多头端收益系统性**高估**（退市股多为长期输家）；对近期截面影响小。**全期结论必须带此标注，分年度看近 3 年更可信**。
- 复权口径：`daily_k_adj` 仅复权收盘（无复权开高低）→ 隔夜跳空/振幅类因子有除权污染风险，需过滤或标注；
- 无换手率（缺流通股本）、无 ST 标记、无行业分类（题材映射可部分替代）。

## 3. 必要性论证

### 3.1 五个现实痛点（全部有前科）
1. **无验证闭环**：tech_score 权重、竞价溢价阈值、分时信号权重全是拍的/抄的，从未回答「有没有预测力」；
2. **口径漂移**：涨停家数两口径、连板高度两口径、预取 dict key 错位的教训——因子库是唯一口径锚（一处定义，处处引用）；
3. **重复计算**：RPS 在 rps.py 与 tech_score v3 各走一遍；板块 streak 只在 board_flow 内部可见；
4. **数据孤岛**：四种存储形态（DuckDB/JSONL/JSON/SQLite 表）无统一截面概念，跨因子相关性/组合分析无法做；
5. **评估范式已现成但没人用**：picks/backtest 的事件研究只验证过「确认规则」一个复合信号。

### 3.2 业务场景与收益
| 场景 | 用法 | 收益 |
|---|---|---|
| 选股引擎 | tech_score v4：权重由 IC 校准替代硬编码；失效维度降权 | 评分可验证、防「假精准」 |
| 盘中 watcher | 因子作为确认/证伪规则的可量化输入（替代纯题材规则） | 规则可回测可调参 |
| 复盘归因 | 当日/当周涨跌的因子暴露归因（「跌在高低波动暴露」） | 复盘从叙事升级为归因 |
| 助手工具 | 「这只票当前因子画像」一键查询 | 决策解释力 |
| 告警引擎 | 因子阈值告警（如 amihud 异常升高=流动性恶化） | 提前风控 |
| 组合风控 | 持仓因子暴露监控（单因子集中度上限） | 风险显式化 |
| 助手 LLM | 评估报告作为结构化上下文注入 | 减少幻觉 |

### 3.3 结合方向（用户提出 3 项 + 补充 7 项）
用户提出：①快讯（events/chains 方向因子，与 A 类量价因子做相关性交叉验证）；②时事新闻（现仅有东财快讯 101/102 频道，缺题材新闻源——列为数据源待补项）；③盘中异动（speed_sampler 异动密度因子）。

补充：④**板块资金流交叉确认**（个股动量 × 所属板块 streak 的交互因子，board_flow 60 日后可做）；⑤**情绪 regime 条件化**（regime.py 先例：退潮期动量/竞价溢价因子降权——因子暴露按情绪相位切换，比独立加因子更有价值）；⑥**宏观事件窗口**（nfp 日历 + 财报期 regime 内已有的日历——事件窗口内停用受扰因子）；⑦**龙虎榜席位因子**（dragon_service/longhu_trail 数据源已有）；⑧**竞价溢价验证**（auction_premium 已实现待验证——B/D 层积累后第一个受益者）；⑨**消费方挂载**（助手工具/告警/复盘归因/风控）；⑩**组合去重**（IC 相关 >0.7 的因子不重复入库，防同类堆叠）。

## 4. 准入标准（四维 + 一票否决，代码级实现于 evaluate.py）

| 维度 | 指标 | 过线标准 |
|---|---|---|
| **有效性** | RankIC 均值 / ICIR（前瞻 exec 口径 3/5/10/20 日） | 任一窗口 \|IC\|≥0.02 且 \|ICIR\|≥0.30 |
| **稳定性** | 分年度 IC 与全期同号占比；参数窗口敏感性 | 同号年份占比 ≥60% |
| **分层单调** | 五分位组 Q1..Q5 年化收益；Q1−Q5 多空差 | 多空差与 IC 同号且年化 ≥3%，单调组 ≥4/5 |
| **数据质量** | 截面覆盖率 | ≥90% |
| **去重** | 与已入库因子 IC 序列相关 | \|corr\| < 0.70 |
| **一票否决** | 未来函数 / 幸存者偏差未标注 / 口径不可复现 | 代码级校验，违反即 FAIL |

**三层判定**（三态纪律）：PASS（全过）→ 进库；CONDITIONAL（有效+稳定过、分层弱）→ 仅辅助维度；FAIL → 淘汰并留档（负 IC 本身是信息：如 A 股短期反转效应）。

**前瞻口径（防泄露）**：signal at T 收盘 → entry **T+1 收盘**（保守，剔除隔夜跳空虚增；`daily_k_adj` 无复权开盘的硬约束下最诚实）→ exit T+h 收盘，h∈{3,5,10,20}；另算 close 口径（T 收盘进）仅作隔夜损耗对比。一字板（T+1 high=low）样本剔除（买不进）。

## 5. 架构（P0 落地形态）

```
backend/app/factors/
├── __init__.py
├── library.py      # 因子注册表：名称/SQL定义/类别/窗口/最小样本（唯一口径锚）
├── evaluate.py     # 评估引擎：全 DuckDB SQL（RankIC/分层/分年/覆盖率/相关矩阵）+ 三层判定
└── (P1: daily.py 每日截面计算 + factor_values 落库；P2: 事件/盘中因子)
backend/scripts/run_factor_eval.py   # 跑批 CLI → backend/data/factors/eval_report.json
backend/tests/test_factors.py        # 合成小仓验证（三态/防泄露/分层单调）
```
设计约束：纯 DuckDB SQL 向量化（1025 万行全量评估分钟级，性能红线）；无 pandas 依赖（backend venv 硬约束）；缺失=NULL 三态（次新/停牌/除权污染不凑数）；评估是离线批任务，不在请求路径上。

## 7. P0 评估结果（2026-09-07 跑批，报告 `backend/data/factors/eval_report.json`）

**universe**：5555 只 / 2016-09-05 ~ 2026-09-03 / 全市场日截面均值 ~5400。11 因子全量 RankIC 评估（DuckDB 全表窗口函数，3m49s）。

| 因子 | 类别 | 主窗 | RankIC | ICIR | 分年同号 | 多空年化 | 覆盖 | 判定 |
|---|---|---|---|---|---|---|---|---|
| liq20 | 流动性 | 20日 | **-0.091** | **-0.59** | 1.0 | -448% | 99% | **PASS** |
| vola20 | 波动 | 20日 | **-0.093** | **-0.52** | 1.0 | -198% | 99% | **PASS** |
| range20 | 价格结构 | 20日 | -0.093 | -0.49 | 1.0 | -150% | 99% | **PASS**（与 vola20 冗余） |
| mom20 | 动量 | 20日 | -0.065 | -0.44 | 1.0 | -286% | 99% | **PASS** |
| mom60 | 动量 | 20日 | -0.059 | -0.37 | 1.0 | -230% | 98% | **PASS** |
| amihud20 | 流动性 | 20日 | +0.054 | +0.34 | 0.9 | +376% | 99% | **PASS**（与 liq20 冗余） |
| gap | 价格结构 | 20日 | +0.022 | +0.32 | 1.0 | +121% | 100% | **PASS** |
| mom10 | 动量 | 20日 | -0.049 | -0.36 | 1.0 | -217% | 99% | CONDITIONAL（与 mom20 冗余） |
| amt_ratio | 量价 | 20日 | -0.030 | -0.34 | 1.0 | -130% | 99% | CONDITIONAL（与 mom10 冗余） |
| mom5 | 动量 | 20日 | -0.033 | -0.26 | 1.0 | -165% | 100% | FAIL（ICIR < 0.30） |
| mom120 | 动量 | 20日 | -0.046 | -0.29 | 0.9 | -181% | 96% | FAIL（ICIR < 0.30） |

**解读（数据事实 → 可用结论）**：
1. **负 IC 全线** = A 股经典三效应实测复现：短期**反转**（20 日动量负预测）、**低波动异象**（vola20/range20 负）、**流动性溢价**（liq20 负 / amihud20 正）。因子方向取反即是多头侧信号（做多低波动、低拥挤、弱动量组）——tech_score 现行「强势区给高分」的 RSI/KDJ 维与 20 日反转效应方向相反，P1 校准时必须正视。
2. **多空年化是 Q5−Q1 对冲口径**，A 股融券受限，数字仅作因子强度参考，不代表单边可实现收益。
3. **分年同号占比 0.9~1.0**（11 个年度切片，含 2016 熔断/2018 熊市/2024-2026 行情）——稳定性远超预期下限；幸存者偏差（§1.4）主要高估多头端绝对收益，对 IC 符号/排序类结论影响有限。
4. **冗余结构清晰**：动量族（mom10/20/60）、流动性族（liq20/amihud20）、波动族（vola20/range20）各为同信源——P1 组合构建时每族按 |ICIR| 择优（liq20 / vola20 / mom20），族间组合前先查相关矩阵。
5. 所有因子主窗口均为 20 日前瞻：IC 绝对值随窗口拉长单调增大（短窗口噪声占比高），与截面因子文献一致；3 日窗口无任何因子过线，**日内/隔夜超短逻辑不适用本因子集**。

**首批因子库目录（9 个入册）**：liq20、vola20、range20、mom20、mom60、amihud20、gap（PASS）+ mom10、amt_ratio（CONDITIONAL，辅助维度）。淘汰留档：mom5、mom120（负 IC 亦是信息：5 日与 120 日窗口反转不稳定）。

## 2. 资金流三级重构（fund-flow-redesign）—— **P0 已实施，P1/P2 未做**

**体系**：大盘 → 板块/题材 → 个股 三级；打通板块监控 / 选股器 / 自选 / 个股详情 / 预警 / 策略信号。

**P0 已实施（2026-09-07）**：
- `board_flow.py` 服务 + 3 端点（`/market/board-fund-flow*`）
- 落盘 `data/boardflow/daily.json` + `daykline.json`
- fund-tab 三段式（①②③）+ R1 命名统一 + R2 `kline-chart.tsx` 下线

**实施偏差（口径须知）**：
1. 成员/日度沉淀深度取 Top20/kind，保留 60 交易日（控文件体积）
2. 龙头股列**仅名称**（成员净额在抽屉）
3. 5d/10d 用官方字段 `f164`/`f174`（实测 = 今日 `f62` + 近 N−1 完成日 bar，偏差 0.00 亿）；**20 日区间与连续流入走落盘自算**（读路径零外呼）

**P1/P2 未实施（保留待办）**：题材徽标 / watcher / alert / tech_score v4 流转项。
（**更正 2026-09-11**：其中「助手工具」已于 09-08 P0-3 落地、09-11 扩容至 **26 个只读工具**
并修掉「提示词自我否认」——明细见 [[KB-ENG-49]] 与 `docs/retro-and-gaps.md` §六。）

## 3. 热点消息管道（hotspot-pipeline-design）—— **P0 已实施**

**三段能力对标**：捕获 → 传导 → 映射验证。

**P0 已实施（2026-09-07 午前，commit c84d382）**：
- G1 快讯流：`news/flash.py` 双域 failover → `build_event` 指纹去重入 EventStore；**盘中 15s / 盘外 60s**
- G2 等后续环节按文档口径落地

**实施口径差异（已在代码/测试锚定）**：
- 链目标用**官方目录实名**：钾肥→「化肥」、电力→「绿色电力」、电网→「智能电网」、算力→「东数西算(算力)」
- 非农方向 P0 按标题意外词二分（超预期 → −1 / 不及预期 → +1 / 无词 → 显式 0）；**意外差量化投票留 P1**

> 原始盘点为 2026-09-07 晨东财接口实测（备域 push2delay），四条标题过 `events/extract.py` 的输出为真实运行结果而非推演。

**已落地**：判定状态机（judged / pending → 6h 收敛 neutral / 半衰期 expired）、方向抽取（题材目录匹配 + 方向词典 + 传导链）、**时区统一北京时间**（2026-09-09 修复：此前 published_at 存 UTC 导致展示早 8 小时）、事件 Tab 可点弹窗、`summary` 字段采集与存量回填。

**待办（⏳ 保留）**：
1. 写入盘前简报 `directions` 或单独晨报卡片（与现有「盘前三方向」合并去重）

3. 「个股名→题材」映射（公司快讯无 `source_symbol`、标题无题材词 → 需映射表或 LLM 增强）

## 2. 复盘策略增量原则（review-strategy-update-2026-09-02）

- **原则：增量迭代**——不新增任何数据生产（不建表、不加采集、不加页面）。
- 含"数据正确性修复"（影响复盘历史结论可信度）。

### ⚠️ 最重要的一条复盘教训（**跨文档通用**）
> **`data_issue` 归因若不主动查数据链，永远是复盘盲区**——界面照常、HTTP 200、结论却是错的。
> 四类静默失败实证：兜底不可达 / 字段全错 / 空结果计入熔断 / 披露语义死代码。
> 排查路径：`GET /api/system/providers` 三看——①当日是否有 breaker open 或切换记录（有则追问"哪些结论建立在降级数据上"）②`ths_sentinel` 状态 ③数据新鲜度。

## 4. 板块资金页口径核对（board-fund-page-audit-20260910）

- **结论：与同花顺"对不上"是双源体系差异，不是 bug。**
- 页面数据 = 东财板块接口（涨跌幅取官方 `f3`、净流入取官方 `f62`，**非自算**）；同花顺 App = 同花顺/申万板块体系 → 命名/粒度/成分股全不同（例：东财把"煤炭"拆为 煤炭/动力煤/煤炭开采 三个）。
- 叠加因素：页面默认「概念 + 净流入」榜，而 App 默认「涨幅榜」——观感差异被放大。
- 改造已上线：列表→**卡片瀑布流**（双列）+ **滚动增量分页**（首屏 30 滚底 +30）。

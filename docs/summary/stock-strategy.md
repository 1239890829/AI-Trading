| 4 | 追涨·潜伏·退潮·买点 | `intraday_rules.py` + `dragon_service.entry_checklist`（buy_point 五因素） | 已落地 |
| 5 | 复盘与回测迭代 | replay 体系 + 归因×胜率 | ✅ 09-02 |

### 三条不可丢的设计原则（**红线级**）
1. **规则必须是纯函数**——调度/取数/分发在服务层，**线上与回测共用同一套规则**；否则"回测通过的规则"与"线上跑的规则"必然漂移。
2. 红线：不真实下单；缺数据显式 `unknown` 绝不猜；**阈值集中成常量表**（回测后可调）；所有提醒标注"非投资建议"。
3. 回放数据可达性：板块涨幅/成交额走 ths 官方板块 K；情绪指标 `metric_history`（120→250 天可扩）；个股日 K 用于 T+1/T+3 收益回算。

## 2. 每日精选 × 盘中融合评估（来源：picks-intraday-fusion-assessment-2026-09-04）

**核心结论：融合方向正确，但重心必须从「盘中帮选股」纠偏为「盘中管执行与退出」。**

| 要点 | 内容（数据支撑） |
|---|---|
| 执行闸门（P0-A） | 09:25 竞价 gap 三态判定 + 推送卡片「执行状态」字段 + 影子下单受闸门约束；**胜率 12% 的桶直接禁掉**（改动小、数据支撑最强） |
| 影子持仓 | shadow 持仓连续 N 日（建议 N=10）跑赢"空仓基准"超阈值 → 复盘提示"gate 可能过严"，**只提示不改行为**（防自指） |
| 出场频率 | 60s（防噪声，QuoteHub 1s 有余量） |
| 分钟决策库（P2-E） | 影子每笔盘中判定落 `minute_decisions`，攒 3 个月后评估分钟级回测（分钟级历史不可回填 → 只能前瞻积累） |
| 复盘闭环 | 每日复盘 picks 维度新增 `shadow` 小节（影子成交/浮动盈亏/与真实决策偏离原因） |

## 3. 止盈档位设计（来源：picks-take-profit-design）

**需求**：日内冲高 ≥3% 减半仓，做成独立可选档位。

| 决策 | 结论 |
|---|---|
| 挂载点 | **watcher 侧新增 tracker**，不扩 AlertEngine（后者缺"组合语义 / 当日一次跨日重置 / 衔接出场纪律"三项能力，而 watcher 全有） |
| 位置 | `watcher_loop` 内与 `IntradayWatcher` 并列（**不塞进 DirectionTracker**——那是题材方向语义，这是标的级纪律） |
| 标的池 | 当日每日精选组合 ∪ 盘前简报方向池（去重，上限 10 只）；备选：仅组合成员（更聚焦） |
| 触发口径 | `当日涨跌幅 ≥ 3%`（默认，env 可调）；口径 = 相对昨收，**直接取腾讯快照字段，无自算误差** |
| 去重 | alert key = `take-profit:{trade_date}:{symbol}` → `append_alert` 天然"当日一次" |

**落地状态**：✅ **已实现——但不是按本文档的原设计**（2026-09-14 `GOV-002` 复核）。
实际做法 = **复用 09-09 已落地的 `picks/exit_engine.py` 挂载点**，未新建 tracker
（避免两套并行实现 + 两套去重状态）；口径 = 快照 `change_pct` ≥ 阈值（无自算误差）、**封板不触发**、
**未持仓只记录、不给卖出指令**（守红线 3）。账本原记 `P0-1`。**标的池范围拍板点**随实现一并收敛。

## 4. 回测基线（来源：2 份回测报告，均已归档）

| 项 | 120 日窗口 | 200 日窗口 |
|---|---|---|
| 区间 | 2026-03-10 ~ 09-01 | 2025-11-06 ~ 09-01 |
| 样本 | 360 条（交易日 × top3 题材） | 600 条 |
| 协议 | T-1 题材 top3 → 确认规则 → **T+1 开盘买、T+3 收盘卖**（板块指数口径） | 同 |

**诚实降级（口径必须随结论一起引用）**：
- phase 不回放（需全市场快照历史）→ 退潮/冰点否决测不到，环境项仅由 promo 分位判定
- 题材→ths 板块匹配失败 45 / 67 条；板块 K 线缺当日 63 / 112 条 → confirm 仍跑但收益不计入
- 业绩/财报结果型题材已从伪预判 top3 剔除（无对应板块会占坑）

**网格结果**：120 日 1.0/1.3 触发 6 次胜率 50%（超额 -0.09%）；200 日 1.0/1.3 触发 7 次胜率 42.9%（超额 -0.57%）；1.5 量比线两窗口均只触发 1 次。

> ⚠️ **最重要的结论是"样本过小"**：触发数普遍 0–7 次，**不足以支撑调参**；跨窗口/跨口径不可相加比较。两窗口唯一一致的信号是"高量比线触发极少"。

# 复盘执行框架（Review Framework v1.0）

> 定位：**LLM 复盘 SOP**——任何「分析某市场现象/案例/走势」的请求，必须按本框架逐步执行，禁止跳步、禁止先下结论再找证据。
> 建库：2026-09-09（首版框架在百大集团案例复盘实践中提炼）。本文自身进入自优化循环（§6）。
> 消费方：LLM 会话复盘、15:45 进化议程（复盘类任务时读取本框架作为 SOP 前缀）、元评估周报（检查本框架的执行偏差）。

## 0. 适用范围与硬约束

- **触发**：用户要求复盘/分析某只票、某类走势、某个市场现象；或议程判定「本轮出现值得归因的异常」。
- **硬约束**（违反任何一条=本轮复盘作废）：
  1. 时间必须 `date` 实测（KB-TRADE-01），跨日先验交易日（KB-TRADE-02）。
  2. 数据三态纪律：拿不到的数据显式标注「未判定/缺失」，禁止臆造补齐（KB-TRADE-05）。
  3. 结论必须挂数据：每个成因判断至少一条实测数据支撑；无数据的判断必须标注「假设，待验证」。
  4. 口径注明：家数、换手、连板数等必须标注来源（ths/东财口径不同不可混算，KB-TRADE-07）。

## 1. 阶段流水（七阶段，串行不可跳）

### 阶段 0｜定界
- 复盘对象是什么（票/现象/策略）？时间窗？用户想回答什么问题？
- 输出：一句话「复盘命题」+ 时间窗 + 成功标准（回答了什么才算完成）。

### 阶段 1｜事实链构建（先数据后观点）
四源数据逐项拉取，拉不到的标 `--`：
- **量价源**：日K（OHLC/换手率/成交量）——板型判定（一字/T字/放量板）、换手率序列。
- **情绪源**：涨停家数、最高板、连板分布、炸板池——定位情绪周期位置。
- **资金源**：龙虎榜（净买/游资净额/机构净额/人气排名）——接力结构。
- **消息源**：涨停原因、概念标签、公告——题材锚与证伪周期。
- 产出：事实表（每行=日期+多列指标），**禁止在此阶段写任何结论**。

### 阶段 2｜周期定位
- 该案例发生在情绪周期的哪个位置（高潮/退潮/冰点/修复）？依据=涨停家数+最高板序列。
- 市场环境对照：主流方向（如科技）量价是缩是放？有无资金迁移迹象？
- 产出：周期位置判定 + 一句「该位置对该案例的约束」。

### 阶段 3｜六维成因剖析
对每个维度给出「实测数据 → 机理判断」：
1. **量能**：缩量/放量的语义（KB-STOCK-24：缩量=抛压真空而非无人问津）；板型节奏。
2. **环境**：资金真空/迁移；题材正当性（政策方向、证伪周期）。
3. **情绪**：启动时点与周期位置的组合（冰点首板=争旗帜；高位首板=接飞刀）。
4. **资金**：接力结构（老出新接=健康；一路对倒=警惕）；一致性演化。
5. **标的属性**：低位/小盘/无机构/低价/题材慢变量/隐藏叙事——逐项打勾。
6. **主观博弈**：主要资金在每一步的期望值计算（胜率×赔率×成本）。
- 每维产出：证据（数据引用）+ 判断 + 置信（高/中/低）。

### 阶段 4｜规律提炼（可证伪化）
- 从六维判断中提炼 **if-then 规则**，每条必须含：
  - 触发条件（量化，如「涨停家数<50 且最高板≤5」）
  - 结论/动作（如「次日最高优先级关注」）
  - 适用边界（什么情况下不成立）
  - **验证状态**：未验证 / 本案例 1 次 / N 次验证 / 失效
- 禁止提炼不可证伪的规律（如「主力有实力」这类废话不配上库）。

### 阶段 5｜与知识库对照
- grep 本 KB（`grep -rn 关键词 docs/kb/`）找：印证（补证据）/ 冲突（**必须显式 ⚠️ 双向指向，不得静默覆盖**，00-INDEX 规则 3）/ 补位（新条目）。
- 新知识当轮入库：写 KB-ID 条目 + 更新 00-INDEX 表格 + 状态与关联。

### 阶段 6｜反例自检（防过度拟合，必做）
逐项回答：
- [ ] 单案例还是多案例？单案例的结论是否标注「待验证」？
- [ ] 是否存在事后归因（用结果倒推原因）？——检查：同样的数据组合在**当时**（事前视角）能否推出同样结论？
- [ ] 存活者偏差：同期同类起点有多少失败案例？（如冰点日 35 家首板多数没走出来）
- [ ] 失效条件：什么信号出现时该规律作废？
- [ ] 下一张验证票是什么？（具体到日期/事件）

### 阶段 7｜入库、自评与闭环
- 入库（KB-ID）+ 00-INDEX 登记 + daily log 一行指针。
- **自评**（六维 0-10 分）并写入文档尾部「自评表」：

| 维度 | 评分依据 | 本轮分 |
|---|---|---|
| 数据完备 | 四源是否齐、缺失是否显式 | /10 |
| 因果深度 | 是否到机理层而非现象层 | /10 |
| 可证伪性 | 规律是否量化可验证 | /10 |
| 知识融合 | 与旧 KB 对照是否充分、冲突是否显式 | /10 |
| 反例自检 | §6 五问是否诚实回答 | /10 |
| 可执行性 | 结论能否转化为系统动作/选股权重 | /10 |

- **闭环规则**：任一维度 <6 分 → 在「框架演化日志」（§7）登记改进项，**下一轮复盘必须先执行该改进再开始**；连续 2 轮同一维度低分 → 升级为议程 C 类改进项（代码/流程修正）。

## 附录 A：外部视角参考 —— 五层提问框架（**非权威，仅拓宽视角**）

> **定位（2026-09-10 用户明确）**：从「他人某一天复盘笔记」反推的**参考输入**，用于拓宽分析视角、丰富决策依据。
> **不是**替代既有体系的标准，**不是**供生搬硬套的模板。**唯一权威 = 本知识库 KB-STOCK/TRADE/ENG/DEC 条目 + 实测数据**；冲突时以 KB 条目为准，本文观点视为**待验证新视角**。
> 原文档 `docs/review-methodology-20260910.md` 已删除，精华即本节；案例原文见 `docs/daily-review/2026-09-09-trading-memo.md`。

**核心思想**：复盘 = 固定顺序的提问，不是总结涨跌。

```
今天是什么盘（大盘+情绪） → 谁真强 → 强中谁是主线、走到哪个阶段
  → 钱实际选了谁（资金验证） → 因此我做/回避/等什么信号（预案挂触发与证伪）
```

| 层 | 核心问题 | 证据 | 关键判别 |
|---|---|---|---|
| ① 定盘性 | 资金进攻还是防守？存量还是增量？ | 涨跌家数 / 两市量能 / 连板高度与接力成功率 | 先判「能不能做」再判「做什么」；普跌+主线没死 = 只做主线内，低吸优于追涨 |
| ② 辨强弱 | 谁走强？真强假强？强完有预期吗？ | 逆势走强 / 分歧日承接 / 高开低走 vs 平开高走 / 量价配合 | **真强 = 别人跌它不跌 + 有人砸有人接 + 位置不高**；假强 = 高开低走 / 一日游 / 无量涨停。弱市里「高开低走」≈负面标签 |
| ③ 立主线 | 孤票还是板块？逻辑闭环？哪个阶段？ | 板块效应（梯队）/ 逻辑闭环（可沿产业链传导）/ 资金验证 | **良性分歧 ≠ 终结；高潮日 = 结束信号；反抽 ≠ 第二波**。给最强方向**定级**（主线/分支/补涨/反抽），不同级别不同打法 |
| ④ 跟资金 | 钱去了哪？从哪来、往哪扩散？ | 板块/个股净流入 / 涨停分布（最多最先封最稳）/ 谁被砸了还有人接 | 依据是「哪里成片涨且有人接力」，不是单条新闻。**散户看消息，高手看消息出来之后谁在买** |
| ⑤ 出预案 | 做什么 / 不做什么 / 等什么 | 三分类清单 | **预案不是预测**——「如果 A 则做 B」的条件句；**每个方向必须挂证伪条件**；盘后对照沉淀成下一轮证据 |

**底层心法（可背）**：弱市里 **逆势走强 > 涨幅靠前**、**承接 > 封板**、**低吸 > 追高**；主线上 **分歧是机会，高潮是风险**；选方向上 **先有板块效应再谈个股，先有逻辑闭环再谈持续**。

**陌生题材强制三步**：①查逻辑链条（利好产业链哪一环）②查资金验证（涨停是否成片、次日承接）③查位置（低位第一次共振才值得当主线候选）。**禁止抄代码。**

**纪律四条**：学提问不学答案 / 产出是假设不是预测 / 证据只认盘面痕迹 / 先板块后个股、先逻辑后代码。

> 检验是否学会：**不再问「他买了什么」，而是拿到同样盘面数据能问出同样的问题、排出同样的优先级。**

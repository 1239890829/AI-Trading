### KB-DEC-001 飞书推送矩阵四类 + 每日唯一总结报告
- **日期**：2026-09-08 定稿；09-09 automation 收敛落地。
- **决策**：飞书推送分四类优先级——CRITICAL 买点卡（盘中实时）＞ ANOMALY 系统异常（哨兵，状态变化才推）＞ REPORT 复盘完成（每日一条）＞ SILENT 其余一律 in_app。**用户每天最多收到一条主动消息（15:45 进化总结报告，what/why/how 三段式）**。
- **代价**：盘中不含情绪/题材提醒（进站内通知中心）。
- **重议条件**：用户主动要求恢复盘中推送。

### KB-DEC-002 告警判读即终态
- **日期**：2026-09-08（用户指令「触发记录状态不再需要确认」）。
- **决策**：LLM 判读落库时事件自动 acknowledged=1；无人工确认环节；前端只读展示。
- **依据**：确认动作是纯摩擦——判读结果（notify/ignore/escalate）本身就是处置。

### KB-DEC-003 进化议程 A/B/C 三类自动执行 + 红线清单
- **日期**：2026-09-08。

### KB-DEC-004 A 类参数影子运行→剧变检测→转正/拒绝
- **日期**：2026-09-08（用户指令「新策略需经数据验证有效后方可启用」）。
- **决策**：A 类参数变更不直接生效——入影子队列（不写运行时覆盖层）；每日评估逐相位权重 L1 漂移（≤0.25）+ 维度灭声（≥0.05）；温和→转正（真生效+30 日劣化回滚实验），剧变→拒绝归档。
- **诚实边界**：影子回答「会不会一步改出极端权重」，效果验证由转正后 30 日实验承担——不冒充。

### KB-DEC-006 策略改动回放对比硬门禁
- **日期**：2026-09-08（用户指令「选股策略调整必须以历史回测为依据，杜绝凭主观经验拍板」）。
- **决策**：picks/ 相关 C 类合入后自动跑 10 交易日回放 vs 基线（data/replay_baseline.json），量化换手/持有/组合分 deltas；degraded 进下轮议程复评。**口径诚实注记：回放只覆盖梯队+技术两维**。

### KB-DEC-008 盘中跟踪量化门槛 ⚠️ 已被 KB-DEC-011 部分修订
- **日期**：2026-09-09（用户反馈「跟踪过多且缺乏依据」）。

### KB-DEC-011 临板预警制：涨停前识别才准入，封板后一律不入册
- **日期**：2026-09-09（用户指令：不要等涨停才加入跟踪；只有涨停前已提醒过的才允许入册）。
- **决策**：
  1. **临板雷达**（`app/picks/pre_limit_radar.py`）：交易时段（含竞价尾段 09:20 起）每 6s 扫全市场快照，按板性缩放临板区——10cm [6.5, 9.7) / 20cm [13.0, 19.7) / ST [3.2, 4.7) / 北交所 [19.5, 29.7)
  2. 新进临板区 → **先登记**（layer=pre_limit，入场价=临板价）→ **再提醒**（规则直发通知中心，不经 LLM 判读零延迟）
  3. **封板后才发现的一律不入册**：机会候选路径、watcher/买点路径登记前统一查封板态（无行情佐证也不入册）
  4. 炸板回落临板区 = 新的涨停前信号（此前从未提醒过）→ 允许预警入册
  5. 当日幂等以台账首见唯一为准（重启安全）；快照新鲜度 120s 守卫防陈旧误报
- **取代**：KB-DEC-008 的 boards≥1 准入分支。

### KB-DEC-012 仓位引擎 + 自动离场（闭环「持仓/离场」段）
- **日期**：2026-09-09（用户指令：选股—验证—持仓—离场—进化闭环）。
- **决策**：①盘中触发（买点/confirm）只回答「到价」，**开不开、开多大**由仓位引擎按市场阶段统一裁定（发酵 65%/2 · 修复 55%/2 · 高潮 45%/2 · 分歧 35%/2 · 退潮 15%/1 · 冰点 10%/1；闸门 strong→0、mild→减半）；角色权重 龙头 55%/中军 40%/其余 30%；最多 2 只（稳定核）。②模拟仓自动开/自动卖；**真实持仓只发 CRITICAL 级离场提醒**（推送矩阵修订：与买点卡同级——等不起日报），用户确认卖出删流水后标签自动消失。③离场规则：封板持有（不早止盈）/角色化硬止损（龙头 8%·中军 6%·其余 5.5%）/峰值武装移动止盈（龙头 +15% 武装回撤 8%）/弱转强波浪提醒持有。④决策与峰值轨迹落 data/position_plans/ 台账化。
- **关联**：[[KB-STOCK-19]] [[KB-STOCK-07]] [[KB-TRADE-11]]

## 一、题材扩散与接力（案例层 · 📎 示例库，非判定标准）

> **本层定位（2026-09-10 依 [[KB-DEC-019]] 反固化条款校正）**：本层是**示例库**——回答「题材**可能**怎么扩散」，
> 供理解与类比。**可迁移的只有一条逻辑**：*题材炒作常沿产业链纵深发散，材料端/上游常是第二波主战场*
> （该逻辑由 [[KB-STOCK-05]] 与扩散模型承载）。
> **本层里出现的具体题材名（厄尔尼诺 / PCB / CPO / 半导体）不是规则**——题材会不断衍生出千万个，
> 写死的题材名既不能预测下一个热点、也不构成任何入场依据。**禁止把本节案例直接当判据引用。**

### KB-STOCK-01 厄尔尼诺→农业链炒作 📎
- **状态**：📎 **题材示例**（非判定标准；[[KB-DEC-019]] 反固化条款）。
- **来源**：用户亲述案例「厄尔尼诺行情炒粮食股」（09-09 复盘指令正式引用，此前多次提及）。
- **内容**：气候异象（厄尔尼诺）→ 农产品涨价预期 → 炒作顺序沿产业链传导：**化肥 → 种业 → 粮食 → 代糖**。
- **观察记录（⚠️ 非验证结论）**：2026-09-09 单日全链涨停。**这是"单日 + 单案例"观察**，
  且与本文件 KB-STOCK-02 的"同日复刻"是同一天同一件事，**只算 1 个证据**，不构成规律验证。
  ⚠️ 连带：`events/chains.py` 把本条写成带强度值的传导链（化肥/种植=2 > 电力=1），
  该"弹性排序"**属未验证印象**，已就地标注（[[KB-ENG-40]]）。
- **🔴 已实测：该「弹性排序」在数据上得不到支持（2026-09-11，P1-22 同期工作）**。
  `scripts/verify_climate_chain.py` 用 NOAA ONI 月表 × 申万一级行业月超额做了月频检验
  （2000-01 ~ 2026-09，**import 生产 `parse_oni`/`classify`** ⇒ 核验相位=线上相位）。
  **h=1 厄尔尼诺月均 − 中性月均**：基础化工（磷化工/化肥）**+0.170% vs +0.305%
  ⇒ t=−0.20、方向相反、分年度仅 2/8 同向**；农林牧渔 +0.492 vs +0.227（t=0.29，3/8）；
  公用事业 +0.959 vs −0.125（t=1.69，5/8，属**弱提示**）。
  **没有一条通过（t≥2 且分年度过半）**，基础化工还出现**方向性反证** ⇒
  「化肥弹性 > 种植 > 电力」**连方向都没站住，绝不可当结论引用**。
  样本本身小（44 个厄尔尼诺月，1950 至今约十余次事件）⇒ 准确表述是「**未获支持**」
  而非「已证伪」；月频重叠季值 ⇒ 有效样本远小于 44。
  ⇒ 由此产生的**结构性结论**：气候源的价值在**「相位」本身**（观测量，比新闻早一步拿到
  确定性），人工传导链只作**可解释性材料**保留，每处输出**必带 `empirical_verdict`**
  （见 `app/market/climate.py` 与 P1-32 落地记录）。
- **真正可迁移的部分**：「产业链纵深扩散」这一逻辑本身（见 [[KB-STOCK-02]] [[KB-STOCK-05]]）；
  具体题材名与排序**不进入任何选股规则**。
- **系统落地**：时事新闻→题材映射（通知中心 + 议程第七路）✅；台账归因记录「时事新闻」类。
- **关联**：[[KB-STOCK-02]] [[KB-STOCK-05]] [[KB-STOCK-09]] [[KB-DEC-019]]

### KB-STOCK-02 PCB 向材料端发散 📎
- **状态**：📎 **题材示例**（本层唯一可迁移逻辑的载体：产业链纵深扩散）。
- **来源**：用户亲述案例「PCB 概念向材料端发散炒作」。
- **内容**：题材炒作不停在整机/模块层，会沿产业链**向材料端纵深发散**——材料端是第二波主战场。
- **观察记录（⚠️ 非验证结论）**：09-09 光通信链同日复刻该模式（光模块 → 光纤/耦合 → 材料 → 电缆）。
  与 KB-STOCK-01 同日 → 同一证据，**不可叠加计数**。
- **系统落地**：扩散模型设计（组合策略 §5）；题材内候选按产业链位置分层。
- **失效条件**：本条可迁移的**只有「产业链纵深扩散」这一逻辑形态**（具体题材名与顺序不可迁移）。
  ⚠️ 而连这个形态本身也**尚未经本地数据验证**——同族的「弹性排序」在 [[KB-STOCK-01]] 的月频检验中
  未获支持（化肥/种植/电力无一通过 t≥2 且分年度过半）⇒ 传播强度排序**不得**当判据。
  若后续样本中「材料端是第二波主战场」不再复现，本条应整体降级为**纯案例**，
  连「可解释性材料」的地位都要重新评估。
- **关联**：[[KB-STOCK-01]] [[KB-STOCK-03]] [[KB-STOCK-04]] [[KB-STOCK-19]]

### KB-STOCK-05 先炒大票龙头，后炒细分补涨
- **来源**：用户亲述规律「先炒大票后炒细分」。
- **内容**：题材启动期资金先打大票（辨识度高、容量大），题材确认后向细分小票扩散补涨——**补涨阶段是散户胜率最高的窗口，也是风险开始积累的窗口**。
- **系统落地**：🔶 扩散顺序模型（组合策略）待实现；当前题材内排序（涨停置顶+涨幅降序）已部分体现。
- **失效条件**（**本条是用户经验，未经实测**）：①题材**没有大票载体**时（成分全是小市值），第一段不存在，顺序退化；
  ②**存量缩量 / 退潮期**资金不足以支撑两段结构，可能普涨一轮就结束；
  ③「补涨阶段胜率最高」是**印象而非实测**——它同时被描述为「风险开始积累的窗口」，
  两个方向都未量化，**不得作为加仓依据**。要转成判据需先做：按题材容量分层 + 记录「大票启动日 → 补涨日」
  的间隔与两段各自的市场中性超额。
- **关联**：[[KB-STOCK-01]] [[KB-STOCK-06]] [[KB-STOCK-19]]

### KB-STOCK-06 优秀交易员提前嗅到板块机会
- **来源**：用户亲述「优秀交易员如何提前嗅到板块机会」。
- **内容**：板块整体启动前有先兆：零星首板出现、消息面催化落地、相邻链涨停传导。**题材要等「成建制」证据才确认——这就是滞后的根源**。
- **验证**：09-09 滞后分层实测：T0 竞价板滞后 ~1min、T1 盘中板 1–2.5min、**T2 题材成建制滞后 10–27min（最大短板）**。
- **系统落地**：✅ **临板雷达**（09-09，`pre_limit_radar.py`：全市场快照 6s 扫描、板性缩放临板区、封板前预警+入册、规则直发零 LLM 延迟）；竞价即时通道/涨停池推送仍 ⏳。
- **失效条件**：①②要分开看。**「先兆三要素」（零星首板 / 消息催化 / 相邻链传导）是观察归纳**——
  三要素**任一单独出现都可能是噪声**，只有同时具备才够「成建制」；不得用其中一条就宣判板块要启动。
- **「滞后时长」是 09-09 单日实测值**（T0 竞价 ~1min / T1 盘中 1–2.5min / T2 题材成建制 10–27min）——
  单日单样本，且受当日行情节奏影响（普涨日会整体压缩、缩量日会拉长）。**换市场结构后须重测**，
  不可把它当固定常数写进任何阈值或告警口径。
- **关联**：[[KB-STOCK-07]] [[KB-TRADE-11]] [[KB-DEC-011]]

## 二、参与纪律（时机层）

### KB-STOCK-07 嗅到≠买入
- **来源**：用户指令「嗅到机会不等于买入，须结合盘面、量价、资金与指标验证通过后再给出买入提示」。
- **内容**：发现（感知层）与买入（执行层）严格分离；介入前须四重验证。
- **系统落地**：✅ 四档择时（空仓/观望/试仓/买入）+ 空仓闸门硬条件 + 台账「入选价 vs 收盘」验证闭环。
- **关联**：[[KB-STOCK-08]] [[KB-STOCK-11]]

### KB-STOCK-08 不可能一直空仓
- **来源**：用户指令「说明如何稳步提升胜率（不可能一直空仓）」。
- **内容**：纯空仓不是可接受常态——必须有低风险的参与档位（试仓），保证系统持续在场、持续积累可复盘样本。
- **系统落地**：✅ 四档择时含「试仓」档；空仓提示重新定义触发条件（当日已改）。
- **关联**：[[KB-STOCK-07]]

### KB-STOCK-09 消息面时效性
- **来源**：09-09 实战（厄尔尼诺新闻与糖业涨停潮同日出现）。
- **内容**：时事新闻→题材映射必须进盘前简报与盘中分析——新闻的题材指向有时效窗口，滞后即失效。
- **系统落地**：✅ 新闻评分过滤入通知中心 + 议程第七路（prediction 链）。
- **失效条件**：本条缺**量化窗口**——「时效」有多长（当日内 / T+1 / 跨周）从未定义，
  所以它只能用来排除**明显过期**的映射，不能用来判「还来得及」。
  另有一个反向的失效场景：消息**已被市场充分定价**时（例如题材已连板三天后才读到那条新闻），
  时效判定应让位于「是否已被消化」——此时「新闻新」不等于「机会新」。
- **关联**：[[KB-STOCK-01]] [[KB-STOCK-17]]

### KB-STOCK-11 竞价分带是龙头续命关键
- **来源**：用户确认（2026-09-01）。
- **内容**：龙头股竞价开盘位置打分：低开 -2 / 平开~+3% 0 / **+3~7% 标准接力 +2** / +7~8% 观察 / **>+8% 超高开抛压 -2**——竞价强弱直接决定龙头当日续命能力。
- **系统落地**：✅ `dragon_score` 竞价分带打分。
- **失效条件**：**分带阈值（-2 / 0 / +2 / 观察 / -2）是经验刻度，未见样本外回测**，
  本条目前只声称「竞价强弱影响当日续命能力」这个**方向**，不声称这几个边界值最优。
  两个已知的可能翻转场景：①**一字板 / 无分歧强势**下，超高开是**强度**而非抛压，
  此时判负会打反；②竞价机制若调整（时段、价格笼子、申报规则），分带需整体重标。
  要动这些数字，先按「分层 + 市场中性超额」做实测，不要凭手感调。
- **关联**：[[KB-STOCK-10]]

### KB-STOCK-12 接力溢价一票否决
- **来源**：用户确认（2026-08-29）。
- **内容**：赚钱效应可否决热度——题材热度再高，若昨日接力资金今日亏钱（溢价为负），直接落「观察」档，不参与。
- **系统落地**：✅ `strength_tier` 判定含接力溢价修正。
- **失效条件**：「溢价为负」必须**先扣掉同日市场 beta** 再判——见 [[KB-STOCK-30]] 的核心教训：
  带「顺大盘」成分的条件若不与同日全市场对照，会把市场级效应读成选股效应（反之亦然）。
  在**普涨 / 情绪高潮日**，全市场都在回落时某题材溢价为负，可能只是 beta 拖累而非题材转弱；
  在**恐慌日**，题材逆势为正也可能只是低 beta。**单看绝对溢价就一票否决 = 口径不全。**
  本条的实测支撑是单边逻辑，未做环境分层——分层后若否决方向不再稳健，应改为降档而非否决。
- **关联**：[[KB-STOCK-13]]

### KB-STOCK-14 放量破位不出低吸（不接飞刀）
- **来源**：用户确认（2026-08-30）。
- **内容**：放量破位与超卖同刻出现时，信号对冲——**不接飞刀是纪律**：此类标的落观察区是设计行为，不是漏报。
- **系统落地**：✅ 做T 引擎信号对冲逻辑。
- **失效条件**：本条的正当性是**「两信号冲突时不可判定 ⇒ 不动」，不是「这样做收益更高」**——
  它是纪律，拿不出、也不需要 alpha 证据。因此它的失效方式是：**出现了能判定优先级的证据**。
  若将来分层实测显示「放量破位的**幅度** + 超卖**深度** + 后续缩量收敛」的某个子集是正期望的，
  可以对该子集开口。⚠️ 但开口**必须先有实测**（照 [[KB-STOCK-29]] 的做法：规则化 → 事件驱动模拟
  → 对照同日全市场 → 分层检验 → 标可成交性），**不得凭个案印象放开**——
  那正是本条当初要拦的行为。
- **关联**：[[KB-STOCK-15]]

### KB-STOCK-15 做T 五指标权重
- **来源**：用户确认（2026-08-30）。
- **内容**：做T 信号五指标加权：**均价偏离 0.30 / 量价背离 0.25 / 量能突变 0.20 / 新高突破 0.15 / 换手进度 0.10**；2 年回测样本外胜率 0.662，无过拟合。
- **系统落地**：✅ 做T 引擎（backend/app/picks/）。
- **失效条件**：「样本外胜率 0.662、无过拟合」这个结论**绑定在当时的样本与市场状态上**，
  且未做环境分层（单边 / 震荡 / 退潮）。它证明的是「在该样本上不过拟合」，
  **不等于权重是全局最优**——权重是该样本内的最优点，换样本需重标。
  衰减的发现机制已存在（[[KB-STOCK-28]] 的滚动胜率告警 + 实验 30 日劣化守护）：
  一旦滚动胜率跌破阈值，本条应从「已落地」转为「待重标定」，而不是继续沿用旧权重。
- **关联**：[[KB-STOCK-14]]

### KB-STOCK-16 题材唯一归属

### KB-STOCK-22 弱转强波浪识别（二浪启动持有）
- **来源**：用户指令（2026-09-09 闭环需求 2）：识别走弱后第二、三天突然转强的走势（二浪、三浪、四浪），不能停留在选股阶段。
- **内容**：强势股首次转弱（昨收跌破成本/前低）后的**突然转强**是波浪结构信号——二浪启动点恰恰是加仓/持有依据而非离场点；三浪、四浪同理递推，结合量能与市场合力。
- **系统落地**：✅ 离场引擎弱转强检测（持仓 ≥1 夜 + 昨收<成本 + 今日 ≥+4% → 「二浪启动」提醒**持有**）；三浪/四浪递推判定 🔶 待实盘样本。
- **失效条件**：①判定条件里的 **「+4%」是阈值而非规律**——过松会把普通反弹误报成二浪（后果是**该走不走**，
  比漏报危险），过紧会漏掉真启动。当前三浪/四浪递推**尚无实盘样本**（🔶），所以它只配用来提醒
  「暂缓离场」，**不构成加仓依据**。②**波浪结构在无趋势的震荡市里不成立**——横盘区间内的
  「转强」多为区间反弹，此时弱转强信号应降到最弱。③「昨收 < 成本」锚在**个人成本**上，
  成本不同的两个持仓会得到不同结论 ⇒ 它是持仓管理工具，不是标的属性，不可写进选股条件。

### KB-STOCK-23 趋势转龙头连板的成因模型（百大集团案例，2026-09）
- **来源**：用户指令「分析百大集团这类个股由走趋势演变为龙头连板的成因」（2026-09-09）；完整实证：`docs/summary/stock-strategy.md`（全部结论有实测数据支撑）。
- **内容**：趋势票演变为龙头连板的六维成因与五条可循规律：
  - **成因六维**：①量能（-60% 超跌+6 周换手<2% 横盘=抛压真空；试盘+6.5% 冲高回落→缩量回踩不破位=确认）②环境（科技主线量价齐缩、资金池退潮→低位非科技方向获流动性再分配溢价）③情绪（**首板诞生于冰点**：涨停 44 家、旧高度 7→4-5 塌缩日——冰点首板在争夺「新周期空间板」旗帜，成功后反哺情绪修复 38→92 家共振）④资金（龙虎榜二板老游资兑现 -2343 万、三四板新主力各净买 ~5900 万=**老出新接健康接力**）⑤标的（低位+小盘 41 亿流通+无机构重仓+题材慢变量+低价六项全中）⑥博弈（龙头地位由二板巨量分歧回封 15.3% 换手确立，此后自我实现）。
  - **规律**：a) 试盘-回踩不破位是趋势转妖最后确认点；b) 冰点日低位放量首板=次日最高优先级（争旗帜）；c) 次日换手 15%+ 分歧仍回封=二板定妖；d) 连板中段换手逐日萎缩（15.3→4.7→1.1%）=惜售持有，**天量低开分歧（18.5%）=周期审判日，次日不回封则周期大概率结束**；e) 题材须「短期无法证伪+政策鼓励+想象可延伸」三要素。
  - **断板后走趋势再连板的本质**：趋势段完成筹码沉淀（以横盘代跌换手消化获利盘），连板段完成情绪定价——与「先趋势后连板」同构，只是顺序互换。
- **验证状态**：单案例归纳，规律 a-e 待 KB-TRADE-13 归因×胜率闭环多案例检验；**规律 d 的第一张验证票=百大 09-10 走向**。
- **系统落地**：🔶 规律 c/d 可接入临板雷达与离场引擎（天量分歧日检测）；情绪冰点定义（涨停<50+最高板≤5）可入 regime 相位判定。
- **失效条件**：**本条整体是单案例（百大集团）归纳，n=1**，六维成因与 a–e 五条规律**全部待多案例检验**
  （机制见 [[KB-TRADE-13]] 归因×胜率闭环）。三个具体的可证伪点，谁先到谁生效：
  ①**规律 d 的判决日就是该股 09-10 走向**——若「天量分歧次日不回封」后周期并未结束，规律 d 降级；
  ②**环境前提不可忽略**：案例发生在「科技主线退潮 + 低位非科技方向获流动性再分配」这一特定结构里，
  资金回到主线时同构形态不一定复现；③六维里的**资金档（龙虎榜净买额）依赖席位数据**，
  该源缺失时六维不完整 ⇒ 此时只能按「五维 + 标注缺失」，**不得用其他维度倒推补位**。
  ⚠️ 尤其注意：规律 a–e 读起来像操作手册，这正是它最危险的地方——**在检验完成前它是假设，不是打法**。

### KB-STOCK-24 缩量的正确语义：不是没人买，而是没人卖
- **来源**：用户观察「近期持续缩量」+ 百大案例实测（2026-09-09）。
- **内容**：超跌后长期缩量横盘（换手 <2%）的真实含义是**浮动筹码枯竭、抛压真空**——这是妖股启动的物理前提，而非「无人关注」的利空。此类标的放量突破时阻力最小。反向：连续放量滞涨/天量才是「筹码松动」信号。
- **主力悄然潜伏的可观测代理链**（2026-09-09 自检补充）：潜伏期无直接「大单/筹码」数据源时，用间接信号链观测——①缩量横盘时长（周级）②试盘（冲高 +5~7% 后回落）③回踩缩量不破位④首板当日量能（对比 5 日均量）。四步齐全才给「潜伏→启动」提示，缺任一步只作观察（宁缺毋滥，[[KB-TRADE-11]]）。
- **系统落地**：⏳ 选股权重可加「缩量横盘时长+换手分位」因子（结合 factors 库条件 IC 验证后启用）。
- **失效条件**：「缩量 = 抛压真空」**只在特定前提下成立**：**超跌 + 长期缩量横盘（换手 <2%）**。
  换一个位置，同一个「缩量」的语义就反了——**高位缩量**是没人接（流动性枯竭），
  **趋势中段缩量**可能是惜售，两者都不能套用本条。所以引用时必须带上「超跌 + 横盘」这两个前提，
  只写「缩量是好事」就是错的。
  ②四步代理链（缩量时长 → 试盘 → 回踩不破位 → 首板量能）是**间接观测**，
  **缺任一步只作观察**；其中任何一两步单独成立都**不足以**下「主力潜伏」结论——
  这是本条最容易被执行时放松的地方。
  ③因子化（⏳）须先过条件 IC 验证，未验证前不得进评分权重。
- **关联**：[[KB-STOCK-23]] [[KB-STOCK-14]]

### KB-STOCK-26 消息驱动选股的五段流水线：分级 → 映射 → 验证 → 情绪 → 推送
- **来源**：用户 2026-09-10 需求（盘前/盘中/盘后消息与政策筛选 + 选股辅助机制，五项要求）。
  本条是该需求的**可复用框架版本**：把「每天海量涌入的消息」压成「少量可执行信号」的固定流水线。
- **① 分级（降噪）**：逐条问三件事——**是不是事实**（已落地 > 拟议 > 传闻）、
  **有没有方向**（利好/利空/中性/待判）、**够不够级**（L1 必上：政策发布 · 行业级涨价 · 国际重大事件；
  L2 选上：龙头业绩预告/重大合同等带标的链的事实类；L3 不上：日常经营、人事变动、纯解读、传闻）。
  ⇒ 产物：**值得读的短名单**（`events/impact.py` 四级分类 × 三级影响力）。
- **② 映射（消息 → 板块 → 个股）**：三条通路并用——
  ①**传导链**：产业链多级（厄尔尼诺→化肥→种业→粮食→代糖，见 [[KB-STOCK-01]]；OpenAI→A股 AI 链）、
  海外实体、宏观（非农/加息降息）；
  ②**方向词典**：题材名/别名归一 + 国产替代对冲（利空外企 = 利多国产）；
  ③**标的池**：题材官方成分反查（**绝不从消息里臆造个股**）。
  ⇒ 产物：**带强度排序与业务依据的标的链**（`events/chains.py` + `extract.py`）。
- **③ 验证（事后看市场买不买账）**：事件后 30/60min 采样「是否出现新涨停 + 关联板块是否净流入」
  → 四态 `confirmed / fermenting / faded / unknown`（`events/verify.py`）。
  **这是"消息到底有没有用"的唯一证据源**——没有它，消息面永远只能凭感觉评价。
- **④ 情绪（三层 + 量能）**：个股 = 四维（封板质量 / 量价配合 / 结构位置 / 筹码松动）；
  板块 = 题材阶段与健康度 + 资金合力 + 梯队完整度；大盘 = 情绪相位（历史分位校准）+ 空仓闸门。
  **量能语义独立判定**（[[KB-STOCK-24]]：缩量 = 没人卖 ≠ 没人买；天量滞涨 = 筹码松动）。
- **⑤ 推送（只发可执行的）**：源头限流（阈值 + 每拍 TopN）→ 判读层去重分级
  （notify / ignore / escalate，实测 **89% 被挡**）→ 出口收敛（飞书只留买点卡，其余走站内悬浮球）。
  **唯一判据：这条消息会改变我今天做什么吗？** 不会 → 不进 notify。
- **通知筛选的判据（分类是示例，不是封版清单）**：唯一准绳是**「这条消息会改变我今天做什么吗」**；
  按它可把信号归为四类**示例**——① 改变方向（政策落地 / 重大国际事件 / 行业级涨价）
  ② 改变标的（题材首次催化、龙头业绩预告、龙头前瞻分跃升）
  ③ 改变时点（情绪相位切换、空仓闸门触发、买点/卖点条件成立）
  ④ 改变仓位（量能异动：天量滞涨、放量破位、缩量突破）。
  ⚠️ **这四类是判据的展开，不是固定分类**：具体清单须按**当期市场结构 + 数据可得性**重新推导，可增删；
  一条消息只按它**实际改变的东西**归类，**不同类别不得混用**（[[KB-DEC-018]]：示例 ≠ 规范）。
- **能力现状（2026-09-10 实测）**：第 ①③④⑤ 段主线均已实现；**第 ② 段有传导链但缺"一阶数据源"**
  ——气象/大宗商品/海外市场都只能等消息见报后跟，做不到用户要的「提前」。
  **宏观日历已补齐**（P1-8，2026-09-11：CPI/GDP/PMI/社融等进盘前简报，规则层筛选 + 三态 + 前端渲染闭环）。

  P1-34 消息面大盘方向预判。**已销账**：P1-35 量能语义统一 · P1-36 判读预算可见性 · P1-8 宏观日历。

### KB-STOCK-27 三倍量战法：规则化、参数口径与**实测否决**（2026-09-10）
- **来源**：用户提出（2026-09-10），与中文圈社区版本同源；社区已有派别警告「单纯盯三倍量去买大概率吃面」。
- **规则体系（结构化）**：
  - **信号（T0）**：当日成交量 ≥ **前 N 日均量 × M**（默认 N=5、M=3，**不含当日**）。
  - **左侧（低吸）**：价格回踩至 T0 **最低价 +1%** 以内，且**当日收盘未跌破** T0 最低价 → 尾盘低吸；
    **止损 = T0 最低价**。
  - **右侧（突破）**：**收盘价突破 T0 最高价** → 当日介入；或突破后次日回踩低吸；
    **止损 = 突破当天最低价**。
  - **离场**：一律**以收盘价判定**——盘中短暂刺破不算破位，收盘跌破才离场。
  - **代码**：`app/picks/triple_volume.py`（纯函数零 IO，三态纪律，阈值集中）；
    测试 `tests/test_triple_volume.py`（12 项）。
- **参数口径（用户问的"近期均量怎么定"）**：分母取**前 5 日均量**；社区另一派用「昨日量」（`V/REF(V,1)≥3`）
  ——**不采用**：昨日可能是极缩量日，会把「温和放量」误判成三倍量。窗口 N 是**可调参数**，
  **最终取值应由回测决定，不得拍脑袋固定**（本模块默认 5，20 日更严格但信号更稀）。
- **⚠️ 三类性质标注（[[KB-DEC-018]]）**：
  - **方法论（可采纳，须验适用性）**：①用「是否改变行动」筛消息/信号；②**止损用收盘口径**
    可避免被日内噪声扫损；③买点分左右侧（左侧赌支撑、右侧等确认）—— 这三条与形态无关，可迁移。
  - **经验（须本地验证后才可依赖）**：三倍量=主力进场、量比 1.5–3 最优、换手 5–15%、
    涨幅 3–5% 最优、"爆量=出货"。
  - **思路（线索非结论）**：各类传导链、"低位比高位安全"。
- **🔴 实测否决（近 250 交易日 / 1.79 万条三倍量信号；脚本 `scripts/verify_triple_volume*.py`）**：

  | 口径 | n | 均值 | 中位 | 胜率 |
  |---|---|---|---|---|
  | T0 当天收盘无脑买、持有 5 日 | 17,308 | **−0.70%** | −1.52% | 40.3% |
  | 左侧低吸（按上述规则） | 9,789 | **−0.32%** | −1.63% | **33.5%** |
  | 右侧突破（按上述规则） | 8,903 | **−0.44%** | −2.29% | **35.9%** |
  | 全市场任意日持有同周期（基准） | 1,335,182 | +0.06% | −0.35% | 46.8% |

  **位置分层检验**（社区假设「高位三倍量=派发、低位=吸筹」）：低位组（信号前 20 日涨幅<10%）
  左侧 −0.23% / 胜率 33.4%，高位组 −0.49% / 33.3% —— **无显著差异，该假设在本样本未获支持**。
- **结论与处置**：**本策略（含其位置变体）在当前样本上为负期望、胜率显著低于市场基准
  ⇒ 不接入选股与推送**。代码保留为纯函数 + 三个可重跑核验脚本（换参数/换窗口即可复验）。
- **边界声明（结论不是终审，勿当"永久否决"）**：样本仅 ~1 年（可能处于特定市场状态）；
  **未做市场环境分层**（用户策略本身提到"大盘环境"，本轮未分层）；未剔除权日；未含费用与滑点
  （含了会更差）；参数未做网格扫描（M=2/3/4、N=5/10/20、持有期）。
  要翻案需：更长样本 + 环境分层 + 参数扫描，**三者齐备后重测**。
- **本条真正可复用的价值（方法，比策略本身重要）**：**如何验证一个形态策略** ——
  ①先把规则写成**可计算的纯函数信号**；②按规则做**事件驱动模拟**（而不是"信号当天无脑买"，
  那是社区批评的用法，实测也确实最差）；③必须与**全市场同周期基准**对照，只看绝对收益会被市场 beta 骗；
  ④做**单变量分层检验**（如位置），验证流传的"前提条件"是否真有区分度；
  ⑤明确列出**未覆盖的变量**，把结论限定在样本内。
- **与海龟战法的同构性**：两者都属「**规则公开、人人可编码**」的拥挤形态 —— 三倍量是社区烂大街的选股公式，
  与海龟的 20 日突破同理：**信号本身没有秘密时，边缘会被交易掉**（见 KB-STOCK-28）。
- **关联**：[[KB-STOCK-01]] [[KB-STOCK-24]] [[KB-STOCK-26]] [[KB-DEC-018]]

### KB-STOCK-28 策略生命周期：为什么策略会失效，以及该怎么管（2026-09-10）
- **来源**：用户提出（以「海龟战法疑似失效」为引），要求建立持续推敲/验证策略的复盘机制，
  明确「哪些长期有效、哪些已过时」，并给过时部分以处置（清除 / 归档 / 改造）。
- **事实核验：海龟战法"失效"的判断——大致成立，但需精确化为「具体形态失效、内核存续」**：
  - **原版规则在现代市场确已被实证为低效**：KTH 皇家理工 2022 年硕士论文对主要市场指数实测，
    原版规则 20 年年化仅 **1.4%**（最高 25.1%，未计费用），结论「not viable」；并指出**主因在退出规则
    而非入场规则**（无法区分噪声与真突破）。
  - **结构性原因（三条，可直接转成我们自己的失效判据）**：①**算法化**——算法交易占成交量 60–70%，
    突破被更快套利，原版入场难以按意图价成交；②**趋势幅度下降**——平均赢家从 5–10× 风险降到 2–3×，
    短期趋势"显著萎缩"（长期趋势统计上未退化）；③**策略拥挤**——规则公开、人人可编码，
    500+ 算法同时买同一突破 ⇒ 边缘归零。
  - **但内核仍有效且已成行业标准**：波动率仓位管理（ATR/N 定 unit）、2N 止损、
    **机械化纪律**、金字塔加仓。多份材料一致：失效的是 1980 年代那套**具体参数**，不是"趋势跟踪"整体
    （趋势跟踪有 100+ 年学术记录）。
  - **另一个常被忽略的事实**：海龟实验成功本身**部分归因于 1980 年代特定的市场 regime**
    （商品/外汇持续大趋势 + 趋势跟踪当时不流行）——**实验证明的是"规则在那个环境有效"，
    不是"普遍有效"**。这对我们同样成立：任何策略结论都必须带**样本环境**。
- **策略生命周期该怎么管（本项目落点）**：
  | 环节 | 本项目现状 | 缺口 |
  |---|---|---|
  | 登记（策略有哪些、各自定义） | 有**因子**登记册（`docs/strategy/factor-candidates.md`）+ 因子生命周期制度 | ❌ **无"策略/战法"级登记册**（因子的登记 ≠ 策略的登记） |
  | 验证（能不能用） | 有回测框架（`app/picks/backtest.py` 批次 D）+ replay 回放 + 消融 | ⚠️ 需覆盖到"形态类策略" |
  | 监控（是否在衰减） | 有实验 30 日劣化守护（`experiments.py`）+ 回放门禁 | ❌ 缺**滚动胜率的衰减告警**（跌破阈值 → 自动标记待评估） |
  | 处置（清除/归档/改造） | 有回收站纪律 + 文档归档规范 | ❌ 缺**策略级处置台账**（谁因何失效、改成什么、留档在哪） |
- **本条的实践样本**：[[KB-STOCK-27]] 三倍量战法即按上述流程走完——登记 → 规则化 → 实证 → 否决
  → 保留代码与脚本待更长样本复验。**它的价值不在策略本身，而在把"验证流程"跑通了一次。**
- **关联**：[[KB-STOCK-27]] [[KB-DEC-018]] [[KB-DEC-011]] [[KB-ENG-36]]

### KB-STOCK-29 「两点半五步法」规则化与实测：原版显著负超额，但内含一条 11/11 年稳定的候选（2026-09-10）
- **来源**：用户 2026-09-10 提供（民间流传的"炒股养家最笨的方法"）；同族见 [[KB-STOCK-27]] 三倍量。
  两条**不可混用**：五步法要"温和"（涨幅 3–5%、量比 1.5–3），三倍量要"爆发"（爆量、大涨）。
- **规则化（原文 → 可计算谓词）**：
  | 步 | 原文 | 量化 |
  |---|---|---|
  | ① | 涨幅 3–5%（"涨得刚好"） | `chg ∈ [3%, 5%]` |
  | ② | 量比 > 1（<1 剔除；1.5–3 最理想） | `量比 = 当日量 / 前 5 日均量（不含当日）≥ 1` |
  | ③ | 换手率 5–15% | `turn ∈ [5%, 15%]` |
  | ④ | 成交量"阶梯式放大" | `当日量 > 前 1 日量 > 前 2 日量` |
  | ⑤ | 均线多头排列 + 不偏离短期均线 + 长期均线不压顶 | `MA5>MA10>MA20 且 close>MA20 且 close/MA5-1 ≤ 5%` |
  | — | 大盘健康才出手 | `全市场中位涨幅 > 0`（等权宽度代理） |
- **⚠️ 口径声明（与结论绑定）**：①**换手率为估算值**——`daily_k` 只有股数，用**最新快照**的流通市值÷价格反推股本，属"用当期股本算历史"（前视偏差），故换手率相关结论只能当近似；
  ②买入价 = **信号日收盘**（原文 14:30 决策 + 尾盘买入的近似）；③不含费用/滑点/涨跌停无法成交，**结果偏乐观**；④ST 按当期名称剔除（历史近似）。
- **样本**：`marketdb.daily_k`，**2407 个交易日 / 5555 只 / 968 万条**（2016-09 ~ 2026-09）。
  脚本：`backend/scripts/verify_two_thirty_five.py`（可重跑，含六节分析）。
- **🔴 主结论：五步全通过 = 显著负超额**
  | 组 | n | T+5 均值 | 超额 | 胜率 | 年度为正 |
  |---|---|---|---|---|---|
  | 全市场基准 | 9,675,409 | +0.14% | — | 47.5% | 6/11 |
  | **五步全通过** | **8,085** | **−0.51%** | **−0.65%** | **39.3%** | **2/11** |
  **累计漏斗显示"越筛越差"**：通过①后卡在②的组 **+0.77%**（最好）→ 通过①②卡在③ **+0.33%** →
  通过①②③卡在④ **−0.55%** → 通过①②③④卡在⑤ **−0.62%** → 五步全通过 **−0.51%**。
  即：**后三步把好样本筛掉了，不是筛出了更好的**。
- **单条件独立诊断（哪一步真携带信息）**：①涨幅3–5% **+0.17% 超额（唯一微弱正，t=+15）**；
  ②量比>1 **0.00%（零信息量，t 不显著）**；③换手5–15% **−0.31%（负贡献，t=−16）**；
  ④阶梯放大 **0.00%**；⑤均线多头 **+0.08%（近零）**。
- **参数敏感性（推翻原文三处直觉）**：
  - **③换手率单调**：<3%（+0.18）> 3–5%（+0.04）> **5–15% 原文档（−0.47）** > 15–25%（−1.57）> >25%（−3.50）
    ⇒ **换手越低越好**，"5–15% 才活跃健康"在本样本不成立。
  - **②量比**：原文理想带 1.5–3 在组内相对最好，但绝对仍为负；**<1（原文明确剔除）反而 +0.63% 超额**（近 250 日 +1.19%）⇒ 该剔除条件方向相反。
  - **⑤均线偏离**：**收盘跌破 MA5 组 T+5 +2.40%（+2.99 超额，t=+7.5）**，而原文要求的 3–5% 偏离档只有 +0.11%
    ⇒ 原文"别偏离均线"的方向对，但真正的低吸位是**均线下方**，不是均线上方的小幅偏离。
  - **①涨幅带单调**：在"跌破 MA5 + 大盘上涨"子集内，涨幅越高越好（3–5% +1.60% → 7–9.5% +5.59% → 涨停附近 +7.09%）
    ⇒ "3–5% 刚刚好"的上限没有依据；**但 >7% 当日多接近涨停、收盘买不进 ⇒ 3–5% 作为上限的真正价值是"可成交性"**，不是收益最优。
- **④大盘前提：方向成立，但它是"市场级效应"而非"选股效应"**
  - 全市场按大盘环境分层：大盘大涨(>1%)日 T+5 **+0.98%**（超额 +0.84，t=+120）；小跌日 −0.12%；持平日 −0.16%
    ⇒ "顺大盘做"这个**前提是真的**（且与本项目情绪相位/空仓闸门同源）。
  - **但**：五步全通过样本即便限制在"大盘大涨"日，T+5 = **+0.70%**，仍**低于同日全市场 +0.98%** ⇒
    **叠加大盘前提也救不回这套筛选**；它只是在分享市场 beta，没有 alpha。
  - 补充：五步组合在**大盘大跌日最差**（−1.26%）⇒ 原文"大盘绿时强势股次日易被拍回"对该组合成立；
    但**全市场**在大跌日反而 +0.26%（超跌反弹），故不可外推成"市场会跌"。
- **🟢 意外收获（本样本事后发现的候选，标注：需样本外复验）**
  **候选B = 涨幅 3–5% + 收盘跌破 MA5 + 大盘中位涨幅 > 0**（n=51,735）：
  T+5 **+1.60%（超额 +1.46%，t=+37.5）**、胜率 **56.9%**，**11/11 年度均为正超额**（+0.32% ~ +2.97%）。
  候选A（去掉大盘条件，n=62,419）T+5 +1.32%、**9/11 年为正**。
  分层还显示：**跌破越深越好**（破 −8~−15% 档 +1.53%，破 −3~−8% +0.42%，刚破 0~−1% ≈ 0）。
  ⇒ 逻辑讲的通：**超跌 + 当日强势反攻 + 顺大盘**（短期反转），与"追多头排列"（动量延续）方向相反。
  - **⚠️ 口径更正（2026-09-10 当晚，P1-40 复核；本条原结论的数字偏乐观）**：上面那个
    **+1.46% 是「混合池超额」**（信号收益 − **全样本**均值）—— 而该组合的条件里**本身就含
    "大盘上涨"**，必然聚集在强势日 ⇒ 其中**大部分是同日市场 beta，不是选股 alpha**。
    改用**市场中性口径**（扣**同一交易日**全市场均值）后：该组合真实超额只有 **+0.43%**，
    样本外（2022–2026）**+0.35%**、扣 25bps 后 +0.10%、35bps 后 −0.00%。
    同类更正：第①步「涨幅 3–5% 单独 +0.17% 微弱正」在市场中性口径下为 **−0.19%**（同样是 beta）。
    **教训：对照基准必须扣「同日」市场均值；否则凡是带"顺大盘/强势日"成分的条件，
    都会被系统性地读成 alpha。** 详见 [[KB-STOCK-30]] 与 [[KB-ENG-39]]。
  **⚠️ 必须标注**：这条是**在同一份样本上反复试探得到的**，存在多重比较/过拟合风险；
  11/11 年为正只是必要条件、不是充分条件 ⇒ **须独立样本外复验（或按时间切分定型/盲测）后才可依赖**，[[KB-DEC-018]]。
- **可复用方法（本条最值钱的部分，比结论更持久）**：
  1. **单条件独立诊断**——只看"组合效果"会漏掉"某一步根本零信息量甚至负贡献"；必须逐条单测。
  2. **参数敏感性**——原文阈值常是**没验证过的直觉**；分层一看，三处方向都反了。
  3. **环境分层**——用来区分**市场级效应**（顺大盘）与**选股效应**（alpha）；叠加环境后仍跑不赢同日全市场 = 无 alpha。
  4. **分年度稳定性**——防"某几年特例"；`2/11` 与 `11/11` 是天壤之别。
  5. **可成交性约束**——涨停收盘买不进；纸面最好的档（涨停附近 +7.09%）恰恰不可执行。
  6. **事后发现的规则必须标"样本外待验"**，不得直接写成"已验证"。
- **处置**：原版五步法**不接入**（负期望 + 年度 2/11）；候选B **记录为待验假设**，
  复验通过后再考虑作为**首个"战法级"登记条目**（[[KB-STOCK-28]] P1-37）。

### KB-STOCK-36 条件化审计纪律：否证结论必须声明「测过的层 / 未测的层」——无条件均值禁止作为终态（2026-09-13，用户发起全系统重审）

**起因**：用户指出系统的「标准化误差」——无条件均值判据 + 统一阈值会把条件化 edge（妖股 /
炒小炒差 / 突发消息急拉 / 连板主升 / 弱市穿越股 / 周期股 / 题材·业绩·情绪股）系统性排除。
**这不是推倒纪律，是给纪律补一维**：两向都错 = 「均值否决掉条件化机会」与「想象接受未验证机会」。

**五条纪律**：
1. **否证结论必须附分层声明**：在哪些层测过（分年度/环境/可成交/市值…）、哪些层未测；
   未测的层不得引申「处处无效」。全部否证结论的分层覆盖见 `docs/strategy/strategy-registry.md` 审计表。
2. **重开条件必须写明分层轴**——「换条件重测」不是推翻旧结论，是在旧结论未覆盖的层上新增证据。
3. **对照必须篮子化/分层随机 + 同信号对账**：单票对照会被个股特异性**双向欺骗**
   （实测：600519 高价整手误差 26pp、000001 whipsaw Spearman 0.30，39 票篮子真值 0.91pp/0.974——
   两个方向都错）；且两引擎必须喂**同一组预处理后信号**（喂不同信号 = 度量不等价）。
4. **「测不了 ≠ 不存在」**：可成交口径（KB-STOCK-31）排除的是「本系统数据测不了的域」
   （排队/排板），不是宣告该域无效——域声明必须随结论出现，打板域挂 L2（P2-30）。
5. **预算/阈值类参数同属语义**：绝对亿值、统一份数上限在极端相位下会系统性偏向
   （高潮期挤兑/冰点期空转），与统计判据同受本条审计（P1-16 先例）。

**系统性产出**：AST 盘点 346 常量 → 条件化盲区审计表（`docs/strategy/strategy-registry.md`）：

### KB-STOCK-37 「情绪高涨 ≠ 上车机会」：先分「接力真假」，再分「钱扩散还是收缩」（2026-09-16）
- **状态**：⏳ 待落地——**判据框架已明确，指标大半已有数据源，但未接线为自动判读**。

  （越不信越拉）、下午拉证券横盘等情况，并给出判断此类行情的方法」。
- **答案：不一定。** 相位（高潮/发酵）说明的是**环境热度**，不说明**钱在扩散**。必须过两道分流：

  **① 接力是不是真的**（有人在接，不是只有封板）

  - ⚠️ 两者**必须按历史分位判**，绝对经验阈值已实测证伪：`picks/gate.py` 原用
    `PROMO_FLOOR=0.30`（「低于 30% 就算接力无人接」），而近 **241 个交易日**实测

  **② 钱是扩散还是收缩**（高涨普涨，还是只有一条线在涨）
  - **中位 vs 均值背离**：昨日涨停股今日 `median_pct` 与 `avg_pct` 的差。背离越大 ⇒
    少数强票把均值拉起来、多数只是小涨 ⇒ **结构分化，不是普涨**
  - **板块净流入集中度**：`/api/market/board-fund-flow` 前列若全属同一条产业链 ⇒ 集中而非扩散

  | 昨涨停今日 中位 / 均值 | **+1.06% / +3.65%（背离 2.6pct）** | **分化**：多数平庸 |
  | 板块资金前列 | 半导体 +218亿 · 通信 +223亿 · 芯片 +195亿 | 钱**集中**科技 |
  | 金融地产风格 / 参股银行 | +0.17% **−8.19亿** / +0.67% **−8.82亿** | 权重**失血** |
  | 沪深300 / 中证1000 / 科创50 | +0.68% / +2.01% / **+4.14%** | 小盘科技强、权重弱 |

  ⇒ 当天是「**接力真 + 钱集中**」型：高涨成立，但**只对科技主线成立**，对权重/金融不成立。
  **所以「能不能上车」的判据必须分两层：环境（相位·接力）+ 结构（资金主线·个股在梯队的位置）。**
  只看环境标签就下单，等于用大盘的一句话解释所有个股。

- **「主力反向操作（越不信越拉）」**：意图**不可直接测量**，任何"主力在想什么"的陈述都是推断。
  可用的间接证据只有三条：① 涨停数与指数是否背离；② 板块资金流与涨幅是否背离；
  ③ **次日验证**——本系统每条情绪判断都带 `verify_next`（次日可验证条件），
  **这是检验此类假设的唯一正道**；单日吻合不构成验证（[[KB-DEC-019]]：同一交易日的多个吻合只算 1 个证据）。

- **「下午拉证券横盘」——待验证假设（⚠️ 非已确认判据）**：从用户举例推导出的**可检查特征**，
  四条**同时**出现才具备"护盘"语义，单条不判：
  1. 证券/银行板块**涨幅为正但主力净流入为负或近似零**（拉价格不接力）；
  2. **指数红而涨停家数不增**（甚至减少）；
  3. 前一日强势题材当日**滞涨，且炸板率上行**；
  4. 权重与**小盘背离方向相反**（沪深300 强于中证1000）。
  **本系统当前没有这条检测**——`board-fund-flow` 提供了所需字段，但没有规则读它。
  在把上列特征做成判据前，**不得当作系统已有能力引用**（[[KB-STOCK-01]] 同族纪律）。
- **重开条件**：需要板块资金流 + 涨停家数的**分钟序列**回测（现有多为日频快照），
  在其上跑 ≥20 个样本日、并与次日溢价对账通过后，才可从「假设」升格为「判读项」。
- **失效条件**：本条的核心主张有两处可被推翻——① 若实测显示「高晋级率 + 低炸板率」日
  与「低晋级率」日的**次日溢价无显著差异**，则「接力真假」这一分流的判别力不成立；
  ② 若「昨日涨停股中位/均值背离」与次日收益**无单调关系**，则「钱扩散还是收缩」不构成有效分流。
  任一条在 ≥20 个样本日上被验伪，本条即降级为「已知无效的直觉」，不得继续作为判读依据。
  ⚠️ 三个具体数字（36% / 11% / 2.6pct）是**单日实测**，只作口径示例，**不是阈值**。

## 一、题材扩散与接力（案例层）

### KB-STOCK-01 厄尔尼诺→农业链炒作
- **来源**：用户亲述案例「厄尔尼诺行情炒粮食股」（09-09 复盘指令正式引用，此前多次提及）。
- **内容**：气候异象（厄尔尼诺）→ 农产品涨价预期 → 炒作顺序沿产业链传导：**化肥 → 种业 → 粮食 → 代糖**。
- **验证**：2026-09-09 实盘全链涨停（化肥/种业/粮食/代糖四环节齐涨停，与糖业新闻同日出现）——扩散链预测与盘面完全吻合。
- **系统落地**：时事新闻→题材映射（通知中心 + 议程第七路）✅；台账归因记录「时事新闻」类。
- **关联**：[[KB-STOCK-02]] [[KB-STOCK-05]] [[KB-STOCK-09]]

### KB-STOCK-02 PCB 向材料端发散
- **来源**：用户亲述案例「PCB 概念向材料端发散炒作」。
- **内容**：题材炒作不停在整机/模块层，会沿产业链**向材料端纵深发散**——材料端是第二波主战场。
- **验证**：09-09 光通信链复刻该模式（光模块 → 光纤/耦合 → 材料 → 电缆，日涨幅递进）。
- **系统落地**：扩散模型设计（组合策略 §5）；题材内候选按产业链位置分层。
- **关联**：[[KB-STOCK-03]] [[KB-STOCK-04]] [[KB-STOCK-19]]

### KB-STOCK-03 CPO 链：光模块→耦合设备→材料端
- **来源**：用户亲述案例「CPO（光模块→耦合设备→材料端）」。
- **内容**：CPO 行情的三段扩散顺序——先光模块（整机），后耦合设备（中游），最后材料端（上游）。
- **系统落地**：与 KB-STOCK-02 同构，进扩散模型案例库。
- **关联**：[[KB-STOCK-02]] [[KB-STOCK-05]]

### KB-STOCK-05 先炒大票龙头，后炒细分补涨
- **来源**：用户亲述规律「先炒大票后炒细分」。
- **内容**：题材启动期资金先打大票（辨识度高、容量大），题材确认后向细分小票扩散补涨——**补涨阶段是散户胜率最高的窗口，也是风险开始积累的窗口**。
- **系统落地**：🔶 扩散顺序模型（组合策略）待实现；当前题材内排序（涨停置顶+涨幅降序）已部分体现。
- **关联**：[[KB-STOCK-01]] [[KB-STOCK-06]] [[KB-STOCK-19]]

### KB-STOCK-06 优秀交易员提前嗅到板块机会
- **来源**：用户亲述「优秀交易员如何提前嗅到板块机会」。
- **内容**：板块整体启动前有先兆：零星首板出现、消息面催化落地、相邻链涨停传导。**题材要等「成建制」证据才确认——这就是滞后的根源**。
- **验证**：09-09 滞后分层实测：T0 竞价板滞后 ~1min、T1 盘中板 1–2.5min、**T2 题材成建制滞后 10–27min（最大短板）**。
- **系统落地**：✅ **临板雷达**（09-09，`pre_limit_radar.py`：全市场快照 6s 扫描、板性缩放临板区、封板前预警+入册、规则直发零 LLM 延迟）；竞价即时通道/涨停池推送仍 ⏳。
- **关联**：[[KB-STOCK-07]] [[KB-TRADE-11]] [[KB-DEC-011]]

### KB-STOCK-21 一字板参与纪律：选对≠能买，开板重评
- **来源**：用户指令（2026-09-09 闭环需求 4）。
- **内容**：一字板/秒板**选对但没有参与机会**——保持观察登记（不追不恼）；某日开板且全方位分析（题材阶段/封单/大盘合力/龙头号召力）仍有机会 → 重新纳入候选并通知。断板后走趋势、走一段趋势后继续连板的，结合市场合力与龙头号召力综合判断，不机械处理。
- **系统落地**：✅ 临板雷达 sealed 首见 → `watch_no_entry` 观察登记（不入持仓池）；开板回落临板区 → `board_reopen` 通知重新纳入；持仓守护对断板/回封按封板判定+移动止盈处理。

### KB-STOCK-22 弱转强波浪识别（二浪启动持有）
- **来源**：用户指令（2026-09-09 闭环需求 2）：识别走弱后第二、三天突然转强的走势（二浪、三浪、四浪），不能停留在选股阶段。
- **内容**：强势股首次转弱（昨收跌破成本/前低）后的**突然转强**是波浪结构信号——二浪启动点恰恰是加仓/持有依据而非离场点；三浪、四浪同理递推，结合量能与市场合力。
- **系统落地**：✅ 离场引擎弱转强检测（持仓 ≥1 夜 + 昨收<成本 + 今日 ≥+4% → 「二浪启动」提醒**持有**）；三浪/四浪递推判定 🔶 待实盘样本。

# 每日精选 × 盘中跟踪融合可行性评估

日期：2026-09-04 · 数据基座：marketdb 近 60 交易日全市场日K（10,237,789 行）+ `daily_pick_set` 实盘产出 5 天样本
结论性质：**评估报告，未动代码**——P0 项待用户拍板后实施。

---

## 0. 结论先行

**融合方向正确，但融合的重心要从「盘中帮选股」纠偏为「盘中管执行与退出」。**

数据给出的核心判断：

1. 盘后静态选股的**可执行 alpha ≈ 0**（真实 picks 15 样本 T+1 均值 +0.10%、胜率 33%；T+3 均值 -2.10%、胜率 1/5）——信号在盘后产出时已被盘面兑现，这不是选股质量能解决的，是**执行时点**问题；
2. 亏损的最大单一来源是**一字/超高开买入**（gap≥9.5% 桶：T+1 均值 -2.09%、胜率仅 12%；360 只一字开盘里 290 只全天封死根本买不到，能买进的=开板=接飞刀）。真实 picks 里 3/15 只正是这种（T+3 -0.98%~-8.84%）；
3. **盘中跟踪有真实的、可量化的价值**：「冲高≥3% 即止盈」对比死守收盘，4693 个可买样本均值 -0.05% → +0.14%、胜率 48% → 63%。涨停股次日盘中平均回吐 4.2%（给了浮盈收盘全吐）；
4. 空仓闸门与数据吻合但**只堵不疏导致策略停滞**：连续 5 天 stand_aside，picks 照常产出却无人"消费"，没有绩效对照就无法回答"空仓是对是错"。

因此融合模块 = **选股（盘后，现有）+ 执行闸门（竞价 9:25 硬数据）+ 盘中出场跟踪（秒级行情）+ 影子模拟持仓（闭环验证）**。四件事缺一不可，但前两件是数据已证实的 P0。

## 1. 方向判断：对在哪，偏差在哪

### 1.1 对的部分（用户直觉被数据证实）

- **"仅靠盘后静态筛选难以真正确立方向"** —— 成立。盘后选出的强势股，次日收益分布完全由开盘溢价主导（见 §2.2），而开盘溢价在盘后不可知。盘后视角下"选对了"的票，一字开盘就变成"买不到"或"接飞刀"。
- **"需要盘中动态跟踪结合"** —— 成立。涨停股次日盘中平均回吐 4.2%，冲高回落率 14~18%（各 gap 桶都一样）。死守收盘会把盘中 4%+ 的浮盈全部吐回。盘中出场信号的期望增益 +0.19%/次，是整个链条里唯一被数据证实为正的主动操作。

### 1.2 偏差/需要纠偏的部分

| 偏差 | 纠偏 |
|---|---|
| 把融合理解为"盘中信号改进选股" | 盘中数据**来不及也不该**改当日选股（选股在收盘定稿）。盘中数据的正确用途是：①次日 9:25 竞价做**执行过滤**；②持仓期间做**出场判定** |
| 期望"融合后信号更准" | gap 分桶显示任何桶的可买样本期望都 ≤+1.5%——没有"更准的入场"，只有"更便宜的入场"（大低开桶 +1.48% 但方差大）和"更少的亏损"（禁买一字板直接切掉 -2.09% 的桶） |
| 空仓=停止一切 | 连续 5 天 stand_aside 而 picks 照常产出，产出与决策脱节。空仓应该是**一种被记录、被验证的决策**，不是功能停摆 |
| 用"近期多数亏损"证明选股失败 | 实测亏损主要来自执行层（一字板接刀、高开追入），选股层（可买样本期望≈0）不赚不亏。若把执行层问题归因于选股，会错调参数 |

### 1.3 一个反直觉发现（防止误判市场状态）

涨停家数 ≥50 的"活跃日"，涨停股次日 T+1 均值 **-0.23%**（4702 样本、胜率 45%），反而差于 30-50 家的中温日（+0.66%）。
**含义**：极端活跃日常伴随高位分歧/兑现潮，"市场热=敢买"是错的。融合模块的市场状态判定不能只用"涨停多不多"，晋级率/炸板率（现有 gate 逻辑）方向是对的，应保留并继续作为主判据。

### 2.3 盘中出场价值（可买样本 4693）

| 出场方式 | 均值 | 胜率 |
|---|---|---|
| 死守到收盘 | -0.05% | 48% |

### 2.4 空仓闸门的验证状态

- 近 60 交易日无"涨停<20 家"的极冷日，gate 的退潮判据（晋级率/炸板率，来自 ths 涨停池）无法用日K 直接复现——**gate 本身的历史有效性未被独立验证**，这恰恰是影子持仓机制要解决的问题（见 §4）。
- 已知事实：08-31~09-04 连续 5 天 stand_aside（退潮→冰点），同期 picks 仍逐日产出——闸门触发期间系统处于"信号空转"状态。

### 2.5 数据限制（如实声明）

- marketdb 只有日K，分钟级历史无法回填：竞价溢价比、炸板、急杀等盘中信号的**历史回测只能用日K近似**（gap≈竞价溢价、冲高回落用 high/low 近似）。盘中信号的精确价值需要靠影子持仓自然积累验证（§4）。
- 09-03 选出的 5 只在 marketdb 无次日数据（09-04 收盘后才有），T+1/T+3 缺 5 个样本。
- 一字开盘且全天封死的样本在现实中买不到，已在 §2.3 中剔除；但 §2.2 分桶未剔除（保留其"买到即亏"的警示含义）。

## 3. 融合模块设计（应涵盖的方面）

### 3.1 执行闸门（P0，数据已证实）

- **触发时点**：次日 9:25 竞价结束（竞价数据一次性拉取，现有 auction_premium 链路可复用）
- **规则**（直接采用 §2.2 实测阈值）：
  - picks 成员 gap ≥ +9.5% → **禁买**（"一字板等开板"= 等接刀）
  - gap ∈ +5%~9.5% → **降级观察**（期望 -1.28%，除非有明确事件催化不买）
  - gap ≤ -5% → 单票异常告警（可能是除权/利空，标注复核而非自动买）
  - gap ∈ -5%~+5% → 可执行，按 picks 原定计划
- **落点**：picks 推送卡片（09:26 automation）直接加「执行状态」字段：可买/禁买/观察；影子持仓的模拟下单同样受闸门约束

### 3.2 盘中出场跟踪（P0，数据已证实）

- **信号**（三层，全部已有基础设施）：
  1. 冲高止盈：持仓股浮盈 ≥3% 后回吐过半 → 出场提醒（§2.3 主信号，参数可扫描）
  2. 高度板炸板：≥3 连板持仓股炸板 → 单拍即告警（intraday_monitor 已有）
  3. 指数急杀：上证 -0.8%/创业板 -1.2%/15min → 组合级风险提示（intraday_monitor 已有）
- **频率**：QuoteHub 1s 行情（已有）+ 出场判定 60s 一拍（watcher 节奏，防噪声）
- **边界**：只对**影子持仓/用户标记持仓**的票做出场跟踪，不做全市场扫描（避免与预警系统职责重叠）

### 3.3 选股与盘中的衔接方式

- **不改选股时点**：收盘定稿次日名单（现有两道稳定性约束保留——换股上限 2 只/日是组合稳定器，实测有效）
- **加一层"执行前状态"**：9:25 竞价闸门输出三态（可买/禁买/观察），这是盘中数据对盘后决策的**唯一**合法修改点
- **盘中不补票**：盘中出现的"新机会"（现有 intraday-top 端点）继续作为独立观察流，**不自动进持仓**——退潮市实测返回 0 只为正确行为（宁缺毋滥）；要参与须经影子持仓先行验证

### 3.4 风控与空仓提示逻辑

- **gate 空仓照常触发**（数据未证伪它，且晋级率/炸板率判据方向正确），但行为改变：
  - 现状：顶部红色横幅 + 组合标"仅观察" + 买入范围撤除 → **保留**
  - 新增：空仓日 picks 照常进**影子持仓**（§4），闸门建议与影子实盘的绩效差逐日记录
- **闸门降级**：影子持仓连续 N 日（建议 N=10）跑赢"空仓基准"超过阈值 → 复盘元结论层提示"gate 可能过严"，**只提示不改行为**，调权仍需人工确认（防自指）

### 3.5 参数与阈值设定规则

| 参数 | 初始值 | 依据 | 调整机制 |
|---|---|---|---|
| 禁买线 | gap ≥ +9.5% | §2.2 最差桶（胜率 12%） | 参数扫描脚本季度复核 |
| 观察线 | gap ∈ +5~9.5% | §2.2 次差桶（-1.28%） | 同上 |
| 盘中止盈 | 浮盈 ≥3% 回吐 50% | §2.3（+0.19%/次） | 影子持仓 A/B：3% vs 5% 双轨跑 |
| 出场判定频率 | 60s | 防噪声 + QuoteHub 1s 已有余量 | 固定 |
| gate 降级观察窗 | 影子跑赢 10 日 | 防自指（不自动改 gate） | 人工拍板 |

**纪律**：所有阈值进 picks 配置文件，不硬编码；改任何阈值必须附参数扫描输出，防"看着调"。

## 4. 影子模拟持仓机制（P0，解决"策略停滞"）

### 4.1 设计

- **每个交易日**（无论 gate 是否空仓）：当日 picks 收盘后自动进独立影子账户模拟下单——次日在执行闸门允许的桶内以开盘价成交、受现有撮合引擎全部硬约束（T+1/涨跌停/整手/费用/停牌拒）
- **空仓日才有意义**：影子持仓记录"如果无视 gate 会怎样"，与真实决策（空仓）形成 A/B：
  - 影子账户累计收益 vs 0（空仓基准）→ **gate 的机会成本**被逐日量化
  - 影子持仓内部再分轨：听执行闸门（禁一字板）vs 不听 → **闸门价值**被逐日量化
- **复盘闭环**：每日复盘报告的 picks 维度新增 `shadow` 小节——影子当日成交/浮动盈亏/与真实决策的偏离原因；周末元结论层汇总影子 vs 空仓绩效，生成调参建议（人工确认生效）
- **技术落点**：`paper_account/paper_order/paper_position` 表已支持多账户（加 namespace/shadow 标记）；撮合引擎、回测引擎、复盘 Agent 全部复用，新增代码量集中在「影子下单调度 + 复盘对照」两处

### 4.2 为什么这是融合里最重要的部分

- 空仓闸门的正确性从未被验证（§2.4）——没有对照组，gate 触发 100 天也无法回答"少赚了多少"
- 盘中信号的分钟级价值无法历史回测（§2.5）——只有影子持仓的**前瞻性记录**能攒出这个数据集（`minute_decisions` 表已预留）
- 策略停滞的根源是"产出→决策→验证"链条在空仓日断裂；影子持仓把这条链重新接上

## 6. 一句话总结

**盘后选股保持不动，把盘中数据用在它真正有增量的两个位置——9:25 的执行闸门（禁一字板）和持仓期间的出场跟踪（防回吐）；同时用影子模拟持仓把"空仓到底对不对"变成每天都能验证的问题。** 数据说这能切掉最差 12% 胜率的买入桶、把出场胜率从 48% 提到 63%、并让策略在退潮期持续进化而不是空转。

# 历史涨停、强势连板与龙头形成研究蓝图 v1

> **定位**：把历史涨停、强势连板、空间板、龙头与题材梯队当作高信息密度的研究样本，系统研究“在起爆前哪些事实已经可见、哪些组合能跨时期复现、哪些只是事后解释”。本文定义研究问题、样本、特征、Jev 分工、验证协议和向猎场回流的边界；唯一任务状态归 `docs/stages/w04-research.md#rsh-031`。
>
> **不是**：追涨停说明书、赢家故事库、固定龙头评分器、Jev 预测器，也不是第二套选股/策略登记册。
>
> **关联**：[猎场决策](../product/hunting-decision-design.md)｜[题材与情绪方法论](../strategy/theme-sentiment-methodology.md)｜[新题材预判](../strategy/theme-prediction.md)｜[Jev 蓝图](../ai/jev-integration.md)｜[策略登记](../strategy/strategy-registry.md)｜[因子治理](../strategy/factor-lifecycle-governance.md)｜[W04 研究阶段](../stages/w04-research.md)

## 1. 为什么值得单独研究

涨停是结果，不是原因。真正有价值的问题不是“涨停后能否解释它为什么涨”，而是：

1. 在首次涨停、首次加速或进入强连板之前，市场、板块/概念、题材分支、事件、资金、情绪、量价和个股相对强弱中，哪些信号已经可以合法看到？
2. 同一个题材中，为什么某只成为空间板/龙头，另一些成为中军、补涨、跟风或失败者？
3. 为什么有些题材由单点异动扩散成梯队，有些异常拉升却只是一日游、诱多或高位出货？
4. 为什么有些强股能在弱市穿越、指数下跌时继续强势，而另一些只随大盘上涨？
5. 首板之后的继续连板、断板反包、趋势化、二浪/三浪、再启动，是否存在不同的可验证机制，而不是一套固定“龙头分”解释所有阶段？
6. 从较早历史样本总结出的规律，能否在后续未参与总结的时期提前筛出最近的涨停/强连板，而不是回头挑中几个成功案例？

这组研究若成立，价值不只体现在“抓涨停”。它还可以改善：

- 猎场提前观察与待触发候选；
- 题材启动/持续/退潮判断；
- 龙头、中军、补涨、跟风的角色识别；
- 板块异常拉升的真假启动过滤；
- 消息/公告到题材分支、公司与梯队的传导；
- 结构转换、二浪/三浪、断板再起等开放情境；
- 风险侧对一日游、假突破、利好兑现、资金集中出货的识别。

## 2. 研究对象必须是层级网络，不是单票故事

每个历史事件至少保留以下六层对象，并按 point-in-time 版本关联：

| 层 | 研究对象 | 典型问题 |
|---|---|---|
| 市场环境 | 上证/深证/创业板/科创等指数、全市场成交、涨跌家数、涨停/跌停/炸板、风格与情绪相位 | 当天是普涨、弱市、冰点修复、主升还是退潮？强势是否只是 beta？ |
| 板块/题材 | 行业、概念、题材、子题材与交叉主题 | 是单股异动、板块同步、题材初生、扩散还是旧题材回流？ |
| 分支/产业链 | 上游/中游/下游、设备/材料/应用、地域/事件分支等实际关系 | 资金从哪里向哪里扩散？是否只集中在一个名字相近但业务弱相关的分支？ |
| 催化与证据 | 政策、公告、业绩、产业供需、涨价、订单、重组、传闻、外围映射、无明确消息 | 催化何时首次可见？确定性、直接性、新颖度与是否已定价如何？ |
| 个股结构 | 价量、相对强弱、波动、换手、流动性、市值、竞价、封板/炸板、趋势/整理等 | 同题材中为什么是它先走强？强势是否可成交、可持续？ |
| 角色与演变 | 首板、连板、空间板、龙头、中军、补涨、跟风、反包、趋势化、二/三浪、再启动及角色转换 | 角色是何时被识别的？何时发生转换？是否只在结果出来后才贴标签？ |

不得把“主力意图”“资金合力”“洗盘”“出货”等不可直接观测概念当成事实字段。若使用，只能作为可证伪假设，并由可观察代理、反例和后续验证支撑。

## 3. 样本设计：赢家与失败者必须同时进入

### 3.1 正样本不是只有一种

按当时交易制度归一化涨跌停幅度，至少区分：

- 首次涨停；
- 二板/三板及更高连板；
- 当期全市场空间板；
- 题材内领先板；
- 弱市穿越型强势；
- 断板反包；
- 连板转趋势、趋势转连板；
- 调整后二浪/三浪/再启动；
- 首板后未连板但走出趋势的强势样本。

这些是结果标签，不是预先给出的策略类别。

### 3.2 必须有完整负样本与对照

每个研究窗口同步保留：

- 涨停打开/炸板、临板未封、冲高回落；
- 同日、同题材、同分支中未涨停的成员；
- 同市场状态下按市值、价格、波动率、流动性等匹配的普通个股；
- 板块异常拉升后未形成题材梯队的失败启动；
- 有重大消息但没有持续行情的样本；
- 无明显消息却走出趋势的样本；
- 系统曾提前观察但最终未起爆的假阳性；
- 后来涨停但系统未观察到的漏选样本；
- 已封死/停牌/流动性不足等“看对但无法参与”的执行负例。

没有这些分母，任何“龙头规律”都可能只是从赢家倒推特征。

## 4. 点时纪律：只允许使用当时已经知道的世界

每项事实保留 `source_event_at / available_at / received_at / decision_asof` 或等价字段。

硬规则：

1. 收盘后发布的涨停原因、龙虎榜、复盘文章不能倒填为盘前/盘中已知特征。
2. 后续新闻、次日价格、最终最高板数、后来确认的题材名不能参与早期特征生成。
3. 历史成分股、证券板块制度、ST/停牌/除权、公司行动和数据修订按当时版本处理。
4. 同一事件来源后续更正时保留版本链，不覆盖早先可见事实。
5. “首次发现”“首次触发”“首次具备模拟执行条件”“实际模拟成交”分别计时。
6. 研究阶段看过的明星案例必须标为污染样本，不可再作为最终盲测胜利证据。

## 5. 从历史到最近：四段式验证而不是边看边调

### A. 探索段

先从较早历史时期建立“涨停/龙头图谱”，允许：

- 描述分布；
- 找失败模式；
- 形成候选机制；
- 设计特征与反例。

此阶段不宣称有 alpha，不把看到的赢家直接写成生产规则。

### B. 冻结假设段

每个候选必须预登记：

- 业务假设；
- 可见时点；
- 计算定义；
- 适用域；
- 反例；
- 比较基线；
- 成本与可成交口径；
- 成功/失败标准；
- 允许测试的参数范围与停止规则。

### C. Walk-forward / OOS 段

按时间向前滚动，训练/选择只使用过去数据；需要时使用 purge/embargo，防止事件簇、题材生命周期和连续日期泄漏。所有尝试进入实验分母，多重比较不能只留下最好的一组。

### D. 最近未触碰保留段

保留最近一段未用于总结、特征选择、阈值调整的数据，最后回答：

- 能否在第一板前/当天封板前/第二板前发现？
- Precision@K、Recall、漏选和假阳性如何？
- 提前量是多少？
- 对强连板、空间板、题材龙头的排序是否有增量？
- 相比简单相对强弱、题材涨停家数、现有猎场基线是否真的更好？

若最近保留段不成立，回到“候选/失效”而不是继续调故事。

## 6. 候选研究族：先作为假设，不预设有效

### 6.1 题材启动与扩散

候选包括：

- 题材涨停/临板宽度与增长速度；
- 首板同步度、不同分支同时启动程度；
- 异常拉升相对大盘/行业的超额强度；
- 题材内上涨分布是否由单股集中向多股扩散；
- 龙头/容量核心/补涨之间的时间差；
- 板块成交与资金代理是否和价格扩散一致。

目标是区分“真实启动”与“单点拉抬、尾盘脉冲、只涨名称相似股、资金集中但无扩散”等失败模式。

### 6.2 题材梯队健康

研究：

- 首板、二板、三板以上梯队的形成速度；
- 晋级率及其市场状态条件化；
- 梯队断层与补位；
- 高标断板后低位是否承接；
- 中军强弱与小票高度之间是否存在可复现关系；
- 同题材角色切换与不同阶段的有效指标。

历史固定“3只成形”“5只成建制”等只作为基线，不能直接当真理。

### 6.3 催化质量与传导

候选语义特征：

- 事件类型；
- 新颖度/是否首次出现；
- 确定性；
- 对公司/题材的直接性；
- 来源可靠性；
- 政策层级/落地程度；
- 产业链传导距离；
- 旧消息重新炒作 vs 新催化；
- 题材叙事是否拥挤；
- 正文证据与市场解读是否一致/冲突。

这些特征必须在当时文本上抽取；“涨了所以消息重要”是禁止的标签泄漏。

### 6.4 龙头形成与强势延续

候选包括：

- 同题材相对强度和排名变化；
- 首次启动时间、封板时间、炸板与回封结构；
- 竞价与早盘承接（数据可用时）；
- 相对成交/换手与流动性条件化；
- 题材角色的领先程度；
- 市场下跌时相对抗跌/逆势上行；
- 题材分歧时能否维持前排；
- 人气/注意力变化（只在可得且点时正确时）。

“市场跌它还能涨停”应定义为可计算的相对韧性/穿越特征，而不是事后挑出妖股。

### 6.5 二浪、三浪与再启动

研究需要同时满足“旧结构 + 新变化”，候选如：

- 第一波后回撤/整理深度与时间；
- 成交量/波动收敛与重新扩张；
- 原题材仍有记忆但拥挤已释放；
- 新催化或产业数据出现；
- 题材/分支重新扩散；
- 老龙与新龙角色交接。

“曾经涨停很多”本身不能成为二浪信号。

## 7. Jev 的正确位置

Jev 适合这项研究，但只用在**窄语义、海量文本和验证**位置。

### 7.1 历史 AI MapReduce

对历史新闻、公告、涨停原因、政策和复盘证据做离线分桶：

- event_type；
- certainty；
- novelty；
- source_type / source_reliability；
- directness_to_company；
- directness_to_theme；
- chain_branch；
- priced_in / stale 候选语义；
- narrative_crowding；
- phase_consistency；
- evidence_conflict。

代码控制数据窗口、样本与流程；Jev 只回答预定义 Choice/Noul/Score，不自由创造交易结论。

### 7.2 Search / Rerank

确定性检索先召回当时可见文本，再由 Jev 做第二阶段语义相关性/证据直接性排序，降低把大量无关消息交给昂贵模型的成本。

### 7.3 Universal Verification

自动复盘或研究摘要输出“X 是因为 Y”“题材由 A 传导到 B”等主张时，Jev 可做 claim↔evidence 旁路核验，发现：

- 引用不支持结论；
- 把后发信息倒填到早期；
- 把题材相关写成公司直接受益；
- 把相关关系写成已证因果；
- 同一来源重复包装成多份证据。

### 7.4 绝对禁止

Jev 不得：

- 直接以自然语言预测“明天涨停概率”并写入生产；
- 读取未来收益后生成早期语义特征；
- 替代证券规则、涨跌停、T+1、可成交、风险与权限硬门；
- 用自身 confidence 冒充交易胜率；
- 自己决定因子/战法晋级；
- 通过对赢家文本解释得更漂亮来证明预测有效。

Jev 的人工金标准、阈值校准、规则/Jev/LLM A/B 仍统一归 RSH-030。RSH-031 只提出历史涨停域需要的分层 anchor，不复制第二套 gold 治理。

## 8. 产物：从“解释”转成可复算研究资产

研究过程应产出可版本化资产，而不是长篇故事：

1. **Limit-up Event Universe**：按当时制度计算的全量涨停/炸板/临板/对照事件。
2. **Theme/Branch Snapshot**：每个 decision_asof 的题材—分支—成员—梯队快照。
3. **Evidence Bundle**：当时可见新闻/公告/市场/资金/技术证据及其版本、缺项和冲突。
4. **Dragon Path**：从 first_seen → first_limit → continuation/break → role transition 的时序记录。
5. **Candidate Feature Registry**：候选因子、定义、来源、适用域、泄漏风险、实验版本。
6. **Hypothesis/Tactic Card**：只对通过基本数据完整性的机制写可证伪战法卡。
7. **Negative Result Register**：失败、无增益、只在狭窄子域有效和数据不足都保留。
8. **Blind Validation Report**：最近保留段、简单基线、现有猎场、候选增量的同条件比较。

稳定结论再提炼回 KB/因子/策略登记；过程样本与大报告不塞进权威文档。

## 9. 验收指标：先测“提前发现”，再谈收益

### 9.1 起爆前识别

- first_seen → first_limit 的提前量分布；
- 首板前、首板当日封板前、二板前的 Recall；
- Precision@K / PR-AUC（稀有事件优先，不用 accuracy 掩盖负样本）；
- 漏选率、假阳性率、候选负担；
- 不同市场状态/板块制度/市值/价格/波动/题材阶段分层。

### 9.2 龙头/强连板识别

- 后续晋级/连板的排序增量；
- 最大板高的 rank correlation 或分层命中；
- 题材龙头/空间板 emergence 的提前识别；
- 弱市穿越子域与普通普涨日分开报告；
- 龙头、中军、补涨、跟风角色预测/识别的混淆和转换准确度。

### 9.3 题材持续性与真假启动

- 题材次日/3日/5日仍活跃的校准；
- 梯队完整度、扩散范围与存续；
- 异常拉升后形成梯队 vs 一日游/回落的区分；
- 消息驱动、无消息驱动分别报告。

### 9.4 可交易与风险

- 信号出现时是否已经封死/不可成交；
- T+1、涨跌停、停牌、流动性与成交约束；
- 成本/滑点后的结果；
- MFE/MAE、尾损和回撤；
- “看对但无法参与”不能算交易成功。

若输出概率，额外报告 calibration/Brier/可靠性图；规则分数不得自动称概率。

## 10. 向猎场回流：只走现有闭环

研究通过后的增量不创建第二个“涨停选股器”：

```text
历史全样本 + 对照
        ↓
候选机制/语义特征
        ↓
RSH-026 点时标签与全分母
        ↓
IMP-020 walk-forward / 消融 / 成本 / 多重比较
        ↓
通过者 → 因子/策略/情境登记
        ↓
IMP-049 统一 Opportunity / scenario evidence
        ↓
猎场：提前观察 → 待触发 → 条件成立
        ↓
模拟/复盘 → 真实结果 → 重新验证/退役
```

仅能提高以下现有能力：

- 候选召回；
- 情境识别；
- 证据质量；
- 题材/角色排序；
- 等待/触发/失效条件；
- 风险过滤。

不能绕过统一机会身份、执行硬门和策略准入。

## 11. 第一批实施顺序

### Phase 0：数据与污染地图

先回答“我们到底有多少历史、哪些字段能点时使用、哪些只在事后存在”。冻结：

- 历史范围；
- 板块制度；
- 涨停/炸板定义；
- 新闻/公告/涨停原因的首次可见时点；
- 题材成员历史；
- 竞价/人气/资金/分钟数据覆盖；
- 已经被研究过的案例与日期；
- 最近保留段。

数据不够时宁可把某特征标为不可验证，不用今天的数据倒推过去。

### Phase 1：最早一批历史事件图谱

从较早一段开始，生成全量 event universe + 失败对照；先做描述性 atlas 和证据质量审计，不调生产阈值。

### Phase 2：候选机制与 Jev 小样本

从不同市场环境、不同板高、不同事件类型分层抽样，建立人工 anchor；Jev 做独立预标和批量抽取，先测语义任务质量和成本，再扩大历史 MapReduce。

### Phase 3：预注册实验

只选择有明确机制、数据足够、与现有基线不重复的候选进入 walk-forward/ablation。一次比较尽量只改变一个机制族。

### Phase 4：最近保留段挑战

冻结模型/规则后揭开最近历史，检查是否真的提前找到新的首板/连板/龙头，而不是只解释已经知道的明星股。

### Phase 5：猎场 shadow

通过 RSH-026/IMP-020 的特征只以 shadow/challenger 方式进入现有机会链；持续记录假阳性、漏选、不可成交和注意力成本，满足准入门后才讨论生产权重。

## 12. 停止与重开纪律

出现以下情况应停止扩大实验，而不是继续堆特征：

- 历史文本没有可靠可见时间；
- 题材成员只能用当前名单回填；
- 正负样本分母不完整；
- 最近保留段失效；
- 增益只来自一个极小幸运桶；
- 加入成本/可成交后优势消失；
- 与简单相对强弱/题材广度基线无显著增量；
- Jev 语义质量不足或成本/延迟不划算。

被否决的方法保留定义、样本、原因与重开条件。未来新数据、新市场状态、新模型或外部方法提供了明确反证时，可以按 living plan 重新打开，但不能只换名字重测。

# 新题材预判方法论（New Theme Prediction）

> 需求：在每日复盘系统中预判下一交易日可能诞生的新题材方向与潜力个股。
> 模块：`backend/app/predict/`（v1 引擎）· API：`/api/predict/*`
> 红线对齐：全部输出是**概率假设 + 依据 + 失效条件**，绝不输出确定性结论（AGENTS 红线 3）；
> 数据缺失显式标注 gap，不臆测。

---

## 一、题材成立的核心条件与验证标准

评分卡六维（权重版本化 `ENGINE_VERSION=v1`，改权重必须换版本号，否则历史命中率失去可比性）：

| 维度 | 权重 | 数据面 | 评分逻辑 |
|---|---|---|---|
| 热榜验证 | 0.25 | ths 热股榜（24h 榜） | 相关标的进 top10 = 1.0 / top30 = 0.6 / 榜外 = 0；**最强可量化先导指标** |
| 消息级别 | 0.20 | 个股新闻标题（东财） | 标题含国务院/中央/部委等权威词 = 1.0 / 0.6 / 仅媒体 = 0.3；识别不出按低档处理 |
| 新闻联动 | 0.20 | 候选股新闻关键词匹配 | ≥2 只热榜股新闻命中同主题词 = 1.0（多股同向发酵）；1 只 = 0.5（旗帜标的特征） |
| 市场环境 | 0.15 | 情绪引擎（market_context） | 冰点 1.0 / 分歧 0.9 / 启动·发酵 0.7 / 高潮 0.3 / 退潮 0.2——冰点分歧出新龙头，高潮难接力 |
| 新鲜度 | 0.10 | 近 5 日涨停池 + 题材看板 | 全新方向 = 1.0；旧题材新催化 = 0.5（需更高消息级别补偿） |
| 资金验证 | 0.10 | 龙虎榜（ths） | 相关标的游资净买 >0 = 1.0；未上榜 = 0.4（首板未触发上榜条件属常见，非负面） |

**成立分级**：`≥0.72 预判成立 / ≥0.58 可能成立 / ≥0.42 弱预期 / <0.42 不预判`。

**验证标准（三路关联，只认数据不认叙事）**：一只热榜股算「题材相关」当且仅当
新闻标题命中关键词 / 近期涨停原因标签命中 / 股票名称命中，三路其一成立。
三路全无 → 直接不预判 + gap 标注，绝不因为"感觉是"而给分。

**每条预判必带失效条件**（不可证伪的预判 = 马后炮，禁止发布）：竞价一致性不足、
D1 涨停家数 <3、热榜跌出 top50、消息证伪、大盘转退潮——五条模板按题材关键词实例化。

## 二、数据采集清单（交叉验证矩阵）

| 数据 | 来源 | 用途 | 状态 |
|---|---|---|---|
| 热股榜（当前/历史） | ths `hot-stock-list(-history)` | 人气先导 + D1 兑现验证 | ✅ 已接 provider（ths 独有，无备源，失败标 gap） |
| 候选股新闻 | 东财（按个股） | 题材关键词联动 + 政策级别 | ✅ 复用 composite 链 |
| 近 5 日涨停池+原因 | ths | 新鲜度（旧题材占用）+ 个股概念标签 | ✅ 复用 |
| 龙虎榜（净买/席位） | ths | 游资资金背书 | ✅ 复用 |
| 情绪阶段/涨跌停宽度 | market_context | 环境适配（冰点出新） | ✅ 复用（与复盘同口径） |
| 题材看板 | theme_service | 当前已激活题材清单 | ✅ 复用 |
| 集合竞价 | ths auction | D1 开盘一致性确认 | ⬜ provider 未接（P1） |
| 全市场新闻流/政策原文 | （未接） | 消息级别判定的主要瓶颈 | ⬜ 升级项，见 §五 |

**关键架构决策**：候选股来自热榜（市场用脚投票），主题材确认靠**逐个拉候选股新闻匹配关键词**
——数据驱动的关联，不维护静态概念映射表（静态表必然过时且覆盖不了新题材）。

## 三、梯队推演与演变路径

**推演 ≠ 确认**——梯队只能等走出来才能最终确认，这是原则不是免责声明。
预判给出的是「候选结构 + 观察优先级」，每日收盘用实际涨停池自动回填对比。

推演依据（按可得数据排序）：热榜排名（人气）、新闻命中数（题材纯度）、
热度值（同榜相对人气，0.10 权重）、龙虎榜净买（资金背书）。
**市值结构/流通盘/股东减持/监管风险无数据源覆盖**——显式声明为局限，不虚构。

- **龙头候选**（1 只）：综合分最高 = 人气 × 纯度 × 资金
- **中军候选**（1-2 只）：次高分，机构+游资共振位
- **跟风候选**（其余）：热榜在榜但纯度弱，D2 分歧日的主要淘汰对象

演变路径（四段）：D1 辨识日（龙头一字/高开定高度，跟风混战）→ D2 淘汰日
（分歧淘汰赛，龙头缩量回封 = 题材续命，**最关键观察点**）→ D3 固化日（龙头 3 板，
中军补涨，高低切换窗口）→ D4+ 扩散或衰败。

## 四、介入时点与成功率

| 时点 | 触发条件 | v1 校准成功率* | 核心风险 |
|---|---|---|---|
| D1 竞价 | 龙头高开 3%-6%（非一字）+ 板块 ≥3 只高开 >2% | 55%-65% | 高开低走；T+1 无法日内止损 |
| D1 一字排板 | 仅龙头候选 + 封单充足 + 热榜 top10 确认 | 40%-50% | 排板被砸；**本系统模拟撮合对涨跌停价硬拒单**，只能按次日可成交价回测 |
| D1 盘中首板 | 10:00 前量价齐升站稳均价线 + 板块 ≥2 板 | 50%-60% | 午后轮动退潮，炸板 |
| D2 分歧低吸 | 龙头首板后回调 -5%~-8%，缩量回踩关键位 | 55%-65% | 分歧转衰败（大面），止损纪律优先 |
| D2+ 补涨轮动 | 龙头确认 3 板后中军/低位正宗首异动 | 45%-55% | 龙头断板，补涨一日游 |
| 一字次日追高 | —— | 30%-40% | **禁**：接最后一棒 |

\* 成功率定义：介入后 3 日内最大浮盈 ≥5% 的概率。**v1 是主观校准区间**
（短线接力公开统计经验），本系统样本外跟踪 ≥20 条后用实际命中率替换（§五）。
退潮期全线 -10pp；弱预期仅保留盘中首板确认计划。

**一字板能否买入的制度性说明**：真实排板需券商快速通道；本系统模拟撮合按红线
对涨跌停价硬拒单（T+1/费用全配置化），因此"周一我爱我家一字板"在系统内的
对应动作是**不追**，介入计划自动落到 D2 分歧低吸或 D1 非一字候选。

## 五、纳入复盘、跟踪与自我迭代

**纳入规则**：预判在**目标日收盘后**由复盘 Agent 自动验证（`maybe_auto_verify`
钩子挂在 `ReviewService.run`），结果一行进复盘报告摘要，明细进验证表：

1. 题材成立了吗？——目标日涨停池题材关联家数 ≥3
2. 人气兑现了吗？——候选股还在 D1 历史热榜 top50（`hot-stock-list-history`）
3. 梯队对了吗？——实际最高连板股 vs 预判龙头候选
4. 结论三分类：**hit**（题材+龙头全中）/ **partial**（题材中、龙头偏）/ **miss**（未成立）；
   数据缺失 = **expired**（不判错也不判对）

**存储**：`prediction_reports`（payload 全量）+ `prediction_themes`（题材明细行，
验证结果回填，独立可检索）+ `data/review/predictions/YYYYMMDD.json` 落盘；
同一目标日覆盖（周末两日重跑，最新有效）。

**稳步提升预判成功率的方法**（方法论自我迭代闭环）：

1. **每条预判必带可证伪条件** → 杜绝马后炮，所有验证可机器执行；
2. **分层命中率统计**（`GET /api/predict/stats`）：按 verdict 分级、按运行语境
   （weekend/evening）分层——找到自己的优势区（如"周末国家级政策"命中率
   显著高于"盘中异动"），把预判资源集中到优势区；
3. **权重再校准**：当某证据维度与结果相关性弱（如新闻联动的 hit 率与总分
   脱钩），降权重并升级 ENGINE_VERSION，历史样本按版本隔离比较；
4. **样本外纪律**：连续 ≥20 条样本外预判命中率稳定 >55% 的题材类型，才提高
   仓位置信度；未达标前一律按低仓位/观察处理；
5. **升级路径**：接全市场新闻流（当前按个股拉新闻是消息级别判定的主要瓶颈，
   v1 实测只能看到媒体级标题）→ 政策原文库 → 集合竞价端点 → 热度历史曲线
   （`hot-stock-rank-trend` 端点已在能力清单，用于"发酵加速度"度量）。

## v1 已知局限（诚实清单）

- 消息级别判定依赖候选股个股新闻窗口（8 条/股），国家级政策原文常不在其中
  ——周末实测只能判到"媒体级"，导致总分被压低。这是**数据源瓶颈不是逻辑错误**，
  接全市场新闻流后重校准；
- 题材相关判定三路（新闻/涨停标签/名称）覆盖不了"名字与概念完全无关"的
  纯度标的（如部分化工转房产标的），依赖涨停池标签积累；
- 主观成功率区间未经本系统数据验证——样本外 20 条之前不构成任何依据；
- 假日历：target_date 按自然周推算，法定节假日不校准（报告内声明）。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/predict/run | 跑预判：`{theme_hint, keywords[]}` 定向；留空自动发现（启发式，置信度封顶） |
| GET | /api/predict/predictions | 预判列表 |
| GET | /api/predict/predictions/{target_date} | 预判详情（含验证结果） |
| POST | /api/predict/verify/{target_date} | 手动补验（复盘 Agent 自动调用，幂等） |
| GET | /api/predict/stats | 命中率分层统计 |

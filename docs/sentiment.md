# 市场情绪与阶段判定 — full.md §5.5（Phase 3）

## 指标清单

涨停/跌停数量、炸板率、封板率、首板至五板+数量、1进2 / 2进3 / 3板+晋级率、
昨日涨停股今日平均与中位收益、翻红率、再涨停率、高位/低位股平均收益、龙头溢价、
断板亏钱效应、市场温度、市场宽度、情绪周期曲线。

## 阶段判定

```text
冰点 → 修复 → 发酵 → 高潮 → 分歧 → 退潮
```

判定输出必须包含：当前阶段、判定时间、使用的指标、指标数值、置信度、可能的误判原因、阶段切换条件。
**禁止**只输出一个阶段名词而不给出依据。

## 口径说明（写入页面，随结果展示）

- 晋级率 = 当日 N 连板数 ÷ 昨日 (N-1) 连板数。
- 炸板率 = 炸板家数 ÷ (涨停家数 + 炸板家数)。
- 市场温度 = 归一化组合指标（涨停数、连板高度、晋级率、赚钱效应的加权），权重配置化并随结果输出。
- 所有情绪指标基于涨停池/全市场行情落库数据（Parquet）计算，标注计算时间与数据时间。

## 涨停家数：两个口径并存（2026-08-28 实测校准）

- **价格法**（全市场快照，实时可用，`/api/market/breadth`）：收盘涨幅 ≥ 涨跌停阈值−0.15pct。
  含"收盘贴板但尾盘炸板"的股票，实测 89 只；N/C 字头上市初期新股（无涨跌幅限制）已排除
  （校准前 90，误判来源见 git 历史）。
- **封单法**（东财涨停池，权威，`/api/limit-up`）：最终封住的 82 只。
- 差值（≈7 只）≈ 尾盘炸板数，本身就是有效信息。**炸板率计算以封单法为准**；
  盘中东财池未披露时用价格法并标注"实时估算"。
- 涨跌停阈值按板块：主板 ±10%、创业/科创 ±20%、北交 ±30%、ST ±5%；阈值规则后续配置化。

## ⚠️ 2026-08-29 判定纠错（改本模块前必读）

当前 `engine.py` 的判定结果**不可信**，已定位根因：

1. **非交易日日期回退**导致自指计算 —— 东财 `push2ex` 传入非交易日时静默返回最近交易日数据
   （且响应无日期字段），`date.today()` 与 `today-1` 取到同一天 → "昨日涨停股今日表现"
   实际是"涨停股查自己涨停那天的收盘价"，恒等于 +10%。详见 `docs/data-sources.md` §3.1。
2. **晋级率从未实现**（本清单写了，`engine.py` 没有），导致「分歧」阶段无法被触发。
3. 判定只用热度指标（高度/均值/涨停数）且无反向校验，只用均值不用中位数。

**8/28 正确结论：分歧（高位分歧），置信度中**，非线上所报的「高潮」。

完整调研、复盘与优化清单见 **`docs/sentiment-phase-review.md`**（含业界判据对照表与待验证项）。

# 市场情绪与阶段判定 — full.md §5.5（Phase 3）

## 指标清单

涨停/跌停数量、炸板率、封板率、首板至五板+数量、1进2 / 2进3 / 3板+晋级率、
昨日涨停股今日平均与中位收益、翻红率、再涨停率、高位/低位股平均收益、龙头溢价、
断板亏钱效应、市场温度、市场宽度、情绪周期曲线。

## 阶段判定

```text
冰点 → 修复 → 发酵 → 高潮 → 分歧 → 退潮
```

判定输出必须包含：当前阶段、判定时间、使用的指标、指标数值、置信度、可能的误判原因、阶段切换条件。
**禁止**只输出一个阶段名词而不给出依据。

### 双轴矩阵（唯一判据，非单轴阈值）

阶段由「热度档 × 赚钱效应档」查表得出，**不是**把热度指标套阈值。
热度轴回答"市场热不热"（涨停家数 / 最高板 / 炸板率），
赚钱效应轴回答"热的是不是能赚到"（1进2 晋级率 / 昨涨停今日中位 / 翻红率 / 跌停家数）。
两侧各按原始分切四档：热度 0 低迷 / 1 偏低 / 2 中性 / 3 高热；赚钱 0 亏钱 / 1 偏弱 / 2 健康 / 3 强劲。

| 赚钱效应 ＼ 热度 | 0 低迷 | 1 偏低 | 2 中性 | 3 高热 |
|---|---|---|---|---|
| 0 亏钱 | 冰点 | 冰点 | 退潮 | 退潮 |
| 1 偏弱 | 冰点 | 退潮 | **分歧** | **分歧** |
| 2 健康 | 修复 | 修复 | 发酵 | 高潮 |
| 3 强劲 | 修复 | 修复 | 发酵 | 高潮 |

### 「分歧」到底怎么触发（P3 #17）

**核心原则：赚钱效应可否决热度。热度再高，赚钱效应跟不上就只能是「分歧」，不能给「高潮」。**
矩阵里 earning=1（偏弱）× heat=2/3（中性以上热度）这两格就是「分歧」——
典型形态是高位股还在涨停、指数不难看，但打板的人已经赚不到钱（1进2 回落、昨涨停今日中位转弱）。

- **进入分歧**：热度中性/高热 且 赚钱效应偏弱；或从「高潮」跌破——1进2 <25% 或 昨涨停今日中位 <2%。
- **离开分歧**：1进2 回升 ≥25% 且 中位 >2% → 发酵；
  最高板断板 且 昨涨停今日中位 <0% → 退潮。
- **冰点与退潮的边界**（最易混）：两者都表现为亏钱，区别在还有没有热度残留——
  退潮是从高位杀下来（最高板回落 / 跌停扩散 / 涨停家数尚未腰斩），
  冰点是跌无可跌（最高板 ≤2 且涨停 <25 家）。只看当期热度会把"正在杀跌的中位市场"误判成冰点。

各阶段切换条件（含上述分歧规则）由 `engine.py` 的 `switch` 表输出，
随 `/api/market/sentiment` 一并返回，供次日对账。

## 口径说明（写入页面，随结果展示）

- 晋级率 = 当日 N 连板数 ÷ 昨日 (N-1) 连板数。
- 炸板率 = 炸板家数 ÷ (涨停家数 + 炸板家数)。
- 市场温度 = 归一化组合指标（涨停数、连板高度、晋级率、赚钱效应的加权），权重配置化并随结果输出。
- 所有情绪指标基于涨停池/全市场行情落库数据（Parquet）计算，标注计算时间与数据时间。

## 涨停家数：两个口径并存（2026-08-28 实测校准）

- **价格法**（全市场快照，实时可用，`/api/market/breadth`）：收盘涨幅 ≥ 涨跌停阈值−0.15pct。
  含"收盘贴板但尾盘炸板"的股票，实测 89 只；N/C 字头上市初期新股（无涨跌幅限制）已排除
  （校准前 90，误判来源见 git 历史）。
- **封单法**（东财涨停池，权威，`/api/limit-up`）：最终封住的 82 只。
- 差值（≈7 只）≈ 尾盘炸板数，本身就是有效信息。**炸板率计算以封单法为准**；
  盘中东财池未披露时用价格法并标注"实时估算"。
- 涨跌停阈值按板块：主板 ±10%、创业/科创 ±20%、北交 ±30%、ST ±5%；阈值规则后续配置化。

## ⚠️ 历史误判案例库（2026-08-29 复盘纠错精华 · 原 `sentiment-phase-review.md`）

> 本节是**方法论资产**：一次"界面正常、HTTP 200、结论全错"的完整静默失败案例。今后情绪口径改动前必读。

### 案例：非交易日日期回退 → 自指计算 → 误判「高潮置信度高」

**根因链**（实测东财 `push2ex/getTopicZTPool`）：

```
date=20260829(周六) → 82 条，首条 000712 锦龙股份 3板
date=20260828(周五) → 82 条，首条 000712 锦龙股份 3板   ← 完全相同
date=20260827(周四) → 77 条
```

**接口传入非交易日会静默回退到最近交易日，不报错、不标注，响应无日期字段**（字段仅 `c/m/n/p/zdp/amount/ltsz/tshare/hs/lbc/fbt/lbt/fund/zbc/hybk/zttj`，无法从响应侧识别）。
于是 `today=周六`、`yesterday=周五`，两次取池拿到**同一份周五数据**；`_prev_zt_performance` 用周五涨停股查周五收盘快照 → 涨停股在自己涨停那天涨幅恒等于 +10%。

| | 错误口径 | 正确口径 |
|---|---|---|
| 样本 | 82（周五池 × 周五收盘） | 77（周四池 × 周五收盘） |
| 均值 / 中位 | **+10.62% / +10.00%** | **+3.17% / +1.97%** |
| 翻红率 / 再涨停率 | **100% / 100%** | **62.3% / 23.4%** |

→「昨涨停均值 10.38% > 3%」是**同义反复**，不含任何信息；高潮结论完全建立其上。**正确结论：分歧（高位分歧）**。

### 误判链条九条（因果序）

| # | 问题 | 性质 |
|---|---|---|
| 1 | **非交易日日期回退**：接口静默返回最近交易日，`date.today()` 两次取到同一天 | **根因** |
| 2 | **自指计算**：用同日池查同日快照，恒等于 +10% | 由 #1 直接导致 |
| 3 | **规则顺序**：高潮判据只看高度/均值/涨停数，无反向校验 | 结构性缺陷 |
| 4 | **缺失晋级率**：文档写了 1进2/2进3/3板+，`engine.py` 从未实现 | 文档与实现脱节 |
| 5 | **只用均值不用中位数**：均值 3.17% vs 中位 1.97%，均值掩盖多数人体感 | 口径缺陷 |
| 6 | **高潮阈值过松**：本项目 ≥5板+≥60家 vs 业界 ≥7板+≥80家 | 阈值未校准 |
| 7 | **炸板率不进规则**：只用差值近似，未用真实炸板池 | 口径缺陷 |
| 8 | **缺跌停家数**：退潮关键信号缺失 | 指标缺失 |
| 9 | **置信度被污染**：`confidence` 依赖伪信号 avg → 输出"置信度：高" | 连带故障 |

**附带发现（红线 2）**：休市日快照 `received_at=周六 11:53` 但底层 `ticktime=周五 16:29`，meta 仍返回 `is_stale=False/is_realtime=True` —— 违反「禁止把过期缓存冒充实盘」。

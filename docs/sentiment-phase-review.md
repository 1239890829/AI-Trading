# 情绪周期判定：调研 · 复盘纠错 · 优化清单

> 生成时间：2026-08-29（周六，休市）
> 数据基准：**2026-08-28（周五）收盘** —— 最后一个已收盘交易日
> 结论一句话：线上判定的「高潮」是**日期回退导致的自指计算产物**，正确结论是 **「分歧」（高位分歧）**，置信度中。

---

## 一、联网调研：业界阶段划分与判据

### 1.1 三种阶段口径（业界并不统一，需先选定）

| 口径 | 阶段序列 | 来源 |
|---|---|---|
| 四阶段 | 冰点 → 修复 → 高潮 → 退潮 | 短线实战派常见简化版 |
| **五阶段** | 冰点 → 修复 → 升温(发酵) → 狂热(亢奋) → 退潮 | 量化/博士论文系，阈值最完整 |
| **六阶段** | 冰点 → 启动 → 发酵 → 高潮 → 分歧 → 退潮 | 打板实战派；**本项目 `docs/sentiment.md` 采用此口径** |

六阶段比五阶段多了「**分歧**」——它专门描述"热度仍在高位、但赚钱效应已开始分化"的过渡态。本次误判的根子就在这：**引擎只有热度判据，没有分化判据，所以「分歧」这个阶段实际上永远无法被触发。**

### 1.2 通用量化判据汇总（多源交叉，分歧处已标注）

| 指标 | 冰点 | 修复 | 升温/发酵 | 狂热/高潮 | 退潮 |
|---|---|---|---|---|---|
| 涨停家数 | ≤20 | 20–40 | 40–80 | **≥80** | — |
| 连板高度 | ≤2 板 | 2–3 板 | 4–6 板 | **≥7 板** | 骤降 |
| 炸板率 | ≥40% | 30–40% | 20–30% | **≤20%** | ≥40% |
| **晋级率（1进2）** | **≤25%** | 25–40% | **≥40%** | ≥40% | **≤25%** |
| 昨日涨停今日涨幅 | — | — | — | 连续 2 日 >4% | 连续 2 日 <2% |
| 涨跌家数比 | <0.5 | 0.5–1 | >2 | >2 | — |
| 跌停家数 | ≥10 | — | — | — | >10~15 |

**源间分歧（如实标注）**：
- 连板高度"狂热"阈值：一说 ≥7 板，一说 ≥6 板。**待验证**，建议以本项目历史分位数自行校准。
- 炸板率"狂热"阈值：一说 ≤20%，实战派另有 <20% 为强势的说法，基本一致。
- 「晋级率 ≥40%」的口径未说明是 1进2 还是全档平均。**待验证**。

### 1.3 值得借鉴的开源项目

**① `simonlin1212/vibe-astock`** — 契合度最高，强烈建议对标
- 核心思想：**"涨停家数只是原料，真正决定盘面状态的是派生读数"**。
- 派生指标四件套：赚钱效应（昨日涨停股今天的均值/**中位数**/翻红率/再涨停率）、晋级率（1进2 / 2进3 / 3板+）、连板溢价、梯队结构 + **断层检测**。
- 明确警告：**"均值与中位数经常背离——少数大涨会把均值拉起来。看多数人的体感以中位数为准。"**
- **"1进2 最敏感：明显走低=退潮，回升=修复"**
- 金句可直接当验收标准：**"涨停 40 家但昨日涨停股今天中位 -1.8%，那是退潮；涨停 25 家但中位 +4%，那是健康"**
- 工程做法：情绪周期做成"近 10 个交易日情绪分曲线"，定位本轮**起点**与"第几天"，而不是单点截面判定。
- 测试哲学值得抄：341 用例，**"重点在那些错了也看不出来的地方——界面照常渲染、数字看着合理，但结论是错的"**。

**② `WhiteWolf-js/daben-review`** — 工程分层与盘中监控成熟
- 分层：`data(akshare/mootdx) → metrics(客观骨架) → agent(推理) → app(REST/SSE) -> 前端`，指标层**纯本地计算、不限频**。
- 盘中 P0 监控三类纯规则事件：① 高度板(≥4板)炸板 ② **实时炸板率破 40%** ③ 指数急杀（上证近 15min 跌≥0.8% / 创业板≥1.2%）。
- 候选票 A+~D 分级 + **次日验证与滚动命中率**（回测 alpha 的闭环雏形）。
- 诚实的能力边界声明写在 README，值得学。

**③ akshare 生态**：`stock_zt_pool_em` / `stock_zt_pool_previous_em` / `stock_zt_pool_strong_em` / `stock_zt_pool_zbgc_em`。其中 **`stock_zt_pool_previous_em`（昨日涨停股今日表现）正是我们手搓错的那一项** —— 直接用成熟口径可避免本次事故。**待验证**：需实测其返回字段与东财 push2ex 是否同源。

### 1.4 对本项目最有价值的三条

1. **赚钱效应（尤其 1进2 晋级率）优先于热度指标。** 热度回答"市场热不热"，赚钱效应回答"你参不参与得了"。阶段判定必须由后者否决前者。
2. **中位数为主、均值为辅**，并同时展示二者差值作为"结构分化度"。
3. **周期是序列不是截面。** 单点判定必然误判，至少要 5–10 日曲线 + 起点定位。

## 二、逐阶段复盘与纠错

### 2.1 线上当前输出（错误结论）

```
阶段: 高潮   温度: 89.2   置信度: 高
判定依据: 高度7板(≥5) / 昨涨停均值10.38%(>3%) / 涨停89家(≥60)
翻红率 1.0    再涨停率 1.0    炸板率 0.073
```

**一眼可见的荒谬**：昨日 81 只涨停股，今天 **100% 翻红、100% 再涨停**。而当日涨停池 82 只里首板就占 64 只 —— 若真有 81 只老票再涨停，它们至少都是 2 板，不可能只有 18 只连板。**数字自相矛盾，却被判为"置信度：高"。**

### 2.2 根因：非交易日日期回退 → 自指计算

实测东财涨停池接口（`push2ex/getTopicZTPool`）：

```
date=20260829 (周六) → 82 条，首条 000712 锦龙股份 3板
date=20260828 (周五) → 82 条，首条 000712 锦龙股份 3板   ← 完全相同
date=20260827 (周四) → 77 条
```

**传入非交易日时，接口静默回退到最近交易日，不报错、不标注、响应里没有日期字段。**（响应字段仅 `c/m/n/p/zdp/amount/ltsz/tshare/hs/lbc/fbt/lbt/fund/zbc/hybk/zttj`，无日期，无法从响应侧识别。）

于是路由逻辑：

```python
today     = date.today()                      # 2026-08-29 周六
yesterday = today - timedelta(days=1)         # 2026-08-28 周五
pool_today     = get_limit_up_pool(today)     # → 回退成【周五】的 82 条
pool_yesterday = get_limit_up_pool(yesterday) # → 【周五】的 82 条
compute_sentiment(..., pool_yesterday, svc.snapshot)  # snapshot 也是周五收盘
```

`_prev_zt_performance` 拿**周五的涨停股**去查**周五的收盘快照** —— 涨停股在它自己涨停那天的收盘涨幅恒等于 +10%。

复现结果：

| | 线上错误口径 | 正确口径 |
|---|---|---|
| 样本 | 82（周五池 × 周五收盘） | 77（周四池 × 周五收盘） |
| 均值 | **+10.62%** | **+3.17%** |
| 中位数 | **+10.00%** | **+1.97%** |
| 翻红率 | **100%** | **62.3%** |
| 再涨停率 | **100%** | **23.4%** |

**「昨涨停均值 10.38% > 3%」这条判据，是同义反复，不含任何信息。** 高潮结论完全建立在它之上。

### 2.3 正确口径下的完整指标（基准日 2026-08-28 周五）

**热度维度（都指向狂热）**

| 指标 | 数值 | 业界档位 |
|---|---|---|
| 涨停家数（封单法） | 82 | 狂热（≥80） |
| 最高板 | 7 板 | 狂热（≥7） |
| 炸板率 | 16.3%（炸板 16 / 涨停 82+16） | 狂热（≤20%） |
| 涨停数趋势 | 46 → 65 → 52 → 77 → **82** | 连续抬升 |

**赚钱效应与承接力维度（全部指向衰竭）**

| 指标 | 数值 | 业界档位 |
|---|---|---|
| **1进2 晋级率** | **16.4%**（61 → 10） | **冰点/退潮（≤25%）** |
| 1进2 四日趋势 | 11.1% → 17.9% → 20.5% → **16.4%** | **持续低迷，非单日波动** |
| 全池存活率 | 17.4% → 20.0% → 30.8% → **23.4%** | 低位震荡 |
| 昨涨停今日中位 | **+1.97%** | 逼近 <2% 亏钱线 |
| 昨涨停今日均值 | +3.17% | 与中位背离 1.2pct |
| 翻红率 | 62.3%（**37.7% 下跌**） | 偏弱 |
| 再涨停率 | 23.4% | 偏低 |
| 连板占比 | 22.0%（首板占 78%） | 一日游结构 |

**收益分布（8/27 涨停股在 8/28 的表现，n=77）**

```
最低 -9.98%   P25 -1.23%   中位 +1.97%   P75 +9.18%   最高 +29.97%
下跌 29只 (37.7%)   跌幅>5% 3只   跌幅>9% 1只
```

**分层收益 —— 这是"分歧"的直证**

| 8/27 板位 | 样本 | 8/28 均值 | 8/28 中位 |
|---|---|---|---|
| 首板 | 61 | +2.67% | **+1.42%** |
| 2 板 | 8 | +3.93% | +3.46% |
| **≥3 板** | 8 | +6.18% | **+9.99%** |

高标中位收益是首板的 **7 倍**。同时高位板（≥3板）次日存活率 62.5%，而首板晋级率仅 16.4%。**资金抱团少数高标、首板大面积一日游、强弱极端拉开** —— 这正是六阶段体系里「分歧」的定义。

### 2.4 ✅ 正确结论

> **阶段：分歧（高位分歧，即高潮之后、退潮之前的分化期）**
> **置信度：中**
> **市场温度：热度高位，赚钱效应急剧分化**

**依据（正面）**
1. 1进2 晋级率 16.4%，且连续 4 个交易日徘徊 11%–20%，**从未触及 25% 的修复下限**，更远低于 40% 的升温线 —— 新资金接力意愿极低。
2. 昨日涨停股今日中位收益仅 +1.97%，P25 为 −1.23%，37.7% 下跌 —— 打板者整体不赚钱，**不符合"无脑接力都能赚"的高潮定义**。
3. 首板中位 +1.42% vs 高标中位 +9.99%，7 倍差距 —— 强弱极端分化。
4. 涨停 82 家里 64 只是首板（78%），连板仅 22% —— 涨停以一日游为主，缺乏梯队扩散。

**为什么不是高潮**
热潮三指标（涨停数/高度/炸板率）确已触及狂热阈值，但这三项衡量的是**热度**，不衡量**你能不能赚到**。业界判据里高潮对应"晋级率≥40%"，实测 16.4%，差了一个量级。

**为什么还不是退潮**
退潮的判据是"龙头断板、连板高度骤降、炸板率≥40%"。实测：最高板仍在拓展（6→7 板）、涨停数创新高（82）、炸板率仅 16.3%、高位板存活率 62.5%。**退潮信号未出现。**

**明日验证条件（把今晚的判断变成明天能对账的东西）**

| 若明日出现 | 则印证/推翻 |
|---|---|
| 1进2 晋级率回升至 ≥25% | 赚钱效应修复 → 回归「发酵」 |
| 1进2 继续 <20% 且最高板断板（7板股不涨停） | 确认「退潮」启动 |
| 涨停家数跌破 60 且炸板率 >30% | 确认「退潮」 |
| 首板中位收益回升至 >3% 且连板占比 >30% | 赚钱效应扩散 → 上调至「发酵」 |

**待验证项**
- **本轮周期起点**未定位。需近 10 个交易日情绪分曲线（vibe-astock 做法），当前仅有 5 日涨停池，缺 8/24 之前数据。
- **节假日交易日历**缺失，当前代码只跳周末（`days=2 if weekday==0 else 1`），遇法定节假日会重复本次事故。
- 高位板样本仅 8 只，分层收益的统计显著性有限。

### 2.5 误判链条（九条，按因果排序）

| # | 问题 | 性质 |
|---|---|---|
| 1 | **非交易日日期回退**：东财接口静默返回最近交易日，`date.today()` 取到两次同一天 | **根因** |
| 2 | **自指计算**：`_prev_zt_performance` 用同日池查同日快照，恒等于 +10% | 由 #1 直接导致 |
| 3 | **规则顺序**：高潮判据排第 2 位，只看 高度/均值/涨停数 三项热度指标，无任何反向校验 | 结构性缺陷 |
| 4 | **缺失晋级率**：`docs/sentiment.md` 指标清单写明了 1进2/2进3/3板+，但 `engine.py` 从未实现 | 文档与实现脱节 |
| 5 | **只用均值不用中位数**：本例均值 3.17% / 中位 1.97%，背离 1.2pct，均值掩盖了多数人的体感 | 口径缺陷 |
| 6 | **高潮阈值过松**：本项目 高度≥5板 + 涨停≥60家 vs 业界 ≥7板 + ≥80家 | 阈值未校准 |
| 7 | **炸板率不进规则**：只参与温度，且用"价格法−封单法"差值近似，未用真实炸板池 | 口径缺陷 |
| 8 | **缺跌停家数**：退潮的关键识别信号完全缺失 | 指标缺失 |
| 9 | **置信度被污染**：`confidence` 由 temperature 与 avg 是否同向决定，avg 是伪信号 → 输出"置信度：高" | 连带故障 |

**附带发现（红线 2）：休市日数据被当作实时。**
快照 `received_at = 2026-08-29T11:53`（周六），但底层 `ticktime = 16:29:xx` 是周五收盘数据，`/api/health` 与 quote meta 仍返回 `is_stale=False / is_realtime=True`。休市日仍在每 5 分钟刷新并把陈旧数据标为实时，违反 AGENTS.md 红线 2「禁止把过期缓存冒充实盘」。

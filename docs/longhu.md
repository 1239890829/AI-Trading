# 龙虎榜模块设计 — full.md §6（Phase 4 深度实现）

## 数据与口径

- 上榜明细：东方财富 `RPT_DAILYBILLBOARD_DETAILSNEW`（已接入，见 docs/data-sources.md）。
- 上榜原因阈值**配置化**（±7% 偏离 / 15% 振幅 / 20% 换手 / 三日 ±20% / 退市整理 / ST 异动…），
  由市场规则配置驱动，不得假设所有板块同一规则。
- 席位类型：机构专用 / 沪股通 / 深股通 / 知名游资 / 一线游资 / 普通营业部 / 量化席位 / 不明席位。
  分类允许人工修正，修正写入审计日志。

## 每日总览

筛选：交易日期、上榜原因、交易所、板块、行业、概念、是否机构参与、是否知名游资、是否连续上榜、
净买额区间、成交额区间。
排序：涨跌幅、净买额、成交额、机构净买额、游资净买额、买卖金额、席位集中度、成交额占比。

## 个股详情统计

- 统计周期：历史 / 近 5 / 20 / 60 日 / 近 1 年。
- 内容：上榜次数、原因变化、净买/买/卖趋势、席位数量趋势、机构与游资参与次数与净额、
  连续买卖次数、首次上榜至今表现。
- 表现：次日/3日/5日/10日涨跌、成功率、平均/中位收益、最大收益、最大回撤、负收益比例、
  样本数量与有效期。

## 席位明细字段

营业部名称、席位类型、买卖金额、净额、占成交额比、历史上榜次数、近一年参与/买卖金额、
历史跟买收益、跟买成功率、常见题材、最近操作时间、数据置信度。

## 关系图

`股票 ↔ 板块 ↔ 题材 ↔ 营业部 ↔ 机构 ↔ 日期` 图谱：
节点筛选/搜索、时间范围、净买/卖过滤、机构游资过滤、连续参与过滤、
多营业部抱团 / 共同买入 / 对手盘 / 协同关系识别、跟买表现统计。
**每条关系必须可回溯至原始数据**（记录来源行 id）。

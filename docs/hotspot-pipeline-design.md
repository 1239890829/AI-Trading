# 热点消息能力建设方案：消息捕获 → 板块传导 → 个股映射与验证（2026-09-07）

> 定位：对照专业投资者处理热点消息的三段能力（捕获/传导/映射验证），盘点现有系统、补齐缺失，并以周末四条真实消息为样例全链路实测。
> 状态：**方案待确认，未实施**。文中板块/个股映射全部为 2026-09-07 晨东财接口实测（备域 push2delay），四条标题过现有 `events/extract.py` 引擎的输出为真实运行结果，非推演。

---

## 0. 结论摘要

1. **现有事件引擎「骨架好、覆盖窄」**：四条消息实测——能正确分类（非农→data/24h半衰期）但 2 条零题材命中（非农、GPT-6）、2 条命中题材却 direction=0（厄尔尼诺→电力、长存→存储芯片）。缺的不是框架，是**词表覆盖、传导链、方向词典精度**。
2. **最大缺口是「快讯流」与「传导链」**：系统只有按标的拉取的个股资讯/公告，没有全市场 7x24 快讯源；事件→板块只有 16 词人工别名表单跳映射，没有「厄尔尼诺→种植/化肥/电网」这类一级事件→多板块的传导知识。
3. **第二个缺口是「验证回路」**：消息出现后没有任何机制回答「市场接没接」——而本次实测恰逢其时：周五收盘存储/设备板块普跌（华虹 -8.9%、长川 -5.7%），论文级消息没有被盘面确认，**没有验证层就会在无确认的消息上追高**。
4. 建设走 P0/P1/P2：P0 = 快讯流接入 + 传导链表 + 方向词典修订（全部复用 events 骨架）；P1 = 验证回路 + 题材核心度 + 事件日历；P2 = 事件类告警 + 助手工具 + 历史相似事件检索。

## 一、专业投资者的三个关键能力拆解（工程化视角）

### 1.1 信息来源与时效——关键不是「快」，是「分级 + 前置」

| 层级 | 专业投资者的来源 | 时效特征 |
|---|---|---|
| 官方一级 | 交易所公告、央行/部委官网、巨潮 | 盘前/盘后定点，可日历化 |
| 一线电报 | 财联社电报、券商晨会、机构群 | 分钟级，7x24 |
| 海外终端 | 彭博/路透、Fed 官网、BLS 日历 | 定点发布（非农 20:30、CPI、议息） |
| 聚合流 | 东财快讯、新浪 7x24、同花顺 | 秒~分钟级，噪音大 |
| 自媒体/小作文 | 群聊、微博 | 最快但可信度最低 |

专业做法的两个本质点：①**事件日历前置**——非农几号几点是先验已知的，提前定好「盯什么、怎么反应」，而不是等消息出来再反应（我们周五晚的非农验证回测就是这类前置研究的产物）；②**来源分级先于内容判断**——同一条「据悉传闻」从财联社电报出来和从自媒体出来价值完全不同。

### 1.2 消息→板块传导逻辑——产业链知识 + 预期差

1. **多级传导**：一级事件（厄尔尼诺）→ 物理影响（南美/东南亚干旱减产）→ 商品价格（粮、肥、糖）→ A 股板块（种植、磷肥钾肥、电力）。专业投资者脑子里有这张图，且知道**每条边的历史可靠性**（粮食价格→种植股弹性弱、化肥涨价→化肥股弹性强）。
2. **预期差思维**：消息本身不重要，「与市场预期的差」才重要——非农 18 万 vs 预期 16.5 万，方向和幅度都是差值决定的。这是周五晚回测的核心方法（意外差标准化投票）。
3. **对冲两条链**：同一条消息常有多空两面（非农强=经济好+加息压力），方向取决于当时主导矛盾——落成系统就是「方向成对分析」（events/extract.py 已有雏形：禁令对国产替代题材反转为利好）。

### 1.3 个股映射与验证流程——先验映射 + 后验验证，两层过滤

```
题材 → 成分股池 → 核心度筛选 → 盘面验证 → 交易决策
                    ①             ②
```
- ①**核心度筛选**：东财板块成分有噪音（实测：泸州老窖混在「农业种植」市值第一），专业投资者按主业纯度/历史辨识度/弹性手工分层——「消息一来买谁」是排好序的。
- ②**盘面验证**：消息出现后 30~60 分钟看市场接不接——板块涨停家数增量、主力净流入、成交额同比放大。**验证失败就不做**（论文阶段的消息尤其如此）。这是纪律，不是能力，恰恰是系统最擅长替代人的部分。

## 三、四条消息的传导路径实测分析

> 时点说明：以下行情字段为 9-05（周五）收盘状态（实测于周一 07:33 开盘前）；四条消息均为周末笔记，**周一开盘才是第一定价窗口**。

### 3.1 非农超预期 → 9月加息押注 → 美股硬件大涨 → A股开盘情绪

```
传导链：非农超预期(意外差=强) → 加息预期↑ → 美元/美债利率↑ → 纳指硬件(周五已定价) → A股算力/果链开盘情绪
```
- **本系统先验量化结论直接可用**（`docs/nfp-ashare-validation.md`，10 年 116 期×双指数）：A 股对非农的定价与美股**方向相反**——劳动市场意外强 → 次日 A 股偏弱（score>0 组上证 -0.17%）且波动放大（|score|≥2 组振幅高 24~33%）。**「超预期」对 A 股是偏空+高波信号，不是美股那条「硬件大涨→A 股科技热」的线性外推**。
- 板块映射（实测成分）：算力/CPO——工业富联、中际旭创、新易盛、寒武纪；消费电子/果链——立讯精密、蓝思科技、京东方A。
- **系统会怎么处理**：`category=data` 正确、24h 半衰期正确，但零题材关联。→ 缺 G2（宏观→板块传导链）+ G6（日历前置：20:30 公布时间应提前一天进简报）。
- 可执行结论：今晨简报应给「非农超预期 → A 股开盘偏弱+波动放大（历史回测），关注算力链是否抗跌分化」而不是转述「美股硬件大涨」。

### 3.2 厄尔尼诺超强 → 全球食品价格 2022 年来最高 → 农业/化肥/电力电网

```
传导链（三级）：厄尔尼诺 → 主产区天气异常(南美/东南亚/澳洲) → 农产品减产涨价 → ①种植/种业 ②化肥(磷/钾) ③电力(负荷+水电) / 电网(投资)
```
- 板块与成分（实测）：粮食种植——北大荒、苏垦农发（**板块仅 2 只 = 窄板块，事件弹性集中**）；磷肥及磷化工——云天化、兴发集团、川恒股份；钾肥——盐湖股份、藏格矿业、亚钾国际；电力——长江电力、华能水电、中国核电；电网设备/特高压——国电南瑞、思源电气、特变电工、中国西电。
- 弹性差异（专业判断的工程化表达）：化肥（涨价直接进利润）> 种植（国内主粮自给，进口依赖大的是大豆/糖）> 电力/电网（逻辑最间接，靠极端天气兑现）。**传导表应记录每条边的强度权重**，输出时按强度排序而不是平铺。
- **系统会怎么处理**：标题含「化肥电力受益」字样才命中「电力」一条且 dir=0（「受益」不在词典）；「厄尔尼诺」无别名 → 农业化肥全漏。→ 缺 G2+G3。

### 3.3 长存 3D 存储学术进展 → 绕过 EUV 推进下一代制造

```
传导链：学术突破(论文级，非量产) → 国产存储信心 → ①存储芯片/长存产业链 ②半导体设备(北方华创=设备龙头即消息主体)
```
- 板块与成分（实测）：存储芯片——长鑫科技、中芯国际、北方华创、华虹宏力；半导体设备——北方华创、中微公司、拓荆科技、盛美上海。
- **关键定性：certainty 应判「proposed/论文级」**，时效半衰期短、不宜给正方向分——恰好落进系统已有的 `fact_kind/certainty` 三档设计，但 `_PROPOSED` 词典（拟|将|计划）不含「论文|理论上|实验室」。
- **盘面验证现状（周五收盘实测）**：存储/设备普跌（华虹 -8.9%、长川 -5.7%、北方华创 -2.7%）——**消息未获盘面确认**，这类事件正确用法是「记录 + 观察周一发酵度」，不是直接映射买入。→ 缺 G5（验证回路）。
- 方向对冲规则现成：若后续出现「EUV 管制升级」类消息，`_FLIP_POSITIVE`（国产替代反转）会自动给出利好判断——这一条现有引擎已具备，是亮点。

### 3.4 OpenAI GPT-6 → 应用端「从问答到直接做事」→ AI 应用/Agent

```
传导链：Agent 执行力升级 → ①应用落地加速(办公/金融/内容) ②算力需求底层受益(推理算力) ③国内大模型跟进
```
- 板块与成分（实测）：AI应用——海康威视、东方财富、同花顺、世纪华通；AI智能体——中控技术、分众传媒、传音控股；AIGC 与 AI应用成分高度重叠（东方财富/同花顺/世纪华通双榜）——**板块交叉去重是映射层的必修课**；算力——工业富联、中际旭创、寒武纪、中国移动。
- **系统会怎么处理**：零命中（OpenAI/GPT 不在别名表，「发布」不在词典）。→ 缺 G2。海外产品事件需要一个「海外实体→A 股题材」的映射子表（OpenAI/英伟达/特斯拉/苹果 → 对应题材），这条边专业投资者的群里天天发生，系统里现在是空白。

## 四、建设方案

### 4.1 总架构：一层采集、两级映射、一个验证环

```
[采集层] 东财快讯 np-weblist(15~30s轮询) + 宏观日历(akshare) + 个股资讯/公告(现有)
     │  build_event() 复用：指纹去重 / 来源分级 / certainty / 半衰期
     ▼
[事件层] EventStore(现有) + 方向词典修订(G3) + 别名表扩容
     │
     ▼
[传导层] EVENT_CHAINS 传导表(新)：关键词 → [(题材, direction, 强度, chain文本, hops)]
     │      ①产业链多级：厄尔尼诺 → 种植/化肥/电力 (带强度权重)
     │      ②海外实体：OpenAI/英伟达/苹果 → AI应用/算力/果链
     │      ③宏观量化：非农/CPI → 方向由意外差投票(已验证) 而非词典
     ▼
[映射层] 题材 → 成分(ths 归因 ∩ 东财成分) + 核心度分层(G4)：主业纯度+历史辨识度
     │
     ▼
[验证环] 事件后 30min/60min/收盘 采样关联板块：涨停增量 / 板块资金f62(P0 board_flow就绪后) / 成交额同比
     │      → status: fermenting(发酵) / confirmed(确认) / faded(证伪) / unknown(未到采样点,显式)
     ▼
[消费层] 事件tab(现有) / 盘前简报传导段 / alert 事件规则 / watcher / 助手工具
```

### 4.2 分阶段实施（P0 最小闭环，全部复用 events 骨架）

| 批次 | 内容 | 关键设计 |
|---|---|---|
| **P0** | ① 快讯流接入：`news/flash.py` 拉东财 `np-weblist/comm/web/getFastNewsList`（101 宏观+全部频道，UA+Referer+req_trace 必带，15~30s 轮询，TTL 失败不缓存）→ `build_event` 入 EventStore；② `EVENT_CHAINS` 传导表（`events/chains.py`，与 ENTITY_ALIASES 同风格人工维护 + LLM 辅助生成初版经审核）；③ 方向词典修订：`_POSITIVE` 增「受益\|进展\|成果\|里程碑\|落地」，`_PROPOSED` 增「论文\|理论上\|实验室\|概念验证」；④ 别名表扩容：OpenAI/GPT→AI应用、厄尔尼诺/拉尼娜→农业种植+磷化工+电力、非农/加息/降息→宏观传导 | 传导表每行带 `basis` 与强度 1-3；direction 仍不许猜——词典没命中就 0；抽测基准：四条消息全部至少命中 1 板块且方向正确或显式 0 |
| **P1** | ⑤ 验证环：`events/verify.py` 事件→关联板块→三次采样落 status；⑥ 题材核心度：`theme_core.py`（ths 归因成员 ∩ 东财成分，按纯度/辨识度分层 Top3-5）；⑦ 事件日历：akshare 宏观日历进盘前简报固定 section（非农日标注「明晨 20:30 非农，周一波动或放大」——周五晚验证报告的直接落地） | 验证采样复用 board_flow（依赖其 P0 落地）；核心度离线批算+24h 缓存，不进请求路径 |
| **P2** | ⑧ alert 新规则 `theme_event_burst`（题材 1h 事件数≥N 且 +1 方向占比≥阈值 → 飞书）；⑨ 助手工具 `{{tool:events\|hot}}`、`{{tool:chain\|keyword=厄尔尼诺}}`；⑩ 历史相似事件检索（事件分类+传导目标粗检索→当时板块 3 日表现） | 规则收口 alert_repo；工具走受限通道（≤2 次/轮） |

### 4.3 性能与纪律红线

- 快讯轮询单源单端点，抽取为纯函数（<1ms），事件存储沿用 EventStore，不为热点消息开新存储；
- 验证采样只在事件活跃窗内跑（半衰期到期即停），不常驻轮询全市场；
- 方向词典/传导表全部人工可审计（basis 必带），LLM 只做初稿生成，**不改运行时判断**；
- 三态纪律：验证状态 unknown/fermenting/confirmed/faded 显式，缺失绝不填 confirmed；
- 东财接口间歇性拦截（今晨主域又拒 urllib，curl_cffi+备域通过）：采集层双域 failover + 延迟口径标注，复用 board_flow 方案已验证的姿势。

## 五、样例验收基准（P0 完成的定义）

用本方案四条消息做固定测试集，`build_event` 期望输出：

| 消息 | 现状（实测） | P0 目标 |

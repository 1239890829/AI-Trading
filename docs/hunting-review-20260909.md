## 一、涨停滞后分析（为什么没能提前监控到快速涨停的票）

### 1.1 实测滞后分层（37 只台账 × 34 家涨停池对照）

| 层级 | 场景 | 实测滞后 | 案例 |
|---|---|---|---|
| **T0 集合竞价涨停** | 09:25 集合竞价即封（金正大 3板/红棉股份/泸天化/瑞尔特/精艺股份/悦心健康 6 只） | **~1 分钟**（09:26:02 首轮登记） | 金正大 09:25 涨停 → 09:26:02 入台账 |
| **T1 盘中快速涨停** | 09:30–09:46 秒板/快速板（华工科技/中粮科技/三孚股份/新亚电子等） | **1–2.5 分钟** | 华工科技 09:30 → 09:31:18（78 秒）；三孚股份 09:37 → 09:38:18 |
| **T2 题材成建制滞后** | 题材首只涨停已现，但题材整体判定未达标 → 后续成员延迟入册 | **10–27 分钟** ⚠️ | 百大集团 09:32 涨停 → 09:52 登记（20min）；华脉科技 09:25 → 09:52（27min）；中基健康 09:34 → 09:51（17min） |

### 1.2 滞后根因（按链路拆解）

1. **T0/T1 的 1–2.5 分钟**：opportunities 60s 缓存重建 + 前端 60s 轮询 + watcher 判读 worker 30s 节拍——三层轮询周期叠加。这是**架构性下限**，可压缩但无法归零。
2. **T2 的 10–27 分钟（最大短板）**：
   - 题材强度档（领涨/强势）判定需要「成建制」证据（多家涨停累积）——题材首只涨停到成建制之间是空窗
   - opportunities 缓存按 trade_date+参数为 key，新题材首现要等下一轮 rebuild
   - 华脉科技 09:25 就 3 板涨停，但其所屬题材（光通信）上午 09:41 才整体成形 → 它作为个体 27 分钟后才被「补登记」
3. **数据延迟层**：快照 15s 轮询 → 涨幅/量比数据本身滞后 ≤15s（次要因素）。

### 1.3 已在合适点位提醒过的票（入选理由实录）

T0 层 6 只全部在**涨停后 1 分钟内**入册且理由完整，以金正大为例：
> 登记 09:26:02｜layer=today_strongest｜题材=化肥磷化工（厄尔尼诺链）｜gate=boards=3 pct=9.88｜certainty=高（阶段基座+封板质量）

T2 滞后的票（百大集团 5 板/华脉科技 3 板）虽迟但到——台账保证「迟到的也入册」，复盘时点可见。

### 1.4 改进方向（按收益排序）

1. **竞价即时通道**（消 T0 到 0）：09:25 集合竞价数据源（竞价涨幅榜）——竞价即涨停的直接登记+气泡，比现在快 1 分钟且**先于开盘**
2. **涨停池即时通道**（压 T1 到 <30s）：涨停池数据已有 WS 链路潜力——首封事件推送直连台账+气泡，跳过 60s 缓存
3. **题材首只涨停快速成册**（消 T2）：题材首只涨停 → 立即以「孕育→启动」层登记该股（不等成建制），题材后续成员按现门槛跟上——把 T2 的 27 分钟压缩到首板即登记
4. 快速涨停（09:35 前首封）跳过 LLM 判读直接 notify（时间敏感类豁免判读延迟）

## 四、现行选股标准（全部源自你的要求，逐条对应）

### 4.1 候选准入（intraday_opportunity）
- 题材容器：当日涨停池 + 官方归因直通（ths 逐字口径）
- 个股判定：**确定性** = 题材阶段基座 × 封板质量修正（三态：高/中/低/未判定，判不出不冒充）；**辨识度** = 人气 × 高度 × 角色（市场记住它的成本）
- 台账登记门槛（09-09 收紧）：**交易时段内**，已涨停（boards≥1）或 涨幅≥5% 或 确定性=高，任一满足；命中依据写入 reason

### 4.2 择时分层（你的「机会分层」需求）
- 今日最强（≥5 家成建制或 ≥2 板或领涨）→ 悄悄启动（2–4 家首板）→ 孕育待发酵（零散待确认）
- 四档：空仓（gate 多条件 OR）/ 观望（梯队断层）/ 试仓（确定性=高单点验证）/ 买入（五因素全过+量价确认）

### 4.3 组合保护
- 空仓闸门：晋级率<30%、炸板率≥35%、跌停≥15 家、接力亏钱——触发撤买入范围
- 稳定器：每日换股上限 2 只（60 日回放实证：日均换手 100%→37%）+ carryover 兜底
- 风险：止损 = max(档位基准, 1.5×ATR%) clamp 3%~12%，逐只带失效条件

### 4.4 执行流程
盘前简报（昨日复盘+今日计划）→ 盘中机会三层跟踪（台账首见登记）→ watcher 确认+AI 判读提醒（代码+名称+依据）→ 收盘清算（入选价 vs 收盘逐笔判定）→ 复盘归因（归因类别×胜率统计）→ 议程裁决（参数改进进影子队列）→ 15:45 进化总结报告（每日唯一推送）

## 五、组合策略设计（稳定核 + 灵活壳 + LLM 验证 + 有效性闭环）

### 5.1 稳定部分（实践中已验证，不随盘面变）
| 组件 | 依据 |
|---|---|
| 每日换股上限 2 只 | 60 日回放：日均换手 100%→37.1%，持有 1.0→2.22 天 |
| 止损纪律（3%~12% clamp） | freqtrade 框架 A 股映射 + 每只失效条件 |
| 梯队第六维 + 阶段系数 | 退潮期个股再强也打折（系数 0.55） |
| 空仓闸门硬条件 | 客观多条件 OR，不主观判断 |
| 三态判定纪律 | unknown ≠ 低，判不出不冒充机会 |

### 5.2 灵活部分（随行情切换）
| 组件 | 切换机制 |
|---|---|
| 六维权重 | regime：财报期（基本面 25%）↔ 空窗期（情绪 25%/梯队 20%）自动切换 |
| 风格路由 | 六相位（启动/发酵/高潮/分歧/退潮/冰点）→ 权重偏移（影子队列守护剧变） |
| 机会分层 | 三层徽标随题材成建制程度自动升降 |
| 择时档位 | gate/断层/试仓/买入四档按盘面证据实时判定 |

### 5.3 LLM 辅助盘面验证（本轮回测发现的新增项）
今日实战暴露的需求：**「题材→上下游扩散」的模式识别**（厄尔尼诺链、光通信链的实时串联）——规则层能发现单点涨停，但「这些涨停属于同一条扩散链」的语义判断交给 LLM：
- **盘中**：聚类后由 LLM 对题材簇做「扩散链推断」（上游/下游/材料端关系），输出进台账 layer 与气泡响应建议（只读）
- **盘后**：议程 LLM 输入加入「当日扩散链 vs 你预判的模型（先大后细/材料端发散）」对照——模式命中率的量化统计由此沉淀

### 5.4 有效性验证（三层闭环，已运行）
1. **当日**：台账清算逐笔判定（入选价 vs 收盘）+ 胜率/平均盈亏统计
2. **参数级**：影子队列（剧变检测）+ 回放门禁（10 日对比 vs 基线）+ 30 日实验劣化自动回滚
3. **策略级**：消融对照（梯队维边际贡献，10 月中旬出数）+ 归因类别×胜率周度统计（本报告 §2.3 机制）+ 元评估周报

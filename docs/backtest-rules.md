# 回测规则（强制禁令）

回测引擎（`backend/app/market/backtest.py`）**已**把以下禁令实现为**代码级校验**，违反即抛异常终止回测，而不是靠约定。

## 1. 数据可用性

- 回测器只能访问 `bar_ts <= 当前回放时间` 的数据；引擎按交易日历逐 bar 推进并提供 `as_of` 视图。
- 财务数据按**公告日**（非报告期）对齐：报告期数据在公告日之前不可见。
- 股票池必须使用**时点成分**；退市股票保留在池内（禁止幸存者偏差）。
- 使用修订后数据重算历史时，必须保留原版本（`version` 字段），不得覆盖时点值。
- **退市必须是显式事件**（R14，2026-09-14 修）：只有 bar 上带 `delisted=True` 才按该 bar
  收盘清算（`reason="delisted"`，计为真实成交）。**回测窗口结束 ≠ 公司退市**——数据流末
  仍未平仓的持仓按末根收盘**估值**并记入 `BacktestReport.open_position`，**不产生成交**，
  因此不进成交笔数 / 胜率 / 盈亏比（这些只由 `pair_trades_ts` 的已配对成交得出）；
  权益（含浮动盈亏）与已实现成交统计由此天然分离。如需「假设清算」，走
  `run_backtest(..., liquidate_at_end=True)`，产物标 `synthetic=True` 且同样不计入成交统计。

## 2. 撮合约束（A 股规则 §2.4 全部配置化）

- T+1：当日买入不可当日卖出（含底仓变相 T+0 之外的持仓校验）。
- 涨停价挂买单不可成交、跌停价挂卖单不可成交；一字板禁止成交。
- 停牌日禁止成交；复牌首日按规则处理。
- 成交价使用次日开盘价/VWAP 等可交易价格，禁止用信号 bar 收盘价撮合同一 bar 的信号。
- 手续费 / 印花税（卖出）/ 过户费 / 滑点全部计入，参数来自配置而非硬编码。

## 3. 每笔交易必须记录

触发时间、触发信号、使用的数据时间、下单时间、成交时间、成交价格、成交数量、
手续费、滑点、是否部分成交、失败原因（涨跌停/停牌/T+1/资金不足）。

## 4. 防泄露测试（**已合入**，先于引擎落地）

> 执行位置：`backend/tests/test_backtest.py`。**八条的实测状态**：第 1~7 条逐一有对应用例；
> 第 8 条（修订数据不覆盖历史时点）在 v1 **结构性不适用**——无财务/多版本数据源接入，
> 引擎不缓存历史序列、每次全量重算；接入财务数据时须以 `(report_period, ann_date, version)`
> 三元组入 `FundamentalsView` 后补测（原始对照表在测试文件头部，此处不重复）。

构造以下用例并断言：
1. 未来 bar 数据不可访问（读取即抛异常）；
2. 未来财报不可见；
3. 退市股不被自动剔除（**且窗口结束不得冒充退市**：四态分别验 =
   仍在市但窗口结束 / 末日新买 / 末日跌停 / 显式退市事件；见 `TestEndOfSample`）；
4. 停牌日无法成交；
5. 涨停买不进、跌停卖不出；
6. T+1 生效（当日买入当日卖出被拒）；
7. 手续费与滑点反映在资金曲线；
8. 修订数据不覆盖历史时点数据。

## 5. 结果可解释性

输出必须包含：基准对比、超额、最大回撤及持续时间、夏普/Sortino/Calmar、胜率、盈亏比、
月度/年度收益、行业与风格暴露、牛市/熊市/震荡市分段表现，以及参数敏感性说明。
样本内/样本外必须分离；禁止“先看结果再调参”的无样本外报告。

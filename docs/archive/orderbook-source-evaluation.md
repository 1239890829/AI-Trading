# 五档盘口数据源评估：现状够不够，下一步选什么

> 检索与实测时间：2026-08-29/30。价格类信息来自公开渠道检索（问答/渠道页居多），**签约前一律以官方最新公示为准**。

## 结论先行（TL;DR）

1. **当前方案对现有用途够用，对升级路线不够。** 现有五档来自腾讯 qt.gtimg 免费快照（3~6 秒切片 × 5 秒轮询），对「盘口展示 + 质量校验 + 模拟撮合（只用最新价/涨跌停价）」完全够；但它没有逐笔、没有委托队列、没有十档，且是轮询非推送——做 T 高阶信号（盘口支撑/大单行为/排队结构）与全市场高频采集这两条路都走不通。
2. **GitHub 检索结论：不存在合法、活跃、精度超过免费快照的开源数据源。** L2 行情是沪深交易所授权销售的数据，开源社区里只有三类东西：同级爬虫（akshare/efinance/easyquotation，本质还是新浪/腾讯免费快照）、已死的免费 L2（dHydra 依赖的新浪 L2 普及版、easyquotation 的 Leverfun 十档均已停服）、付费账号的转发工具（IssacLv2←大智慧365、mootdx←通达信协议）。数据本身开源 = 无源之水。
3. **商业推荐（2+1）：首选券商 miniQMT/xtquant，次选掘金量化；大智慧365+第三方转发仅作说明不推荐。** 中小规模收益最大化 = 维持免费源 + （若要升级）miniQMT；大规模/商用 = 掘金机构版或 miniQMT 全功能。理由见 §4。

## 1. 现状评估（实测）

| 维度 | 现状 | 事实依据 |
|---|---|---|
| 数据形态 | 五档价+量（快照切片，非逐笔合并还原） | `tencent.py get_order_book` ← qt.gtimg 快照字符串 |
| 更新频率 | 上游 ~3-6s 切片 × 本地 5s 轮询，端到端 5-10s | `poll_interval_seconds=5` |
| 覆盖度 | 全 A 股 | 同快照接口 |
| 备源 | 新浪（同级别快照）、东财（push2 本机被 WAF 限流，已实测） | docs/data-source-comparison.md |
| 消费方 | 盘口展示、质量校验、paper 撮合（最新价+涨跌停价） | 实际未用到档位深度 |
| 合规 | 免费接口爬取：本地个人研究属行业普遍现状；**对外提供服务/转售/商用分发不合规**（交易所行情授权体系） | — |

**量级测算**：自选 30 只 × 5s 批量轮询 = 每 5s 一个批量请求，免费源无压力；全市场 5550 只高频采集 ≈ 每 3s 92 个批量请求——免费源必封，且在合规上站不住。**结论：现状与「当前量级」匹配；瓶颈只在升级需求出现时成立。**

**升级需求触发条件**（满足任一才值得花钱）：
- 做 T 信号要用盘口结构（大单挂撤、队列、十档压力位）——五档快照推不出来；
- 全市场分钟级/秒级采集（选股器、L2 因子）；
- 把行情能力对外提供服务（合规要求持牌授权）。

## 2. GitHub 检索：为什么没有开源可选

| 检索到的方案 | 实际情况 | 判定 |
|---|---|---|
| easyquotation（新浪/腾讯爬虫） | 与本项目现有源同级，精度不高于 qt.gtimg | 无增益 |
| easyquotation 的 leverfun 十档 / dHydra 的新浪 L2 普及版 | 上游免费 L2 服务已停服（repo 停更于 2016-2019 时代） | 不可用 |
| IssacLv2 | 需购买大智慧365 收费账号，本地转发成 HTTP——**数据是买的，工具只是转发**，且违反终端许可、随时失效 | 数据源≠开源 |
| mootdx（通达信协议） | 协议级分笔/五档快照，精度与免费源同级；L2 仍需付费通达信 | 无增益 |
| akshare / efinance / a-stock-data(mootdx 聚合) | 全部是免费接口聚合，盘口档位能力 ≤ 腾讯快照 | 无增益 |

**结构性原因**：L2 行情由交易所授权销售，任何"开源 L2 数据"都不可能合法存在；开源能提供的是解析工具和接入 SDK，不是数据。

## 3. 候选对比（3 个）

### A. 券商 miniQMT（迅投 QMT 极简模式，xtquant Python 库）

| 维度 | 内容 |
|---|---|
| 数据准确度/覆盖 | 交易所授权 Level-1 全推（五档、逐笔合并快照）；开通 L2 权限后十档+逐笔成交+委托队列；全 A 覆盖 |
| 更新频率 | **全推（推送式）**，非轮询；L1 毫秒级到达，L2 切片 ~3s |
| 接入方式 | `xtquant` 官方 Python 库（xtdata 行情 / xttrader 交易）；本地订阅回调 |
| 授权/合规 | 券商行情授权给开户账户；**个人研究合规，禁止转售/对外商用分发** |
| 价格明细 | 软件 0 元；门槛=近 20 日日均资产 ~10 万（国金/华西/中金财富；中泰称零门槛）；L2 权限达标多免费，不达标 ~300 元/月（公开渠道口径 800-2000 元/年、个别 88 元/月起） |
| 接入/维护成本 | 新增 Provider 适配（推模式→内部 Quote/OrderBook schema）1.5~2 天；**硬限制：仅 Windows + 需常驻登录终端**（本项目主力是 macOS，需一台 Windows 常驻机/VM 做行情网关，跨机取数增加运维面）；长期风险=券商政策变动、登录态掉线 |

### B. 掘金量化（myquant.cn，官方云服务）

| 维度 | 内容 |
|---|---|
| 数据准确度/覆盖 | 交易所授权 L1（免费版）+ L2 附加购买（十档/逐笔）；历史数据底座完整（回测友好） |
| 更新频率 | 免费版实盘行情 ~3s 延迟；专业版实时 tick |
| 接入方式 | 官方 SDK（Python/C++/C#）+ REST，跨平台，无本地终端依赖 |
| 授权/合规 | 服务商持牌授权链路清晰，**三者中合规最干净** |
| 价格明细 | 免费版（回测/模拟可用）；专业版 ~2000-3000 元/年；**L2 附加 ~600 元/年/市场**（渠道口径，签约前核实）；机构版 1.5万~5万/年 |
| 接入/维护成本 | Provider 适配 1~2 天；云服务无终端运维，**长期维护成本三者最低**；限制=依赖第三方服务可用性与续费 |

### C. 大智慧365 + 第三方转发工具（IssacLv2 类）——仅作说明，不推荐

| 维度 | 内容 |
|---|---|
| 数据 | 沪深 L2 十档/逐笔/买卖队列/深市千档（免费版已含 L2 基础行情，高阶收费） |
| 接入 | **无官方 API**；靠第三方本地转发工具出 HTTP |
| 合规 | 违反终端许可条款（账号随时可能被封）；转发工具随时失效 |
| 成本 | 软件免费版 0 元（收费版数百元级，官方页为准）；接入 ~1 天 |
| 判定 | 短期最便宜，长期维护不可控、合规瑕疵——**不做主线**。它存在的意义恰好证明了结论：真 L2 必须走授权渠道买 |

（注：Wind/东方财富Choice/恒生聚源属机构级终端，数万元/年起且 API 面向机构，对本项目量级明显过配，不列入候选。）

## 4. 性价比排序与分规模推荐

**收益最大化：A（miniQMT）**——它是唯一「0 软件费拿交易所授权全推行情 + 官方 Python API」的通道，L2 达标后十档/逐笔/队列全解锁，同时 xttrader 顺带打通未来实盘模拟通道（与本项目的 paper 引擎形成对照）。代价是 10 万资金门槛（不占现金流但占资产配置）和 Windows 常驻终端的运维面。若这两条都接受，A 是无脑选。

**中小规模（现状：自选几十只、本地个人、显示+模拟撮合）**：
1. **维持免费源（0 元）**——现有用途五档快照完全够，升级是伪需求；
2. 需要升级精度/合规时 → **miniQMT**（0 软件费）；
3. 不想绑券商/没有 Windows → **掘金专业版+L2（约 3000-4000 元/年）**。

**大规模（全市场高频采集、逐笔因子、对外商用）**：
1. **掘金机构版（1.5万~5万/年）**——合规链路最干净、无终端运维、API 并发有保障，商用首选；
2. **miniQMT 全功能（50 万门槛，华泰/银河等）**——成本仍为零+极速柜台，但商用再分发仍受券商授权限制；
3. 数据规模再上一个量级（多资产/机构研究）→ 恒生聚源/Wind 这类机构数据终端，本方案不展开。

**给本项目的直接建议**：现在不动（免费源 + 备源加固足够）；当分时图做 T 信号（docs/minute-chart-plan.md P2）证明需要盘口结构数据时，优先评估 miniQMT（先确认能否接受 Windows 常驻机），不行再上掘金专业版。两边的 Provider 适配都建议落在现有 `MarketDataProvider` 协议的新增方法上（推模式行情用独立 Hub，不复用轮询 QuoteHub），切换成本已隔离。

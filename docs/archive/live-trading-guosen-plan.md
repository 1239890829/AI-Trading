## 1. 通道结论

**国信 miniQMT（极简模式）**：
- 门槛：近 20 个交易日日均资产 **10 万元**（股票+基金+现金计入）；免费，无年费，仅正常佣金。
- 条件：风险测评 **C4 积极型**及以上；半年以上 A 股交易经验；账户无冻结/休眠异常。
- 关键：**必须走客户经理渠道申请**（自助开户账户申请不了量化权限）；申请时原话确认
  「带独立交易模式的 miniQMT」。审核 1-3 个工作日。
- 客户端：国信 QMT 下载后登录勾选「独立交易/极速模式」进入 miniQMT；**运行期需客户端保持在线**。

## 2. 技术栈

```
[macOS] ashare-ai-trader 后端(8000)
   │  HTTP（仅内网/Tailscale）
   ▼
[Windows] trade-bridge（薄 FastAPI，我们写，~300 行）
   │  本机 import xtquant
   ▼
[Windows] 国信 QMT 客户端（miniQMT 极简模式，保持登录）
   ▼
国信交易通道
```

- easytrader.MiniqmtTrader 可直接复用（委托/成交/错误回调 + 沪深市价类型映射 + 持仓/资金/撤单），
  或桥内直接用 xtquant（少一层依赖）。**决策：桥内直接 xtquant**，easytrader 作为 API 形态参照。
- xtquant 包来源：QMT 安装目录自带，或 thinktrader 官方渠道（不 pip 装来路不明的包）。

## 3. 风控红线（桥实现前必须成立）

1. 下单全部经 picks execution-gate 同口径校验（涨跌停双边区间 / T+1 / 停牌 / 额度）。
2. 白名单操作：限价买/卖、撤单、查询；**市价单禁用**（滑点不可控）。
3. 单笔金额上限、单日累计额度、日内笔数上限——桥侧硬编码 + 配置双保险。
4. QMT 客户端心跳：断线即熔断（拒绝新委托），恢复需人工确认。
5. 全部委托/成交回报落 /real/trades 与本地日志；每日对账（桥持仓 vs 系统持仓）。
6. **不做打板抢板**：miniQMT 通道延迟不适合排队封单，只用于接力确认/低吸/卖出纪律执行。
